# Clase 02 — Instalación & formas de correr Claude Code

**Tags:** `Setup` `Herramientas`
**Conecta con:** Clase 01 · Clase 03

---

## Idea central

Hay 3 formas de correr Claude Code. La app de escritorio es la recomendada para el curso porque integra todo en un solo lugar sin configuración extra.

---

## Las 3 formas de correr Claude Code

| Forma | Cuándo usarla |
|-------|--------------|
| **App de escritorio** | Uso general del curso — recomendada |
| **Terminal** | Flujos avanzados, scripts, VPS |
| **IDE (VS Code / JetBrains)** | Si ya programas y quieres integración nativa |

---

## Instalación

- El proceso es **idéntico en Mac y Windows**
- Descarga desde claude.ai → pestaña **Code**
- Requiere Node.js instalado para algunos MCPs

---

## 💡 Tip

Instala la app de escritorio aunque después uses la terminal — la interfaz visual es útil para entender qué hace Claude Code antes de automatizarlo.
