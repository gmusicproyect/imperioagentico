## La idea que une todo

> Un agente de Claude Code es: **identidad** (CLAUDE.md) + **procedimientos** (Skills) + **herramientas** (MCPs) + **lógica** (loops/DAME) + **infraestructura** (Routines/VPS) + **memoria** (Obsidian/RAG)

Cada clase enseñó una pieza. Este mapa muestra cómo encajan.

---

## Checklist del agente listo para producción

- [ ] CLAUDE.md global con identidad base
- [ ] CLAUDE.md local por proyecto con contexto específico
- [ ] Al menos 1 Skill documentado por flujo repetible
- [ ] MCPs necesarios conectados y verificados con `/mcp`
- [ ] Framework DAME definido para las tareas autónomas
- [ ] Routine o Cron configurado para automatización
- [ ] Sistema de alertas (Telegram, email) para errores
