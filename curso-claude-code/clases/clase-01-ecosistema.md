# Clase 01 — Ecosistema Anthropic & productos Claude

**Tags:** `Infraestructura` `Fundamentos`
**Conecta con:** Clase 02 · Clase 04

---

## Idea central

Claude Code es la evolución natural del ecosistema Anthropic: primero existía para developers, luego lo re-empaquetaron como Cowork para usuarios administrativos. El poder real está en Code porque combina edición de archivos + ejecución de código en lenguaje natural.

---

## Los 4 productos principales

| Producto | Para qué sirve |
|----------|---------------|
| **Claude Chat** | Chatbot conversacional (equivalente a ChatGPT) |
| **Claude Design** | Interfaces, landing pages, estructuras HTML |
| **Claude Cowork** | Mover y editar archivos en una carpeta (uso administrativo) |
| **Claude Code** | Editar archivos + correr código en terminal ← **foco del curso** |

---

---

## Conceptos clave

- Claude Code tiene **acceso directo a carpetas del computador**
- Ejecuta cosas a **nivel de terminal**
- Crea código **y** edita los archivos = aplicaciones funcionales completas
- Todo en **lenguaje natural**

---

## ⚠️ Error común

No confundir **Cowork** (mueve archivos, sin terminal) con **Code** (tiene terminal completa). Son productos distintos con capacidades muy diferentes.
