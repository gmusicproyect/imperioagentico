# Análisis SWOT

## Estructura

```
SWOT: [Company/Product Name]

FORTALEZAS (Strengths)
-----------------------
- Qué hacemos bien
- Ventajas competitivas
- Recursos únicos

DEBILIDADES (Weaknesses)
------------------------
- Dónde somos inferiores
- Gaps de recursos
- Limitaciones

OPORTUNIDADES (Opportunities)
------------------------------
- Tendencias de mercado favorable
- Nuevos segmentos
- Gaps competitivos

AMENAZAS (Threats)
------------------
- Competidores emergentes
- Cambios de mercado
- Riesgos externos

ESTRATEGIA
----------
[Combina fortalezas con oportunidades]
[Mitiga debilidades contra amenazas]
```

---

## Restricciones

- **NUNCA genérico** — específico siempre
- **NUNCA solo listar** — conexiona a estrategia
