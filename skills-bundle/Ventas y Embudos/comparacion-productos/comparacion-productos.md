# Constructor de Comparativa de Producto

## Cuándo Usar Este Skill

- Usuario quiere página "vs" landing pages
- Usuario necesita comparar su producto contra competidores
- Usuario necesita matriz de comparación

## Estructura

```
[Tu Producto] vs [Competidor]

QUÉ RECIBES CON [TU PRODUCTO]
- Feature 1
- Feature 2
- Feature 3
- Feature 4
- Feature 5

NO RECIBES
- Feature A (mejor en competitor)

PRECIO: $[X]/mes

MEJOR PARA: [Tipo específico de cliente]
```

## Ejemplo

```
AI Email Writer para Creadores vs ConvertKit

FEATURE MATRIX
==============

                    Tu Producto    ConvertKit    Mailchimp
Automated sequences     ✓              ✓             ✓
AI-powered copy         ✓              ✗             ✗
Subject line A/B test   ✓              ✗             ✓
Creator community       ✓              ✓             ✗
Affordable pricing      ✓              ✗             ✓

PRICING
-------
Tu Producto: $29/mes
ConvertKit: $29/mes (pero menos features)
Mailchimp: $0-350/mes (overkill para creadores)

VEREDICTO
---------
Elige tu producto si: Eres creador, necesitas automatización, quieres AI writing
Elige ConvertKit si: Te importa la comunidad de creadores, presupuesto mayor
Elige Mailchimp si: Necesitas marketing automation completa para equipo
```

## Restricciones

- **NUNCA injusto** — sé honesto sobre fortalezas de competidores
- **NUNCA genérico** — específico sobre qué competidor
- **NUNCA con datos falsos** — verifica pricing y features
