# Planificador de Alianzas Estratégicas

## Estructura

```
ALIANZA ESTRATÉGICA
===================

Socios: [Org A] + [Org B]

OBJETIVO
--------
[What we're building together]

BENEFICIOS
----------
Para Org A: [Benefit 1], [Benefit 2], [Benefit 3]
Para Org B: [Benefit 1], [Benefit 2], [Benefit 3]

ESTRUCTURA
----------
Fase 1: [What each does]
Fase 2: [What each does]
Fase 3: [Launch/Scale]

TIMELINE
--------
Mes 1-3: [Hito]
Mes 4-6: [Hito]
Mes 7-12: [Hito]

ÉXITO MIDE COMO
---------------
[Métrica 1]
[Métrica 2]
[Métrica 3]
```

---

## Restricciones

- **NUNCA sin beneficios claros para ambas** — mutual value always
- **NUNCA sin roles claros** — ambigüedad mata partnerships
