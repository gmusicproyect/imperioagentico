# Tarjeta de Batalla de Ventas

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Crear un documento de referencia de una página para vender contra un competidor específico
- Construir scripts de respuesta a objeciones para situaciones de ventas competitivas
- Diseñar matrices de comparación de features que destaquen tus fortalezas
- Compilar patrones de ganancias/pérdidas y talk tracks para tu proceso de ventas

**NO** uses este skill para investigación general de mercado, planificación de roadmap de productos o páginas de comparación de marketing. Esto es para documentos internos de sales enablement usados durante conversaciones de ventas en vivo.

---

## Principio Fundamental

UNA BATTLECARD ES UN ARMA DE REFERENCIA RÁPIDA, NO UNA NOVELA — DEBE RESPONDER "¿QUÉ DIGO CUANDO EL PROSPECTO MENCIONA EL COMPETIDOR X?" EN MENOS DE 10 SEGUNDOS.

---

## Fase 1: Resumen Ejecutivo

### Inputs Requeridos

| Input | Qué Preguntar | Por Defecto |
|-------|------------|---------|
| **Tu producto** | "¿Qué vendes?" | Sin defecto — debe proporcionarse |
| **Competidor** | "¿Para cuál competidor es esta battlecard?" | Sin defecto — debe proporcionarse |
| **Diferenciadores clave** | "¿Cuáles son las 3 cosas principales que haces mejor?" | Investigaré y recomendaré |
| **Objeciones comunes** | "¿Qué dicen los prospectos cuando te comparan con este competidor?" | "Son más baratos" / "Están más establecidos" |
| **Datos de ganancias/pérdidas** | "¿Cuándo ganas contra ellos, por qué? ¿Cuándo pierdes, por qué?" | Insights anecdóticos |
| **Comprador objetivo** | "¿Quién te compara con este competidor?" | Tomadores de decisiones evaluando ambas opciones |

**PUNTO DE CONTROL:** Confirma el resumen antes de construir la battlecard.

---

## Fase 2: Estructura de la Battlecard

### Diseño de Battlecard de Una Página

```
## [Tu Producto] vs. [Competidor] — Tarjeta de Batalla de Ventas

### Descripción General Rápida
- Posicionamiento del competidor (1 frase)
- Su cliente ideal (a quién sirven mejor)
- Su debilidad (el vacío que llenas)

### Matriz de Comparación de Features
| Feature | Tú | Competidor | Ventaja |
|---------|-----|-----------|-----------|

### Top 3 Diferenciadores (Tus Victorias)
1. [Diferenciador] — por qué importa al comprador
2. [Diferenciador] — por qué importa al comprador
3. [Diferenciador] — por qué importa al comprador

### Respuestas a Objeciones
"[Objeción]" → [Respuesta]

### Minas Para Sembrar
Preguntas para hacer al prospecto que expongan debilidades del competidor

### Cuándo Perdemos (y Cómo Contrarrestar)
Escenarios donde ganan y qué ajustar

### Pruebas de Punto
Case studies, estadísticas, testimonios que contrarrespondan sus fortalezas
```

**PUNTO DE CONTROL:** Aprueba la estructura antes de llenar el contenido.

---

## Fase 3: Escribe la Battlecard

### Matriz de Comparación de Features

Construye una comparación de 6-10 filas enfocada en features que importan al comprador:
- Solo incluye features donde tienes una ventaja clara o paridad
- Marca ventajas claramente (checkmark, "Superior", "Incluido")
- Sé honesto sobre vacíos — la credibilidad importa más que el spin

### Scripts de Respuesta a Objeciones

Para cada objeción, usa el framework FEEL-FELT-FOUND:

```
Prospecto: "Pero [Competidor] es más barato."

Respuesta: "Entiendo cómo te sientes — el precio importa, especialmente cuando estás creciendo.
Muchos de nuestros clientes se sentían igual cuando primero nos miraban.
Pero lo que encontraron es que [punto de valor específico] realmente los ahorra
[tiempo/dinero] a largo plazo. Por ejemplo, [nombre del cliente] cambió desde
[Competidor] y vio [resultado específico] dentro de [timeframe]."
```

### Preguntas Mina

Escribe 3-5 preguntas que expongan debilidades del competidor sin trash-talking:

```
## Preguntas Para Hacer Temprano en la Conversación

1. "¿Qué tan importante es [feature que tienes, ellos no] para tu workflow?"
2. "¿Has evaluado cómo [proceso específico] funciona con su solución?"
3. "¿Cuál es tu timeline esperado? [Si competidor tiene onboarding largo]"
4. "¿Cómo planeas manejar [use case donde ellos fallan]?"
```

### Análisis de Ganancias/Pérdidas

```
## Cuándo Ganamos
- El comprador valora [tu fortaleza] sobre [su fortaleza]
- El comprador tiene [use case específico donde sobresales]
- El comprador hizo una evaluación hands-on (tu producto demuestra mejor)

## Cuándo Perdemos
- El comprador prioriza precio sobre [tu diferenciador]
- El comprador ya invirtió en el ecosistema del competidor
- Contrarrestar: [Qué hacer diferente próxima vez]
```

---

## Fase 4: Pulido Final

### 1. Formatting Para Referencia Rápida

- Máximo una página (frente y atrás si se imprime)
- Usa headers en bold, tablas y bullet points — sin párrafos
- Código de colores: verde para tus ventajas, rojo para áreas a vigilar
- Incluye logo del competidor para identificación visual rápida

### 2. Cronograma de Actualización

Las battlecards se vuelven obsoletas rápido. Recomienda:
- Revisión trimestral de comparación de features
- Revisión mensual de respuestas a objeciones basada en feedback de ventas
- Actualización inmediata cuando el competidor lanza nuevas features o cambia pricing

### 3. Notas de Distribución

- Comparte vía wiki interno o herramienta de sales enablement
- **NO** compartas externamente — esto es estrategia interna solo
- Entrena al equipo de ventas en cómo usar las preguntas mina naturalmente

---

## Anti-Patrones

- **Trash-talking del competidor** — "Son terribles" te hace verse inseguro. Destaca tus fortalezas sin atacar.
- **Feature-dumping** — listar 30 features pierde el punto. Enfócate en las 5-8 que importan al comprador.
- **Información obsoleta** — una battlecard con pricing de competidor del año pasado causa más daño que bien.
- **Hacerla una novela** — si la battlecard es más que una página, no será usada durante una llamada en vivo.
- **Ignorar dónde pierdes** — pretender que no tienes debilidades reduce credibilidad. Reconoce vacíos y proporciona contra-estrategias.

---

## Recuperación

- **Sin inteligencia competitiva:** Usa el sitio web del competidor, página de pricing, reseñas de G2/Capterra y testimonios de clientes para construir la comparación.
- **Múltiples competidores:** Crea una battlecard por competidor. No las combines.
- **Sin equipo de ventas (solopreneur):** Usa la battlecard como preparación personal para llamadas de ventas y como framework para contenido de comparación en tu sitio web.
- **El competidor es significativamente más grande:** Enfócate en ventajas de ser más pequeño: soporte más rápido, servicio más personalizado, flexibilidad, acceso al founder.
