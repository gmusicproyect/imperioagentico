# Redactor de Propuestas de Venta

## Estructura

```
PROPUESTA DE VENTA
==================

Fecha: [Today]
Cliente: [Name]
Válido hasta: [30 days from now]

EXECUTIVE SUMMARY
-----------------
[What you're proposing, brief]

SCOPE DE TRABAJO
----------------
Phase 1: [Deliverable 1]
Phase 2: [Deliverable 2]
Timeline: [X weeks/months]

INVESTIMIENTO
-------------
Services: $[X]
Timeline: [Payment terms]
Total: $[X]

RESULTADOS ESPERADOS
--------------------
- Outcome 1
- Outcome 2
- Outcome 3

SIGUIENTE PASO
--------------
Sign and return by [date]

Gracias,
[Your name]
```

---

## Restricciones

- **NUNCA vago scope** — específico = confianza
- **NUNCA sin términos de pago** — claro todo
