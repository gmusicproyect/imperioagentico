# Lienzo de Propuesta de Valor

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Mapear tu propuesta de valor contra segmentos específicos de clientes
- Identificar trabajos, dolores y ganancias del cliente para informar decisiones de producto y messaging
- Alinear tus features de producto con lo que realmente importa a los clientes
- Articular por qué tu oferta es la mejor solución para una audiencia específica

**NO** uses este skill para análisis competitivo, estrategia de pricing o trabajo de identidad de marca. Esto es para mapeo estructurado de propuesta de valor usando el framework del canvas.

---

## Principio Fundamental

TU PROPUESTA DE VALOR NO ES LO QUE CREES QUE TU PRODUCTO HACE — ES EL SOLAPAMIENTO ENTRE LO QUE TU CLIENTE NECESITA Y LO QUE ENTREGA ÚNICAMENTE TÚ. EL CANVAS REVELA ESE SOLAPAMIENTO.

---

## Fase 1: Resumen Ejecutivo

### Inputs Requeridos

| Input | Qué Preguntar | Por Defecto |
|-------|------------|---------|
| **Producto/servicio** | "¿Qué ofreces?" | Sin defecto — debe proporcionarse |
| **Cliente objetivo** | "¿Para quién es esto? Sé específico." | Sin defecto — debe proporcionarse |
| **Messaging actual** | "¿Cómo describes actualmente tu producto?" | Lo que compartan |
| **Investigación de clientes** | "¿Has hablado con clientes? ¿Qué dicen?" | Limitada o anecdótica |
| **Competidores** | "¿Quién más resuelve este problema?" | Conocimiento general |

**PUNTO DE CONTROL:** Confirma inputs antes de construir el canvas.

---

## Fase 2: Perfil de Cliente (Lado Derecho del Canvas)

### Trabajos del Cliente

Identifica lo que el cliente está intentando lograr:

```
## Trabajos del Cliente

**Trabajos Funcionales (tareas que necesitan completar):**
1. [Trabajo 1 — ej., "Enviar facturas profesionales a clientes"]
2. [Trabajo 2 — ej., "Rastrear qué facturas están pagadas y vencidas"]
3. [Trabajo 3 — ej., "Manejar flujo de caja entre múltiples clientes"]

**Trabajos Sociales (cómo quieren ser percibidos):**
1. [Trabajo — ej., "Verse profesional y establecido ante clientes"]
2. [Trabajo — ej., "Ser visto como organizado y en control de finanzas"]

**Trabajos Emocionales (cómo quieren sentirse):**
1. [Trabajo — ej., "Sentirse confiado sobre finanzas empresariales"]
2. [Trabajo — ej., "Reducir estrés alrededor de cobrar"]
```

### Dolores del Cliente

```
## Dolores del Cliente

**Frustraciones:**
1. [Dolor — ej., "Crear facturas desde cero toma mucho tiempo"]
2. [Dolor — ej., "Perseguir pagos atrasados es incómodo y toma tiempo"]

**Riesgos/Miedos:**
1. [Dolor — ej., "Preocupado de verse poco profesional"]
2. [Dolor — ej., "Miedo a que gaps de flujo de caja hundan el negocio"]

**Obstáculos:**
1. [Dolor — ej., "No sé qué incluir en una factura"]
2. [Dolor — ej., "Sin sistema para rastrear quién debe qué"]
```

### Ganancias del Cliente

```
## Ganancias del Cliente

**Ganancias Requeridas (must-haves):**
1. [Ganancia — ej., "Facturas enviadas y pagadas confiablemente"]

**Ganancias Esperadas (expectativas estándar):**
1. [Ganancia — ej., "Facturas con aspecto profesional"]
2. [Ganancia — ej., "Rastreo fácil del estado de pago"]

**Ganancias Deseadas (les encantaría tener):**
1. [Ganancia — ej., "Recordatorios de pago automáticos"]
2. [Ganancia — ej., "Creación de factura de un clic"]

**Ganancias Inesperadas (wow factors):**
1. [Ganancia — ej., "Forecasting de flujo de caja basado en datos de factura"]
```

**PUNTO DE CONTROL:** Revisa el perfil del cliente antes de mapear el lado de valor.

## Fase 3: Mapa de Valor (Lado Izquierdo del Canvas)

### Productos y Servicios

Lista lo que ofreces que aborda los trabajos del cliente.

### Aliviadores de Dolor

Para cada dolor del cliente, muestra qué feature o aspecto de tu producto lo alivia.

### Creadores de Ganancia

Para cada ganancia del cliente, muestra cómo tu producto la crea o amplifica.

### Análisis de Fit

```
## Fit de Propuesta de Valor

| Dolor/Ganancia del Cliente | Tu Solución | Fuerza de Fit |
|--------------------|---------------|-------------|
| [Dolor 1] | [Feature/beneficio] | Fuerte / Moderado / Débil |
| [Dolor 2] | [Feature/beneficio] | Fuerte / Moderado / Débil |
| [Ganancia 1] | [Feature/beneficio] | Fuerte / Moderado / Débil |
```

Destaca:
- **Fits fuertes** — estos son tus core selling points
- **Fits débiles** — gaps a resolver en desarrollo o reconocer en messaging
- **Trabajos/dolores sin atender** — oportunidades o límites a comunicar

---

## Fase 4: Pulido Final

### 1. Declaración de Propuesta de Valor

Destila el canvas en una sola declaración:

```
Para [cliente objetivo] quien [trabajo a realizar],
[nombre del producto] es el [categoría] que [beneficio clave].
A diferencia de [alternativa], nosotros [diferenciador clave].
```

### 2. Jerarquía de Messaging

Rankea los elementos de propuesta de valor por importancia:
1. Mensaje principal (el dolor #1 que alivias)
2. Mensajes secundarios (2-3 ganancias que soportan)
3. Pruebas para cada mensaje

### 3. Guía de Aplicación

Muestra cómo usar la salida del canvas para:
- Titulares y copy de sales page
- Messaging y targeting de ads
- Prioridades de desarrollo de producto
- Scripts de servicio al cliente

---

## Anti-Patrones

- **Listar features en lugar de trabajos** — "Tenemos un dashboard" es un feature. "Rastrear todas las facturas en un lugar" es un trabajo.
- **Adivinar dolores del cliente** — si no has hablado con clientes reales, el canvas es ficción. Básalo en investigación.
- **Intentar fit todo** — no puedes aliviar cada dolor y crear cada ganancia. Enfócate en los fits más fuertes.
- **Un canvas para múltiples segmentos** — diferentes segmentos de cliente tienen diferentes trabajos, dolores y ganancias. Crea un canvas separado por segmento.
- **Nunca actualizar el canvas** — las necesidades del cliente evolucionan. Revisita trimestralmente.

---

## Recuperación

- **Sin investigación de clientes:** Recomienda 5 entrevistas cortas con clientes existentes o potenciales. Proporciona preguntas de entrevista para usar.
- **Muchos segmentos de cliente:** Comienza con el segmento de mayor valor o más grande. Completa un canvas totalmente antes de comenzar otro.
- **Fit débil en todo:** Esto es insight valioso — puede significar que el producto necesita reposicionamiento o el cliente objetivo necesita cambiar.
- **Usuario no puede articular su diferenciador:** Usa el canvas para encontrarlo. El solapamiento entre necesidades del cliente y lo que los competidores pierden es el diferenciador.
