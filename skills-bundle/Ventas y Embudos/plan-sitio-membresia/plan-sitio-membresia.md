# Planificador de Sitio de Membresía

## Cuándo Usar Este Skill

- Usuario tiene contenido/conocimiento que vende como membresía
- Usuario quiere ingresos recurrentes de una comunidad
- Usuario dice "cómo hago un sitio de miembros"

## Principio Fundamental

UNA MEMBRESÍA EXITOSA NO ES SOBRE EL CONTENIDO. ES SOBRE LA RETENCIÓN. Si nadie se queda, no es negocio.

## Estructura

### 1. Tipo de Membresía

| Tipo | Precio | Contenido | Retención Típica |
|------|--------|-----------|-----------------|
| **Content Library** | $29-99 | Cursos, plantillas, guides | 60% |
| **Community** | $49-199 | Slack/forum, acceso grupo | 70% |
| **Coaching Access** | $199-999 | Group/1:1 calls, contenido | 80% |
| **Hybrid** | $99-299 | Contenido + comunidad + calls | 75% |

### 2. Estructura de Contenido

```
ÁREA DE MIEMBROS
================

Dashboard
- Progress tracker
- Recent updates
- Recommended next lesson

Courses (3-5 main)
- Module structure
- Videos + downloadables
- Action items per module

Library (Bonus)
- Templates
- Swipe files
- Tools/resources

Community
- Forum / discussions
- Member directory
- Live calls calendar

Your Profile
- Settings
- Billing
- Download receipts
```

### 3. Pricing

```
PRICING STRUCTURE
=================

Monthly: $[X]
- Best for quick consumption
- Higher churn

Annual: $[X] (2 meses free vs monthly)
- Incentivizes commitment
- Lower churn

Lifetime: $[X] (one-time)
- Large payment upfront
- Eliminates churn (once paid)
- But less sustainable cash flow
```

### 4. Retención

**Día 1 (Onboarding)**
- Welcome email
- "Start here" path
- First win milestone

**Semana 1**
- Completion reminder
- Community introduction
- First live call

**Mes 1**
- Progress check-in
- Testimonial request
- Introduce community feature

**Mes 2**
- New content/module launched
- Monthly theme or challenge
- Upsell opportunity

**Mes 3**
- Celebrate wins / ask for testimonial
- "Why some members leave" save-sequence
- Referral program

## Ejemplo: Community de Email Marketing

```
MEMBRESÍA: Email Marketing Insider
===================================

PRECIO
------
$79/mes or $690/año (save $258)
Lifetime: $990

CONTENIDO
---------

Courses (updated monthly):
- Advanced Gmail sequences
- List building secrets
- Automation frameworks

Library (100+ assets):
- 50 email templates
- Copy swipes
- Design templates
- Zapier workflows

Community:
- Discord server
- Member intros
- Weekly challenges
- Monthly live group call

Your Account:
- Progress tracker
- Certifications
- Download limits

RETENCIÓN PLAN
--------------

Day 1: Welcome email, "3-day quick start" path
Week 1: Email about most-accessed lesson, community intro
Week 2: Live group call (bonus content + face time)
Week 3: Challenge announcement ("Write your best email sequence")
Week 4: Celebrate completions, ask for testimonial
Month 2: New module drops + bonus training
Month 3: Referral program launch (refer friend = $40 credit)
```

## Restricciones

- **NUNCA cree membresía sin demo/beta** — prueba retención primero
- **NUNCA cobres por contenido pasivo sin comunidad** — comunidad = retención
- **SIEMPRE plan retención desde día 1** — inicio fuerte = menos churn
- **NUNCA sobreprices** — membresía < $99/mes debería ser accesible
