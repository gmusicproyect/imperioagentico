# Plantillas de Emails de Ventas

## Estructura Base

```
ASUNTO: [Specificidad + curiosidad / valor]

CUERPO:
[Personalization]
[Hook/Problem]
[Solution]
[Outcome]
[CTA]

FIRMA
```

## Plantillas Probadas

### Plantilla 1: Apertura Fría

```
ASUNTO: Quick question for you, [Name]

Hi [Name],

I was reviewing [specific insight about their business]
and noticed [opportunity/problem].

Most [their role] we talk to struggle with [specific pain].

We help [similar companies] solve this in [timeframe].

Worth a quick chat? Reply with "demo" and let's talk.

[Your name]
```

### Plantilla 2: Follow-up

```
ASUNTO: Following up on my last email

Hi [Name],

Haven't heard back, so either:
1. You missed it (totally get it, inbox is crazy)
2. It's not urgent right now (completely understand)
3. You're not interested (all good)

If 1 or 2, I'd love to chat briefly. Reply with "call" and
we can jump on for 15 minutes next Thursday.

[Your name]
```

---

## Restricciones

- **NUNCA genérico** — personalizado siempre
- **NUNCA largo subject** — máx 60 chars
