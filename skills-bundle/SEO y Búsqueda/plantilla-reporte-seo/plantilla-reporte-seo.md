# Plantilla de Reporte de SEO

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Crear un reporte de SEO mensual o trimestral
- Rastrear progreso de palabras clave objetivo
- Demostrar ROI de esfuerzos de SEO
- Comunicar resultados a clientes o stakeholders

---

## Secciones Clave del Reporte

### 1. Resumen Ejecutivo

```
## Resumen Ejecutivo

**Período:** [Mes/Trimestre]
**Tráfico Orgánico:** [Mes actual] vs [Mes anterior] — [+/- X%]
**Keywords Rankeadas (Top 10):** [número]
**Nuevos Rankings:** [número]
**Traffic del Objetivo:** [% del tráfico total que viene de SEO]
```

### 2. Tracking de Palabras Clave

```
## Performance de Palabras Clave Objetivo

| Palabra Clave | Ranking Anterior | Ranking Actual | Volumen/mes | Tráfico |
|---|---|---|---|---|
| [KW1] | #8 | #4 | 1,200 | 87 |
| [KW2] | #15 | #9 | 800 | 45 |
| [KW3] | Nuevo ranking | #12 | 600 | 28 |
```

### 3. Métricas de Tráfico

```
## Tráfico Orgánico

- Sesiones totales: [número]
- Usuarios únicos: [número]
- Páginas por sesión: [número]
- Duración promedio de sesión: [minutos]
- Tasa de rebote: [%]
- Conversiones orgánicas: [número]
- Valor de conversión: [cantidad]
```

### 4. Hallazgos y Recomendaciones

```
## Principales Hallazgos

**Lo que está funcionando:**
- [Página de alto rendimiento]
- [Palabra clave que sube]
- [Tipo de contenido que convierte]

**Áreas de oportunidad:**
- [Palabras clave sin tráfico]
- [Páginas con bajo CTR]
- [Contenido que podría expandirse]

**Recomendaciones para próximo mes:**
1. [Acción específica]
2. [Acción específica]
3. [Acción específica]
```

### 5. Acciones Completadas

```
## Acciones Completadas Este Mes

- [ ] Publicado [X] posts de blog
- [ ] Optimizado [X] páginas existentes
- [ ] Construidos [X] backlinks
- [ ] Implementado schema markup en [X] páginas
- [ ] Mejorado velocidad de página a [X] segundos
```

---

## Métricas Clave a Rastrear

- **Organic Traffic:** Sesiones totales de búsqueda orgánica
- **Keyword Rankings:** Posición en SERP para palabras clave objetivo
- **Click-Through Rate:** Clics / impresiones en Google Search Console
- **Conversions:** Leads, ventas o acciones deseadas desde tráfico orgánico
- **Pages Per Session:** Profundidad del engagement
- **Backlinks:** Dominios refirientes, autoridad de liens

---

## Formato de Entrega

- Reporte mensual (para sitios activos en SEO)
- Reporte trimestral (para cambios más lentos de SEO)
- Reporte de dashboard (Google Data Studio, Looker Studio)
- PDF imprimible para presentaciones
