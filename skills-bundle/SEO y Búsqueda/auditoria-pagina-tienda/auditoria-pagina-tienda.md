# Auditoría de Página de Tienda

## Cuándo Usar Este Skill

Usa este skill cuando:
- Tu tienda tiene bajo volumen de tráfico
- Las páginas de producto tienen baja tasa de conversión
- Necesites optimizar para búsqueda orgánica
- Quieras identificar por qué los competidores rankean mejor

---

## Principio Fundamental

UNA PÁGINA DE TIENDA DEBE CUMPLIR DOS OBJETIVOS: RANKEAR PARA PALABRAS CLAVE RELEVANTES Y CONVERTIR VISITANTES EN CLIENTES.

---

## Áreas de Auditoría

### 1. SEO On-Page

- [ ] Title tag incluye palabra clave primaria
- [ ] Meta descripción tiene 150-160 caracteres
- [ ] H1 contiene palabra clave
- [ ] Alt text en todas las imágenes
- [ ] Contenido: mínimo 300 palabras de descripción

### 2. Optimización de Conversión

- [ ] Precio visible above-the-fold
- [ ] Botón "Add to Cart" / "Buy Now" prominente
- [ ] Opiniones/calificaciones visibles
- [ ] Política de devolución clara
- [ ] Indicadores de confianza (SSL, certificaciones)

### 3. Imágenes

- [ ] Imagen principal de alta resolución
- [ ] Múltiples vistas del producto
- [ ] Zoom de imagen disponible
- [ ] Fotos de estilo de vida o en contexto
- [ ] Peso optimizado (< 100KB por imagen)

### 4. Contenido de Producto

- [ ] Título es descriptivo y contiene palabra clave
- [ ] Descripción corta (1 párrafo, 50-100 palabras)
- [ ] Descripción larga (200-400 palabras con beneficios)
- [ ] Especificaciones completas (talla, color, material, etc.)
- [ ] Instrucciones o Preguntas Frecuentes

### 5. Reseñas

- [ ] Al menos 5+ reseñas visibles
- [ ] Calificación promedio mostrada
- [ ] Fotos/videos de clientes
- [ ] Fecha de reseña visible

---

## Cómo Rankear Mejor

1. **Target long-tail keywords** — "[marca] [producto] para [use case]"
2. **Escribir contenido único** — el fabricante proporciona, pero tú enfócate en beneficios
3. **Optimizar para search intent** — si buscan "[producto] review", muestra reseñas prominentemente
4. **Mejorar velocidad de página** — imágenes optimizadas, minify CSS/JS
5. **Construir enlaces** — obtén menciones de blogs relevantes, reviews de productos

## Anti-Patrones

- **Copiar descripción del fabricante completamente** — Google penaliza contenido duplicado
- **Omitir especificaciones** — "¿Cuál es el tamaño?" sin respuesta = usuario se va
- **Solo una imagen de producto** — múltiples vistas construyen confianza y ayudan conversión
- **Sin reseñas** — las reseñas mejoran CTR en SERP y conversión en página

---

## Recuperación

- **Bajo tráfico a pesar de optimización:** El problema es probablemente backlinks o Domain Authority. Ejecuta link building.
- **Tráfico pero baja conversión:** Problema es página, no SEO. Testea título diferente, imagen, o precio.
- **Producto nuevo sin reseñas:** Incentiva primeros clientes a dejar reseñas. Las reseñas iniciales son el bottleneck más común.
