# Optimizador de Listado de Producto

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Optimizar un listado de producto existente para mayores tasas de conversión
- Escribir un nuevo listado de producto desde cero para Amazon, Shopify, Etsy u otras plataformas
- Mejorar SEO y descubribilidad de páginas de producto
- Auditar un listado de producto contra mejores prácticas de plataforma

**NO** uses este skill para fotografía de producto, campañas publicitarias o estrategia de SEO de tienda completa. Esto es para copy y optimización de listado de producto individual.

---

## Principio Fundamental

UN LISTADO DE PRODUCTO DEBE RESPONDER CADA PREGUNTA QUE UN COMPRADOR TIENE ANTES DE QUE HAGA CLIC EN "AGREGAR AL CARRITO" — LA INFORMACIÓN FALTANTE MATA CONVERSIONES.

## Fase 1: Briefing

### Información Requerida

| Input | Qué Preguntar | Por Defecto |
|-------|------------|---------|
| **Producto** | "¿Qué producto estás listando?" | Debe proporcionarse |
| **Plataforma** | "¿Dónde está listado? (Amazon, Shopify, Etsy, Walmart, otro)" | Amazon |
| **Palabras clave objetivo** | "¿Para qué términos de búsqueda debería rankear este producto?" | Investigaré |
| **Listado actual** | "Comparte la URL de listado existente o copy." | Comenzando nuevo |
| **Puntos de venta únicos** | "¿Qué hace este producto diferente de competidores?" | Debe proporcionarse |
| **Comprador objetivo** | "¿Quién es tu comprador ideal? ¿Qué problema esto resuelve para ellos?" | Debe proporcionarse |
| **Punto de precio** | "¿Cuál es el precio de venta?" | Debe proporcionarse |

**PUNTO DE CONTROL: Confirma briefing antes de optimizar.**

---

## Fase 2: Auditoría (si existe listado)

### Scorecard de Listado

Evalúa el listado actual en:
- **Optimización de título** — palabras clave, conteo de caracteres, legibilidad (calificación 1-10)
- **Bullet points** — impulsados por beneficio, escaneable, información completa (calificación 1-10)
- **Descripción** — convincente, rica en palabras clave, responde objeciones (calificación 1-10)
- **Imágenes** — calidad de imagen principal, imágenes de estilo de vida, infografías (calificación 1-10)
- **Palabras clave de backend** — cobertura de términos de búsqueda, sin duplicación (calificación 1-10)

Para listados nuevos, salta a Fase 3.

**PUNTO DE CONTROL: Presenta scorecard de auditoría y confirma prioridades de optimización.**

---

## Fase 3: Optimizar

### Reglas Específicas de Plataforma

**Amazon:**
- Título: 150-200 caracteres, palabra clave primaria primero, Marca + Producto + Característica Clave + Tamaño/Variante
- Bullets: 5 bullets, comienza cada uno con frase de BENEFICIO en MAYÚSCULAS, máximo 200 caracteres cada uno
- Descripción: Usa A+ Content si Marca Registrada, de lo contrario descripción de 2,000 caracteres
- Palabras clave de backend: Máximo 250 bytes, sin puntuación, sin palabras repetidas del título

**Shopify:**
- Título: Claro y descriptivo, máximo 70 caracteres para SEO
- Descripción: Formateada en HTML con encabezados, beneficios, specs y contexto de estilo de vida
- Meta descripción: 155 caracteres con palabra clave primaria
- Tags: 10-15 tags relevantes para búsqueda interna y colecciones

### Entregables

**1. Título de Producto Optimizado**
- Palabra clave primaria integrada naturalmente
- Diferenciadoresizadores clave visibles
- Límites de caracteres de plataforma respetados

**2. Bullet Points / Características Clave**
- 5 bullets impulsados por beneficio (Amazon) o lista de características (Shopify)
- Cada bullet: declaración de beneficio → característica de apoyo → detalle específico
- Aborda principales preocupaciones y objeciones de comprador

**3. Descripción de Producto**
- Párrafo introductorio: hook emocional conectando al problema del comprador
- Medio: características con beneficios, especificaciones, casos de uso
- Cierre: constructor de confianza (garantía, promesa, aseguranza de calidad)

**4. Palabras Clave de Backend / Tags SEO**
- Lista de palabras clave no ya en el título o bullets
- Variaciones long-tail y errores ortográficos (Amazon)
- Meta título y meta descripción (Shopify)

**5. Recomendaciones de Imagen**
- Requisitos de imagen principal por plataforma
- Imágenes de estilo de vida y infografía sugeridas
- Alt text para cada slot de imagen

---

## Fase 4: Pulir

### Lista de Verificación de Conversión

- [ ] Título incluye palabra clave primaria
- [ ] Todos los 5 bullet points son benefit-first
- [ ] Descripción aborda al menos 3 objeciones comunes
- [ ] Specs son completos (dimensiones, peso, materiales, compatibilidad)
- [ ] Social proof referenciada (reseñas, premios, certificaciones)
- [ ] Call to action presente en descripción
- [ ] Palabras clave de backend no tienen superposición con copy visible
- [ ] Previsualización móvil revisada (¿cómo se ve en teléfono?)

### Monitoreo de Desempeño

Rastrea semanalmente por 30 días post-optimización:
- Impresiones, clics, tasa de conversión
- Cambios de ranking de palabra clave
- Sentimiento de reseña para quejas relacionadas con información nueva

---

## Anti-Patrones

- **Keyword stuffing** — títulos ilegibles atestados de palabras clave dañan conversión. Escribe para humanos primero, algoritmos segundo.
- **Bullets solo características** — "Made of stainless steel" es una característica. "Never rusts or stains — looks brand new for years" es un beneficio. Lidera con beneficios.
- **Especificaciones faltantes** — "¿Will this fit my XYZ?" Si el listado no responde, el comprador se va. Incluye cada spec relevante.
- **Ignorar móvil** — 70%+ de compradores de Amazon navegan en móvil. Solo el título y primeros 3 bullets son visibles sin desplazamiento.
- **Copy-paste del fabricante** — descripciones genéricas del fabricante no venden. Reescribe con el lenguaje del comprador y sus preocupaciones.

---

## Recuperación

- **Sin datos de palabra clave:** Usa Amazon search autocomplete, sugerencias de búsqueda de Etsy o Google Keyword Planner gratis.
- **Producto sin diferenciador claro:** Enfócate en la experiencia de compra — garantía, servicio al cliente, envío rápido o extras incluidos.
- **Conversión de listado es baja a pesar de optimización:** El problema podría ser precio, imágenes o reseñas, no copy. Diagnostica qué elemento es el cuello de botella.
- **Plataforma rechazó el listado:** Revisa políticas de contenido específicas de plataforma. Problemas comunes: reclamaciones prohibidas, palabras clave restringidas o violaciones de formateo.
