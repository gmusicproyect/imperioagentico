# Secuencia Upsell

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Vender producto más alto a cliente existente
- Aumentar lifetime value
- Natural upgrade path

---

## Principio FUNDAMENTAL

UPSELL SOLO FUNCIONA CUANDO LA PERSONA PUEDE IMAGINAR MEJOR VERSIÓN DE SÍ MISMA PAGANDO.

---

## Trigger

- Después de compra inicial (24-48 horas)
- Cuando alcanza hito (100 usos, etc.)
- Post-review positivo
- Escalada natural (Lite → Pro → Premium)

---

## Structure

**Email 1:** Agradecimiento + tease de upgrade
**Email 2:** Mostrar diferencia clave
**Email 3:** Comparación directa
**Email 4:** Incentivo (descuento, bonus)
**Email 5:** Final push

---

## Copy Framework

**Email 1:**
```
Thank you for getting [starter product].

Now that you're using it, you might be ready for the next level.

Sneak peek: [Pro feature]
```

**Email 2:**
```
[Starter] is great for [use case].

But if you need [advanced use case], check out [Pro].

[Pro feature] changes everything.
```

**Email 3:**
```
Comparison:
Starter vs. Pro

[Table]

Which looks right for you?
```

**Email 4:**
```
Upgrade to Pro within 5 days and lock in $99/month (saves $20).

[Upgrade]
```

---

## Upsell Criteria

**Buena candidata para upsell:**
- Active user (not dormant)
- Positive about starter
- Growing need
- Budget likely (paid once)

**Mala candidata:**
- Inactive
- Free user (just testing)
- Complaining
- Churning risk

---

## Anti-Patrones

- **Upsell a inactivos** — wait until proven engaged
- **Immediately after signup** — let them enjoy starter
- **Discount heavy** — should sell on value, not price
- **Complicado upgrade** — máximo 2 clicks

---

## Métricas

- Objetivo: 10-20% upsell rate
- Median upgrade: 30-50% de aumentar
