# Secuencia Downsell

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Crear una oferta downsell para prospectos que rechacen tu producto primario
- Escribir copias de página downsell y secuencias de follow-up email
- Diseñar una escalera de producto que capture ingresos en múltiples puntos de precio
- Construir un downsell en un funnel de ventas existente o flujo de checkout

**NO** uses este skill para upsells (ofertas de mayor precio), order bumps, o promociones de descuento a clientes existentes. Esto es para ofertas downsell estructuradas después de que un prospecto dice no.

---

## Principio Fundamental

UN DOWNSELL NO ES UN DESCUENTO EN LA MISMA COSA — ES UNA OFERTA DIFERENTE A UN PUNTO DE PRECIO MENOR QUE TODAVÍA RESUELVE EL PROBLEMA DEL PROSPECTO, SOLO DE UNA MANERA MÁS PEQUEÑA.

## Fase 1: Resumen

### Entradas Requeridas

| Entrada | Qué Preguntar | Por Defecto |
|-------|------------|---------|
| **Oferta primaria** | "¿Qué rechazó el prospecto?" | Sin valor por defecto — debe ser proporcionado |
| **Precio primario** | "¿Cuál fue el precio para el cual dijeron no?" | Sin valor por defecto — debe ser proporcionado |
| **Razón del rechazo** | "¿Por qué la mayoría de la gente dice no? (precio, timing, confianza, ajuste)" | El precio es la objeción principal |
| **Producto existente de nivel inferior** | "¿Tienes una versión más pequeña de esta oferta?" | Diseñaré una |
| **Disparador de downsell** | "¿Dónde sucede el no? (salida de página de ventas, abandono de checkout, después del pitch)" | Salida de página de ventas o post-webinar |

**PUNTO DE CONTROL: Confirma el resumen antes de diseñar el downsell.**

---

## Fase 2: Diseño Downsell

### Tipos de Downsell

Elige la estructura downsell correcta:

**1. Versión Lite** — mismo producto, fewer features o módulos
- Curso completo ($497) → Módulos principales solo ($197)
- Mejor para: productos de información, cursos, membresías

**2. Plan de Pago** — mismo producto, extendido en el tiempo
- $497 de una sola vez → 3 pagos de $197
- Mejor para: objeción de precio con alto valor percibido

**3. Formato Diferente** — mismo conocimiento, entrega de menor costo
- Coaching grupal ($997) → Curso auto-dirigido ($297)
- Mejor para: negocios basados en servicio

**4. Starter/Essentials** — versión de nivel de entrada
- Toolkit completo ($197) → Pack starter ($47)
- Mejor para: productos digitales, plantillas, herramientas

### Reglas de Precio de Downsell

```
## Directrices de Precios

- El downsell debe ser 30-60% del precio de la oferta primaria
- Debe sentirse como un trato genuino, no un castigo por decir no
- Planes de pago: el total puede ser 10-20% más que el precio de una sola vez (prima de financiamiento)
- Nunca hagas downsell a menos de $17 — por debajo de eso, usa un tripwire en su lugar
```

**PUNTO DE CONTROL: Aprueba el concepto downsell antes de escribir copias.**

## Fase 3: Escribir Copia Downsell

### Estructura de Página Downsell

1. **Encabezado** — reconoce su decisión, presenta la alternativa
2. **Párrafo de empatía** — "Entiendo, [oferta primaria] podría no ser lo correcto para ti ahora"
3. **Introduce el downsell** — aquí está lo que ESTÁ disponible a una inversión menor
4. **Qué está incluido** — lista de bullets clara
5. **Revelación de precio** — con anclaje al valor de oferta original
6. **CTA** — "Obtén [Producto Downsell] por $X"
7. **Enlace sin gracias** — siempre proporciona una forma de rechazar gracefully

### Reglas de Copia

- Nunca culpabilices o presiones — el prospecto ya dijo no una vez
- Enmarca como una alternativa genuina, no una versión inferior
- Lidera con lo que OBTIENEN, no lo que se elimina
- Mantén la página a 200-400 palabras — si rechazaron una página de ventas larga, una más corta convierte mejor

## Fase 4: Downsell Email Sequence

### Email 1: Introducción Downsell (inmediato, en página o después de clic)

```
Asunto: espera — tengo otra opción para ti

Hola [Nombre],

Vi que [principal offer] podría no ser lo correcto para ti ahora. Totalmente entiendo — el investimiento o timing podría estar apagado.

Aquí hay lo que SÍ tenemos disponible: [Downsell product name] por $[X].

Obtiene [3 beneficios clave] sin el costo completo de la versión full.

¿Interesado? [CTA]

Si no, sin resentimientos. [No thanks link]

— [Tu nombre]
```

### Email 2: Seguimiento (24 horas después)

```
Asunto: re: la opción menos costosa

Hola [Nombre],

Una cosa rápida — si el precio era la preocupación, [Downsell product] obtiene varias de las características principales de [Primary offer] sin romperte el banco.

[Brief value statement]

¿Quieres echarle un vistazo? [CTA]

— [Tu nombre]
```

### Email 3: Final Follow-Up (72 horas después)

```
Asunto: tu acceso expira en 24 horas

Hola [Nombre],

Solo una última nota — tu descuento especial para [Downsell product] expira hoy.

Si quieres empezar: [CTA]

Si no es ahora, está bien — solo regresa cuando estés listo.

— [Tu nombre]
```

## Anti-Patrones

- **Hacer el downsell parecer como castigo** — "Ya que no compraste lo principal, aquí está la versión barata" suena resent ido.
- **Downsell que es solo un descuento** — "Paga 50% menos por exactamente lo mismo" no es downsell, es solo descuento.
- **Downsell más caro que la oferta primaria** — esto mata la credibilidad.
- **Sin razón clara para el downsell** — "Aquí está otro producto" confunde. Conecta a su objeción específica.
- **Demasiadas opciones de downsell** — 1 downsell claaro convierte mejor que 3 opciones.

---

## Recuperación

- **Prospecto dice no al downsell también:** No envíes un tercer email. Cierra gracefully y marca para futuro retargeting.
- **Downsell no convierte:** Verifica el precio. 30-40% del original es el sweet spot. Si es más bajo, se siente como castigo.
- **Falta claridad sobre qué está incluido:** Reescribe los bullets. El prospecto ya rechazó una venta pitch larga — sé super claro aquí.
- **Conversión alta en downsell pero bajo AOV:** Buena captura, pero ahora enfócate en upsells a estos clientes downsell.
