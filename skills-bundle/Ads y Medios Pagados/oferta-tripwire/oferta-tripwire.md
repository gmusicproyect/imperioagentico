# Oferta Tripwire

## Principio Fundamental

EL TRABAJO DEL TRIPWIRE NO ES GANANCIA — ES CAMBIAR A ALGUIEN DE LEAD A COMPRADOR, PORQUE LOS COMPRADORES SON 10X MÁS PROPENSOS A COMPRAR NUEVAMENTE QUE QUIENES NUNCA HAN COMPRADO.

---

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Diseñar oferta bajo-ticket ($7-$47) que convierta leads en compradores primerizos
- Crear copy de página de ventas y plan de entrega para producto tripwire
- Mapear el tripwire en escalera de productos más grande con rutas de upsell
- Definir psicología de precios que haga la oferta sentir como una ganga

**NO USES** para precios de oferta principal, lead magnets gratis, o páginas de ventas alto-ticket. Esto es específicamente para ofertas bajo-costo diseñadas para crear compradores.

---

## Fase 2: Diseño de Tripwire

### Concepto de Producto

El tripwire debe:
1. **Resolver un problema específico rápido** — no solución compreh ensiva
2. **Estar directamente relacionado a oferta principal** — compradores deben querer el producto más grande después
3. **Alto valor percibido, precio bajo** — debe sentirse como robo
4. **Entrega instantánea** — sin espera

### Framework de Tripwire

```
Nombre del producto: [Nombre que implica valor y velocidad]
Formato: [Paquete de plantillas / Mini-curso / Archivo swipe / Herramienta]
Precio: $[7-47]
Valor percibido: $[100-500]
Entrega: Descarga instantánea / acceso inmediato

La Victoria Rápida: ¿Qué resultado específico obtiene el comprador?
La Brecha: ¿Qué necesitarán a continuación? (lleva a oferta principal)
El Puente: ¿Cómo este producto lleva naturalmente a querer más?
```

### Posicionamiento en Escalera de Producto

```
Gratis: [Lead magnet] → $0
Tripwire: [Esta oferta] → $17
Principal: [Oferta principal] → $297
Premium: [Alto-ticket] → $997+
```

## Fase 3: Escribe Copy de Ventas

### Estructura de Página de Ventas Tripwire

1. **Headline** — establece la victoria rápida y precio
2. **Pain point** — 2-3 oraciones sobre el problema
3. **Intro de solución** — qué es el producto tripwire (1 párrafo)
4. **Qué está incluido** — lista de bullets con apilamiento de valor
5. **Anclaje de precio** — muestra valor percibido, revela precio bajo
6. **Botón CTA** — "Obtén Acceso Instantáneo por $17"
7. **Garantía** — 30 días reembolso, sin preguntas

### Reglas de Copy

- Mantén la página corta — 300-500 palabras. Ofertas bajo-ticket necesitan páginas bajo-fricción.
- Usa apilamiento de valor: lista cada componente con valor individual, luego total.
- El precio debe sentirse absurdo comparado al valor listado.
- Sin sales letter largo-forma. Esto no es página alto-ticket.
- Un botón CTA único, repetido dos veces.

---

## Anti-Patrones

- **Precio demasiado alto** — un producto de $97 no es tripwire. Mantén bajo $47.
- **No relacionado a oferta principal** — si el tema tripwire no tiene nada que ver con producto principal, los compradores no upgradearán.
- **Sobre-entregar** — si el tripwire resuelve el problema completo, no hay razón para comprar oferta principal.
- **Sin ruta de upsell** — un tripwire sin upsell es solo producto barato. El valor está en relación de comprador que crea.
- **Entrega compleja** — solo acceso inmediato. Si tienen que esperar email de login o contenido drip, la fricción mata experiencia.

---

## Recuperación

- **Sin oferta principal aún:** Diseña el tripwire como producto independiente y planifica la oferta principal. Pero advierte que un tripwire sin ruta de upsell limita valor estratégico.
- **Usuario quiere cobrar $97+:** Eso no es tripwire — es oferta principal. Recomienda extraer un componente para vender a $17-27 como verdadero tripwire.
- **Sin lead magnet existe:** Recomienda construir lead magnet primero. El flujo debe ser: contenido gratis → tripwire → oferta principal.
