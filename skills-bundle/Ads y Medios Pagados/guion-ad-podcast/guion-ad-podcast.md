# Guión de Ad de Podcast

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Escribir scripts de ad host-read para sponsorships de podcast
- Crear spots de podcast pre-producidos (announcer-read)
- Desarrollar scripts de ad para colocaciones pre-roll, mid-roll o post-roll
- Producir variaciones múltiples de script para diferentes shows de podcast

**NO USES** este skill para outlines de episodios de podcast, show notes, o comerciales de radio. Esto es específicamente para scripts publicitarios de podcast.

---

## Principio Fundamental

EL MEJOR AD DE PODCAST SUENA COMO EL HOST RECOMENDANDO ALGO GENUINAMENTE A UN AMIGO — NO LEYENDO UN SCRIPT CORPORATIVO.

---

## Fase 1: Brief

### Inputs Requeridos

| Input | Qué Preguntar | Default |
|-------|---------------|---------|
| **Producto/servicio** | "¿Qué estás anunciando?" | Sin default — debe ser proporcionado |
| **Tipo de ad** | "¿Host-read o pre-producido?" | Host-read |
| **Colocación** | "¿Pre-roll (60s), mid-roll (60-90s), o post-roll (30s)?" | Mid-roll (60 segundos) |
| **Oferta/CTA** | "¿Cuál es la oferta? (código de descuento, URL, prueba gratis)" | Sin default — debe ser proporcionado |
| **Puntos clave** | "¿Qué 2-3 puntos DEBEN mencionarse?" | Sin default — debe ser proporcionado |
| **Género de podcast** | "¿Qué tipo de podcast? (negocio, comedia, crimen real, salud)" | Negocio/emprendimiento |

**PUNTO DE CONTROL: No procedas hasta que el producto, oferta y puntos clave estén confirmados.**

---

## Fase 2: Framework de Script

Selecciona el framework basado en tipo de ad y colocación.

### Estructura Host-Read

**Pre-Roll (30-60 segundos)**
- Conexión personal o caso de uso (10s)
- Qué hace el producto y por qué importa (20s)
- Oferta + URL de tracking/código (10s)

**Mid-Roll (60-90 segundos)**
- Historia o experiencia personal con el producto (20-30s)
- Beneficios clave — máximo 3 (20-30s)
- Oferta + URL de tracking/código + repetición (15-20s)

**Post-Roll (15-30 segundos)**
- Recordatorio rápido del sponsor y oferta (10s)
- URL de tracking/código (5-10s)

### Estructura Pre-Producida

- Intro de announcer con nombre de brand (5s)
- Framing de problema + solución (15-20s)
- Beneficio clave + punto de prueba (15-20s)
- Oferta + CTA + URL (10-15s)

---

## Fase 3: Escribe Scripts

Entrega 2 variaciones de script con diferentes ángulos.

### Formato de Script

```
## Script [A/B]: [Nombre de Ángulo]

**Tipo:** Host-read / Pre-producido
**Colocación:** Mid-roll
**Duración:** ~60 segundos
**Conteo de palabras:** ~150 palabras (apunta a 2.5 palabras/segundo)

---

[TALKING POINTS DEL HOST — no script palabra por palabra]

• Abre con: [Historia personal o situación relatable]
  Ejemplo: "Así que he estado usando [Producto] por sobre tres meses, y tengo que decirte..."

• Puente a producto: [Cómo el producto se conecta con la historia]
  Ejemplo: "Lo que amo de esto es [beneficio específico] — Yo estaba haciendo [forma antigua] antes y me tomaba [tiempo]."

• Beneficios clave (golpea estos naturalmente):
  1. [Beneficio 1 — más relevante para esta audiencia]
  2. [Beneficio 2]
  3. [Beneficio 3 — opcional]

• Oferta: [Lenguaje de oferta exacto]
  "Ve a [URL de tracking] o usa código [CODE] al checkout por [descuento]."

• Repite URL/código: [Dilo dos veces, deletrea si es necesario]

---

**URL de tracking:** [vanity URL]
**Código promo:** [CODE]
**Debe mencionar:** [Cualquier lenguaje legal o de brand requerido]
```

---

## Fase 4: Pulido

### Notas de Entrega para Hosts

- **Guía de tono:** Conversacional, como recomendar a un amigo. No leas palabra por palabra.
- **Talking points, no teleprompter:** Los bullet points permiten entrega natural — los scripts palabra por palabra suenan rígidos.
- **Toque personal:** Anima al host a añadir su propia experiencia si han usado el producto.
- **Pacing:** 150 palabras = ~60 segundos a ritmo natural de podcast.

### Checklist de Configuración de Tracking

```
- [ ] Vanity URL creada y redirigiendo correctamente
- [ ] Código promo activo y probado
- [ ] Tracking de atribución en lugar (parámetros UTM o landing page única)
- [ ] Fecha de expiración del código establecida (si aplica)
- [ ] Host ha recibido producto/servicio para probar (para host-read auténtico)
```

---

## Anti-Patrones

- **Escribir scripts palabra por palabra para host-reads** — los hosts suenan robóticos leyendo scripts. Proporciona talking points.
- **Demasiados talking points** — 3 beneficios máximo. Más que eso y el host se apresura o el oyente sintoniza.
- **Olvidar repetir la URL/código** — siempre di la URL de tracking o código promo al menos dos veces.
- **Aperturas genéricas** — "Este episodio te es traído por..." es la forma más rápida de trigger un skip. Lidera con una historia.
- **Sin mecanismo de tracking** — cada ad debe tener una URL única, código, o landing page para atribución.

---

## Recuperación

- **Host no ha usado el producto:** Escribe el script como recomendación de tercera persona con social proof en lugar de experiencia personal. "Sobre 50,000 equipos usan [Producto] para..."
- **Slot de tiempo muy corto (15 segundos):** Despoja a nombre de brand, un beneficio, y la URL. Sin historia — solo el punch.
- **Múltiples podcasts con audiencias diferentes:** Escribe scripts separados adaptados a cada audiencia. Un podcast de negocios y uno de comedia necesitan hooks diferentes.
- **Sin código promo u oferta:** Crea urgencia con una landing page limitada en tiempo u contenido exclusivo. Cada ad de podcast necesita una razón para actuar ahora.
