# Página de Ventas Alto-Ticket

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Escribir página de ventas largo-formato para producto o servicio precio $500 o más
- Construir confianza extensa mediante social proof, casos de estudio y manejo de objeciones
- Crear CTA basada en aplicación o booking de llamada en lugar de checkout directo
- Diseñar copy de ventas que justifique precios premium a compradores sofisticados

---

## Principio Fundamental

COMPRADORES ALTO-TICKET NO NECESITAN MÁS HYPE — NECESITAN MÁS PRUEBA, MÁS ESPECIFICIDAD, Y MÁS CONFIANZA QUE ESTA INVERSIÓN ENTREGARÁ UN RETORNO MEDIBLE.

## Fase 2: Arquitectura de Página

### Estructura de Página de Ventas Largo-Forma

```
## Secciones de Página de Ventas (en orden)

1. **Sección Hero** — Headline + subheadline + CTA primario
2. **Agitación de Problema** — Define el dolor en términos específicos, relacionables
3. **Soluciones Fallidas** — Qué han intentado que no funcionó
4. **Introducción de Solución** — Presenta tu oferta como el puente
5. **Sección de Credibilidad** — Tu historia, credenciales, resultados
6. **Qué está Incluido** — Desglose detallado de entregables
7. **Casos de Estudio / Testimonios** — 3-5 historias de resultados detallados
8. **Manejo de Objeciones** — Aborda las top objeciones directamente
9. **Quién Es Para / No Es Para** — Califica el comprador
10. **Sección de Inversión** — Revelación de precio con contexto de valor
11. **FAQ** — 5-8 preguntas cubriendo logística y preocupaciones
12. **CTA Final** — Urgencia + garantía + aplicación/booking
13. **Sección P.S.** — Elemento de persuasión final
```

---

## Fase 3: Escribe la Página de Ventas

### Sección Hero
- Headline establece la transformación, no el nombre del producto
- Subheadline añade especificidad (para quién, timeframe, resultado)
- Texto de botón CTA: "Solicita Ahora" o "Reserva Tu Llamada" (no "Compra Ahora")

### Casos de Estudio
- Estructura: Situación → Solución → Resultado
- Incluye números específicos siempre que sea posible
- Mezcla perfiles diferentes de comprador

### Manejo de Objeciones
- Aborda cada objeción directamente con sección dedicada
- Formato: "Podrías estar pensando [objeción]. Aquí está la realidad: [reframe]."

### Sección de Inversión
- Nunca disculpes el precio
- Ancla contra costo del problema continuo (ingresos perdidos, tiempo desperdiciado)
- Si aplica, muestra matemáticas de ROI

### Reglas de Copy

- Escribe 3,000-5,000 palabras total — alto-ticket requiere profundidad
- Cada afirmación debe estar respaldada por prueba o especificidad
- Usa formateo para escannability: bold de frases clave, párrafos cortos, subheadings cada 200-300 palabras
- CTA aparece al menos 3 veces (hero, después de casos de estudio, sección final)
- Sección de garantía debe ser prominente y específica

---

## Anti-Patrones

- **Hype sobre sustancia** — "¡Esto cambiará tu vida para siempre!" sin especificidad insulta compradores sofisticados.
- **Esconder el precio** — compradores alto-ticket esperan transparencia. Si escondes precio, asumen lo peor.
- **Testimonios débiles** — "¡Programa excelente!" de "J.S." es inútil. Usa nombres completos, fotos, resultados específicos.
- **Checkout directo para $2,000+** — la mayoría de compradores arriba de $1,000 necesitan conversación primero. Usa aplicación o CTAs de booking de llamada.
- **Sin garantía** — precios premium sin garantía crean demasiado riesgo percibido.

---

## Recuperación

- **Sin testimonios disponibles:** Usa resultados personales, explicación de metodología, y garantía fuerte para compensar brecha de prueba.
- **Usuario quiere vender $2,000+ con checkout directo:** Recomienda funnel de aplicación o llamada. Tasas de conversión para checkout directo arriba de $1,000 típicamente bajo 0.5%.
- **Transformación poco clara:** Pregunta "¿Cuál es el cambio antes/después más grande que experimenta tu comprador?" y construye página completa alrededor de eso.
- **Múltiples audiencias:** Elige el perfil de comprador de mayor valor. Escribe página para ellos. Otras audiencias pueden ser servidas por páginas diferentes.
