# Guión de Ad de YouTube

## Principio Fundamental

TIENES 5 SEGUNDOS ANTES QUE APAREZCA EL BOTÓN DE SKIP — EL HOOK DEBE DETENER EL SCROLL Y LA PRIMERA LÍNEA DEBE GANAR LA SIGUIENTE LÍNEA.

## Cuándo Usar

- Escribir scripts para ads de YouTube pre-roll (skippable/non-skippable), mid-roll o bumper
- Crear variaciones de hooks para probar en campañas de YouTube
- Desarrollar scripts que sigan requisitos de formato de ad de YouTube
- Producir múltiples versiones de script para pruebas A/B

## Frameworks de Formato

**15-Segundo Skippable (más común)**
- Segundos 0-3: Hook (patrón interrupt — debe funcionar antes del botón skip)
- Segundos 3-10: Puente de problema + solución
- Segundos 10-15: CTA con urgencia

**30-Segundo Skippable**
- Segundos 0-5: Hook con claim audaz o pregunta
- Segundos 5-15: Agitación de problema + intro de solución
- Segundos 15-25: Prueba (testimonial, stat, demo)
- Segundos 25-30: CTA con paso claro siguiente

**6-Segundo Bumper (non-skippable)**
- Segundos 0-2: Un puñetazo visual/verbal
- Segundos 2-4: Brand + beneficio
- Segundos 4-6: CTA (URL o acción)

## Estilos de Hook (Rota en Variaciones)

1. **Hook de pregunta:** "¿Todavía [cosa dolorosa]?"
2. **Claim audaz:** "[Resultado específico] en [timeframe específico]."
3. **Pattern interrupt:** Algo visual o declaración inesperada
4. **Lead de social proof:** "[Número] personas ya [resultado deseado]."
5. **Hook negativo:** "Deja de [error común] — aquí por qué."

## Formato de Script

```
## Script [A/B/C]: [Estilo de Hook]

**Formato:** [15s skippable / 30s / 6s bumper]
**Duración:** [X segundos]

[SEGUNDO 0-3]
(Visual: [describe qué está en pantalla])
"[Línea hablada — el hook]"

[SEGUNDO 3-10]
(Visual: [describe])
"[Líneas habladas — problema/solución]"

[SEGUNDO 10-15]
(Visual: [CTA en pantalla con URL])
"[Línea CTA hablada]"

---

**On-screen text:** [Cualquier text overlays]
**End card:** [Texto de botón CTA + URL]
```

## Anti-Patrones

- **Enterrar el hook** — si tu value proposition no cae en primeros 3 segundos, el ad falla
- **Feature dumps** — lista un beneficio, no cinco características
- **CTAs débiles** — "aprende más" es vago. Usa "Comienza tu prueba gratis" o "Obtén el toolkit"
- **Ignorar visualización sin sonido** — siempre planifica para text overlays ya que mayoría de viewers móviles miran sin sonido
- **Escribir scripts de radio** — YouTube es visual. Cada segundo necesita dirección visual

## Recuperación

- **Usuario inseguro de formato:** Defaultea a 15-segundo skippable — es más versátil
- **Sin beneficio clave claro:** Pregunta qué dicen sus mejores clientes del producto
- **Múltiples productos:** Escribe scripts para un producto a la vez
- **Sin capacidad de producción de video:** Adapta scripts para formato estático/slideshow con text overlays y voiceover
