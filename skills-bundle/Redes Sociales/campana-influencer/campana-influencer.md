# Brief de Campaña con Influencer

## Cuándo Usar Esta Skill

Usa esta skill cuando necesites:
- Crear un brief profesional para enviar a socios influencers
- Definir entregables, cronogramas y directrices de mensajes para una colaboración
- Establecer workflows de aprobación de contenido y derechos de uso
- Planificar campañas con influencers con expectativas claras y KPIs

**NO** uses esta skill para encontrar influencers, negociar tarifas o gestionar relaciones continuas con influencers. Es específicamente para crear el documento del brief de campaña.

---

## Principio Central

UN BRIEF CLARO PROTEGE AMBOS LADOS — EL INFLUENCER SABE EXACTAMENTE QUÉ ENTREGAR Y LA MARCA OBTIENE CONTENIDO QUE CUMPLE EXPECTATIVAS SIN REVISIONES INFINITAS.

---

## Fase 1: Entradas de Campaña

### Entradas Requeridas

| Entrada | Qué Preguntar | Por Defecto |
|---------|---------------|-------------|
| **Marca/producto** | "¿Para qué marca y producto es esta campaña?" | Sin predeterminado — debe proporcionarse |
| **Objetivo de campaña** | "¿Objetivo principal? (conciencia, ventas, registros de correo, descargas de app)" | Conciencia + ventas |
| **Plataforma(s)** | "¿Qué plataformas? (Instagram, TikTok, YouTube, podcast)" | Instagram |
| **Nivel del influencer** | "¿Qué nivel? (nano 1-10K, micro 10-100K, mid 100K-500K, macro 500K+)" | Micro (10-100K) |
| **Presupuesto por influencer** | "¿Cuál es el presupuesto por influencer?" | $500-1,500 |
| **Cronograma** | "¿Cuándo debe publicarse el contenido?" | En 4 semanas |

**PUNTO DE CONTROL: No procedas hasta que se confirmen marca, objetivo y plataforma.**

---

## Fase 2: Estructura del Brief

Construye el documento de brief comprehensivo.

### Sección de Descripción General de Campaña

```
## Brief de Campaña: [Nombre de Campaña]

**Marca:** [Nombre de marca]
**Producto:** [Producto/servicio específico]
**Fechas de campaña:** [Inicio] — [Fin]
**Ventana de publicación de contenido:** [Rango de fechas para publicación]

### Objetivo de Campaña
[1-2 oraciones describiendo el objetivo y qué se vería como éxito]

### Audiencia Objetivo
[A quién debe alcanzar el contenido del influencer — datos demográficos, intereses, pain points]
```

### Sección de Entregables

```
### Entregables

| # | Tipo de Contenido | Plataforma | Especificaciones | Fecha de Entrega |
|---|------------------|-----------|------------------|-----------------|
| 1 | [Post del feed / Reel / Story / Video] | [Plataforma] | [Duración, proporción, formato] | [Fecha] |
| 2 | [Tipo] | [Plataforma] | [Especificaciones] | [Fecha] |

### Especificaciones de Contenido
- Duración de video: [X-X segundos]
- Proporción de aspecto: [9:16 / 1:1 / 16:9]
- Debe incluir: [Producto visible, mención de marca, CTA]
- Requisitos de caption: [Etiquetar @marca, incluir #hashtag, divulgación #ad]
```

### Directrices de Mensajes

```
### Mensajes Clave (Elige 1-2, no escribas guion)

1. [Mensaje central — enfocado en beneficios, lenguaje natural]
2. [Mensaje secundario]

### Puntos de Conversación
- [Punto 1 — beneficio específico o característica a destacar]
- [Punto 2]
- [Punto 3]

### NO Menciones
- [Nombres de competidores]
- [Afirmaciones de salud/finanzas no aprobadas]
- [Cualquier cosa fuera de marca]

### Tono
[Cómo debe sentirse el contenido — auténtico, educativo, entusiasta, sobrio]
El creador debe usar su propia voz. No lea de un guion.
```

## Fase 3: Logística

### Workflow de Aprobación

```
### Proceso de Aprobación de Contenido

1. **Envío de borrador:** El creador envía contenido de borrador antes del [fecha]
   - Enviar vía: [Email / carpeta compartida / DM de plataforma]
   - Incluir: Video sin procesar + caption propuesto
2. **Revisión de marca:** La marca proporciona feedback en [48 horas]
   - Máximo 2 rondas de revisiones
3. **Aprobación final:** La marca confirma aprobación por escrito
4. **Publicación:** El creador publica dentro de la ventana aprobada

### Política de Revisiones
- Las revisiones se limitan a precisión de mensajes y directrices de marca
- La marca NO solicitará cambios al estilo, edición o personalidad del creador
- Si las revisiones exceden 2 rondas, se aplica compensación adicional
```

### Compensación y Derechos

```
### Compensación
- Tarifa: $[cantidad] por [entregable / campaña]
- Términos de pago: [50% adelantado, 50% en entrega / Net 30]
- Método de pago: [Factura, PayPal, transferencia]
- Afiliado/comisión: [X% en ventas rastreadas, si aplica]
- Bonificación: [$X por X conversiones, si aplica]

### Derechos de Uso
- Repost orgánico por marca: [Sí/No, duración]
- Amplificación pagada (whitelisting/Spark Ads): [Sí/No, duración, tarifa adicional]
- Uso en sitio web/email: [Sí/No]
- Duración de derechos: [X meses desde publicación]
- Exclusividad: [Exclusividad de categoría por X días/meses]
```

## Ejemplo: Marca de Skincare DTC x Micro-Influencer

**Entregables:** 1 Instagram Reel (30-60s) + 3 Instagram Stories
**Mensaje clave:** "Mi rutina matutina acaba de simplificarse — [Producto] reemplazó 3 pasos."
**NO menciones:** Afirmaciones médicas, lenguaje de cura/tratamiento, marcas competidoras
**Compensación:** $800 + producto gratis + 15% comisión de afiliado
**Derechos de uso:** La marca puede hacer repost orgánico por 6 meses, amplificación pagada por 3 meses con $300 adicionales

---

## Anti-Patrones

- **Sobre-escribir el guion al creador** — prescribir diálogos exactos mata la autenticidad. Proporciona puntos de conversación, no un guion de teleprompter.
- **Sin proceso de aprobación** — sin un workflow claro, las revisiones se alargan y ambos lados se frustran.
- **Entregables vagos** — "algunos posts" no es un entregable. Especifica cantidad, formato, plataforma y fecha límite.
- **Ignorar divulgación FTC** — cada asociación pagada debe incluir #ad o #sponsored. Incluye este requisito en el brief.
- **Sin cláusula de derechos de uso** — si planeas ejecutar el contenido como anuncios pagados, establécelo por adelantado con compensación.

---

## Recuperación

- **El influencer quiere libertad creativa:** Suaviza el mensajeo a solo puntos de conversación. Proporciona 2-3 ejemplos de estilos de contenido que te gustan, no guiones.
- **Presupuesto muy bajo para cantidad de entregables:** Reduce entregables o cambia a nano-influencers que acepten compensación solo de producto.
- **Sin producto para enviar:** Proporciona acceso digital, prueba de servicio o tarjeta de regalo. El creador necesita experimentar el producto.
- **Cronograma ajustado:** Señala tarifas de emergencia por adelantado. La mayoría de creadores necesitan mínimo 2-3 semanas desde el brief hasta publicación.
