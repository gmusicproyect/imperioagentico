# Plan de Comarketing

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Planificar una campaña de comarketing con una marca o negocio complementario
- Diseñar tácticas de promoción cruzada con contenido compartido e intercambio de audiencia
- Crear criterios de selección de socios y marcos de evaluación
- Construir sistemas de atribución para medir la contribución de cada socio

**NO** uses este skill para marketing de afiliados, campañas de publicidad pagada, o planes de marketing en solitario. Esto es para marketing colaborativo donde dos marcas co-crean y co-promocionan.

---

## Principio Fundamental

EL COMARKETING FUNCIONA SOLO CUANDO AMBAS AUDIENCIAS SE BENEFICIAN GENUINAMENTE — SI LA ASOCIACIÓN SE SIENTE FORZADA O UNILATERAL, AMBAS MARCAS PIERDEN CONFIANZA CON SU GENTE.

## Fase 1: Resumen

### Información Requerida

| Entrada | Qué Preguntar | Por Defecto |
|---------|---------------|------------|
| **Objetivo de campaña** | "¿Qué quieres de este esfuerzo de comarketing? (leads, ventas, awareness)" | Generación de leads |
| **Socio** | "¿Tienes un socio específico en mente, o necesitas criterios de selección?" | Necesito criterios de selección |
| **Tu audiencia** | "Describe el tamaño, plataforma y demografía de tu audiencia." | Sin defecto — debe proporcionarse |
| **Tipo de campaña** | "¿Webinar, contenido co-autorizado, bundle, sorteo, o algo más?" | Contenido co-autorizado + promoción cruzada |
| **Cronograma** | "¿Cuándo necesita lanzarse esta campaña?" | 4-6 semanas desde ahora |
| **Presupuesto** | "¿Cuál es el presupuesto combinado para esta campaña?" | $0 (solo capital humano) |

**PUNTO DE CONTROL: Confirma el resumen antes de proceder.**

## Fase 2: Planificar

### Criterios de Selección de Socio

Si no se ha identificado un socio, usa esta matriz de evaluación:

```
| Criterio | Peso | Puntuación (1-5) | Notas |
|----------|------|-----------------|-------|
| Superposición de audiencia (mismo comprador, producto diferente) | 25% | | |
| Tamaño de audiencia relativo al tuyo (0.5x-3x ideal) | 20% | | |
| Alineación de marca (valores, tono, calidad) | 20% | | |
| Calidad de engagement (audiencia activa, no solo grande) | 15% | | |
| Capacidad de respuesta y confiabilidad | 10% | | |
| Historial de colaboración anterior | 10% | | |
```

### Estructura de Campaña

```
## Campaña: [Nombre]
**Tipo:** [Webinar / Contenido co-autorizado / Bundle / Sorteo]
**Cronograma:** [Fecha de inicio a fin]
```

## Fase 3: Construir

### Creación de Contenido Compartido

Para cada activo co-creado, define:
- Quién redacta la primera versión
- Quién revisa y edita
- Pautas de marca que ambas partes deben seguir
- Proceso de aprobación y cronograma
- Dónde vive el activo final (sitio web de quién)

### Sistema de Atribución

```
## Rastreo y Atribución
**Parámetros UTM:**
- Tu tráfico: ?utm_source=nombre_socio&utm_medium=comarketing&utm_campaign=[nombre]
- Su tráfico: ?utm_source=tu_nombre&utm_medium=comarketing&utm_campaign=[nombre]

**Método de rastreo:** [Dashboard compartido de Google Analytics / enlaces de rastreo separados]
**Cadencia de informes:** [Semanal durante campaña, informe final 7 días después del cierre]

**Métricas para rastrear por socio:**
- Tráfico enviado
- Leads generados
- Tasa de conversión
- Ingresos atribuidos (si aplica)
```

### Cronograma de Campaña

```
## Cronograma Semana por Semana

**Semana 1:** Finalizar acuerdo de asociación y plan de campaña
**Semana 2:** Crear contenido compartido y páginas de destino
**Semana 3:** Revisar, aprobar y preparar materiales promocionales
**Semana 4:** Lanzamiento — ambos socios promocionan simultáneamente
**Semana 5:** Check-in a mitad de campaña, ajustar si es necesario
**Semana 6:** Cierre de campaña, empuje final, recopilación de datos
**Semana 7:** Análisis de resultados e informe compartido
```

## Ejemplo 1: Webinar de Generación de Leads Co-Hospedado

```
Socios: Herramienta de marketing de email + Coach de copywriting
Activo compartido: Webinar "Escribe Emails que Conviertan"
Tu promoción: 3 emails a tu lista de 8,000 + 5 posts en redes
Su promoción: 3 emails a su lista de 12,000 + 5 posts en redes
Objetivo: 500 registros combinados, 200 asistentes en vivo
Seguimiento: Ambos socios envían replay + sus ofertas respectivas
```

## Ejemplo 2: Guía Co-Autorizada + Bundle

```
Socios: Consultor de SEO + Diseñador web
Activo compartido: "Checklist Completo de Lanzamiento de Sitio Web" (PDF co-autorizado)
Tu promoción: Post del blog + 3 emails + Instagram stories
Su promoción: Post del blog + 3 emails + Posts de LinkedIn
Objetivo: 1,000 descargas de guía, hacer crecer ambas listas
Seguimiento: Cada socio ofrece su servicio como próximo paso lógico
```

## Anti-Patrones

- **Desajuste de audiencia** — asociarse con alguien que tiene la misma audiencia que tú crea competencia, no colaboración. Encuentra audiencias complementarias.
- **Promoción desigual** — si un socio promociona mucho y el otro apenas lo menciona, crece el resentimiento. Define compromisos de antemano.
- **Sin rastreo** — sin parámetros UTM y analytics compartido, no puedes medir ROI o atribuir resultados de manera justa.
- **Creación de contenido por comité** — una persona redacta, otra edita. Escribir conjuntamente desde cero produce trabajo mediocre.
- **Sin plan de seguimiento** — la campaña genera leads, ¿luego qué? Ambos socios necesitan una secuencia de nutrición post-campaña.

---

## Recuperación

- **No puedo encontrar un socio adecuado:** Busca en nichos adyacentes, no en el mismo nicho. Pregunta "¿Quién sirve a mi cliente antes o después de que me necesite?"
- **El socio deja de promocionar a mitad de campaña:** Ten una cláusula de compromiso mínimo en el acuerdo. Si no cumplen, reduce el alcance de colaboración futura.
- **La campaña tiene bajo desempeño:** Analiza por canal. Usualmente un canal lleva la campaña. Dobla esfuerzos allí y corta el resto.
- **Los leads son de baja calidad:** Revisa la alineación de audiencia. Si la audiencia del socio no es realmente tu comprador objetivo, la asociación fue incorrecta, no la campaña.
