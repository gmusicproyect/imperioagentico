# Resolución de Quejas

## Cuándo Usar Esta Competencia

Usa esta competencia cuando necesites:
- Crear un marco estructurado para manejar quejas de clientes
- Escribir scripts de empatía y plantillas de respuesta para tipos comunes de quejas
- Definir caminos de escalada y niveles de autoridad para resolución
- Construir pautas de oferta de recuperación y procedimientos de seguimiento

**NO** uses esta competencia para escribir respuestas de revisión individual (usa revisión-respuesta), comunicación de crisis, o resolución de disputas legales. Esto es para construir el sistema de manejo de quejas.

---

## Principio Fundamental

UNA QUEJA BIEN RESUELTA CREA MÁS LEALTAD QUE NINGUNA QUEJA EN ABSOLUTO — CLIENTES QUE SE SIENTEN ESCUCHADOS Y AYUDADOS SE CONVIERTEN EN SUS DEFENSORES MÁS FUERTES.

## Fase 1: Inventario de Quejas

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|---------|-------------|--------------|
| **Tipo de negocio** | "¿Qué producto o servicio proporcionas?" | Sin predeterminado |

## Fase 2: Marco de Resolución

Construye el método ESCUCHA para manejar cada queja.

### El Marco ESCUCHA

```
## Resolución de Quejas: Método ESCUCHA

### E — Escucha
Escucha completamente sin interrumpir o defender. Deja que el cliente termine.
"Cuéntame todo lo que sucedió."
"Quiero entender el cuadro completo."

### S — Simpatiza
Reconoce sus sentimientos antes de abordar los hechos.
"Entiendo cuán frustrante debe ser eso."
"Esa no es la experiencia que mereces, y lo siento."

### C — Culpa
Toma responsabilidad sin excusas o cambio de culpa.
"Siento que esto sucediera. Deberíamos haber [fallo específico]."
"Tienes razón — nos equivocamos en [problema específico]."

### U — Usa Solución
Ofrece una solución específica con plazo.
"Aquí es lo que voy a hacer: [acción específica] antes de [fecha específica]."
"Me gustaría ofrecerte [resolución] para arreglarlo."

### C — Controla
Registra la queja, resolución y plan de seguimiento.
Registra en rastreador de quejas para análisis de patrones.
```

### Matriz de Autoridad de Resolución

```
## Autoridad de Resolución

| Severidad de Queja | Opciones de Resolución | Autoridad |
|-------------------|----------------------|-----------|
| Menor (Severidad 1-2) | Disculpa + arreglo | Cualquier miembro del equipo |
| Moderada (Severidad 3) | Disculpa + arreglo + crédito/descuento pequeño | Líder de equipo / propietario |
| Mayor (Severidad 4) | Reembolso completo o reemplazo + disculpa | Propietario |
| Crítica (Severidad 5) | Reembolso completo + compensación adicional + llamada personal | Propietario — inmediato |
```

### Plantillas de Respuesta por Tipo de Queja

**Problema de Calidad:**
```
Hola [Nombre],

Gracias por avisarme sobre [problema específico]. Ese no es el estándar de calidad que mantenemos, y lo siento.

Aquí es lo que estoy haciendo:
- [Arreglo inmediato — reemplazo, rehacer, corrección]
- [Paso preventivo — qué cambia para que no suceda de nuevo]

[Oferta de resolución si es apropiada]

Te daré seguimiento antes de [fecha] para asegurar que todo está correcto.

[Nombre]
```

**Problema de Plazo/Entrega:**
```
Hola [Nombre],

Tienes razón — nos perdimos el [plazo/fecha de entrega] y entiendo cómo eso te impacta.

[Explicación breve y honesta — no una excusa]

Aquí está el plazo actualizado: [fecha/hora específica].
[Compensación por el retraso si aplica]

Asumo la responsabilidad de esto y personalmente aseguraré que se cumpla el plazo revisado.

[Nombre]
```

## Fase 3: Escalada y Recuperación

Define cuándo y cómo escalar, y qué se ve la recuperación.

### Disparadores de Escalada

```
## Protocolo de Escalada

| Disparador | Escala A | Plazo |
|-----------|---------|-------|
| Cliente menciona abogado/legal | Propietario | Inmediatamente |
| Mismo cliente se queja 3+ veces | Propietario | Mismo día |
| Queja se hace pública (redes sociales, revisión) | Propietario | Dentro de 1 hora |
| Impacto financiero sobre $[cantidad] | Propietario/Finanzas | Mismo día |
| Cliente amenaza con irse | Propietario | Dentro de 4 horas |
```

### Pautas de Oferta de Recuperación

```
## Matriz de Oferta de Recuperación

| Severidad | Culpa Nuestra | Culpa Compartida | No Nuestra Culpa |
|----------|---------|---------|---------|
| Menor | Disculpa | Disculpa | Explicación |
| Moderada | Disculpa + 10-20% crédito | Disculpa + 10% crédito | Disculpa + gesto de buena fe |
| Mayor | Reembolso completo o rehacer | Reembolso parcial + rehacer | Explicación + gesto pequeño |
| Crítica | Reembolso completo + crédito bonus | Reembolso completo | Explicación + empatía |
```

### Protocolo de Seguimiento

- **48 horas después de resolución:** Verifica — "Quería asegurar que [resolución] te funcionó."
- **1 semana después de resolución:** Seguimiento breve — "¿Está todo en buen camino?"
- **30 días después de resolución:** Verificación final — solo para quejas mayores/críticas

### Análisis Mensual

1. ¿Cuántas quejas este mes vs. el último?
2. ¿Qué tipo aparece más frecuentemente?
3. Para la queja más común: ¿qué cambio sistémico la prevendría?
4. Tiempo promedio de resolución — ¿está mejorando?
5. Retención de cliente después de queja — ¿se quedaron?

### Plan de Acción de Causa Raíz

Cuando la misma queja aparece 3+ veces:
```
**Queja recurrente:** [Tipo]
**Causa raíz:** [Por qué sigue sucediendo]
**Arreglo sistémico:** [Proceso, producto, o cambio de comunicación]
**Propietario:** [Nombre]
**Plazo:** [Fecha]
```

## Anti-Patrones

- **Defender antes de simpatizar** — explicar por qué algo sucedió antes de reconocer sentimientos se siente despectivo.
- **Resolución de talla única** — un descuento 10% no arregla un fallo de calidad mayor. Empareja la resolución a la severidad.
- **Sin seguimiento** — resolver el problema pero nunca verificar nuevamente te pierde la oportunidad de reconstruir confianza.
- **Culpar al cliente** — incluso si el cliente cometió un error, enmarca la respuesta alrededor de lo que harás, no lo que deberían haber hecho.
- **Ignorar patrones de quejas** — quejas individuales son fuegos para apagar. Los patrones son problemas sistémicos para arreglar.

---

## Recuperación

- **Cliente está extremadamente enojado y no se calma:** Reconoce sin coincidir su energía. "Escucho cuán frustrado estás, y quiero arreglar esto." Si es hostil, establece un límite: "Quiero ayudarte — enfoquémonos en la solución."
- **Usuario no tiene presupuesto para reembolsos/créditos:** Ofrece resolución no monetaria: soporte prioritario, tiempo de consultoría libre, prueba extendida, o llamada de disculpa personal.
- **Queja es poco razonable:** Simpatiza con el sentimiento, establece límites claros sobre lo que puedes ofrecer, y documenta la interacción.
- **Mismo cliente se queja repetidamente:** Programa una conversación directa para entender el problema subyacente. Las quejas repetidas generalmente señalan una desconexión fundamental.
- **Usuario está emocionalmente afectado por quejas:** Separa la queja de identidad personal. La queja es sobre el producto o servicio, no sobre ti como persona.
