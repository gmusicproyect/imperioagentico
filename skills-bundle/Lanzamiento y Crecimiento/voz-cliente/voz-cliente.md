# Voz del Cliente

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Construir un programa sistemático de Voz del Cliente (VoC) desde cero
- Definir métodos de recolección, marcos de análisis y distribución de insights
- Crear un ciclo de feedback que convierta la opinión del cliente en mejoras de negocio
- Asegurar que las perspectivas del cliente informen decisiones de producto, marketing y servicio

**NO** uses este skill para analizar feedback existente (usa análisis-feedback), escribir encuestas o segmentación de clientes. Esto es para diseñar el programa general de VoC.

---

## Principio Fundamental

VOZ DEL CLIENTE NO ES UNA ENCUESTA — ES UN SISTEMA CONTINUO QUE CAPTURA, ANALIZA Y ACTÚA SOBRE LO QUE LOS CLIENTES DICEN, PIENSAN Y SIENTEN EN CADA PUNTO DE CONTACTO.

---

## Fase 1: Diseño del Programa

Define el alcance y objetivos del programa VoC.

### Información Requerida

| Dato | Qué Preguntar | Predeterminado |
|------|---------------|----------------|
| **Tipo de negocio** | "¿Qué hace tu negocio?" | Sin predeterminado |
| **Base de clientes** | "¿Cuántos clientes tienes?" | Menos de 100 |
| **Feedback actual** | "¿Cómo recopilas feedback hoy?" | Ad hoc, sin sistema |
| **Decisiones a informar** | "¿Qué decisiones de negocio debería influenciar la opinión del cliente?" | Producto, marketing, servicio |
| **Recursos** | "¿Cuánto tiempo puedes dedicar a VoC mensualmente?" | 2-4 horas |

**PUNTO DE CONTROL: Confirma los objetivos del programa antes de diseñar métodos de recolección.**

## Fase 2: Sistema de Recolección

Diseña el sistema de recolección de feedback multicanal.

### Métodos de Recolección

```
## Canales de Recolección VoC

| Canal | Método | Frecuencia | Audiencia | Responsable |
|-------|--------|-----------|----------|-------------|
| Encuestas | NPS + CSAT | Trimestral | Todos los clientes | [Nombre] |
| Entrevistas | Llamadas 1:1 con clientes | Mensual (3-5 llamadas) | Usuarios activos + en riesgo | [Nombre] |
| Tickets de soporte | Etiquetar y categorizar temas | Continuo | Todos los contactos de soporte | [Nombre] |
| Reseñas | Monitorear Google, G2, redes sociales | Escaneo semanal | Reseñadores públicos | [Nombre] |
| Conversaciones de ventas | Documentar objeciones y solicitudes | Continuo | Prospectos | [Nombre] |
| Datos de uso | Rastrear patrones de comportamiento | Análisis mensual | Todos los usuarios | [Nombre] |
```

### Guía de Entrevista con Clientes

```
## Plantilla de Entrevista VoC (20 minutos)

1. ¿Cómo describirías [producto/servicio] a un colega? (Insight de posicionamiento)
2. ¿Qué problema estabas tratando de resolver cuando nos encontraste? (Jobs-to-be-done)
3. ¿Cuál es la cosa más valiosa que hacemos por ti? (Propuesta de valor central)
4. Si pudieras cambiar una cosa, ¿cuál sería? (Prioridad de mejora)
5. ¿Qué casi te hizo NO comprar / registrarte? (Insight de objeciones)
6. ¿Hay algo que desearías que ofreciéramos que no ofrecemos? (Oportunidad de expansión)
```

**PUNTO DE CONTROL: Presenta el sistema de recolección para aprobación.**

## Fase 3: Marco de Análisis

Convierte feedback cruda en insights accionables.

### Sistema de Etiquetado

```
## Etiquetas de Feedback

| Categoría | Etiquetas |
|-----------|---------|
| Tema | Producto, Servicio, Precios, Soporte, Onboarding, Comunicación |
| Sentimiento | Positivo, Neutral, Negativo |
| Impacto | Solicitud de función, Bug/Problema, Elogio, Queja, Sugerencia |
| Urgencia | Inmediato, Próximo trimestre, Backlog |
```

### Reporte Mensual VoC

```
## Reporte de Voz del Cliente — [Mes]

### Resumen de Datos
- Encuestas recopiladas: [#]
- Entrevistas completadas: [#]
```

## Fase 4: Ciclo de Acción

Cierra el ciclo entre feedback y acción de negocio.

### Distribución de Insights

```
## Quién Recibe Qué

| Audiencia | Insights | Formato | Frecuencia |
|----------|---------|--------|-----------|
| Producto/Desarrollo | Solicitudes de funciones, problemas de usabilidad | Lista priorizada | Mensual |
| Marketing | Lenguaje del cliente, objeciones, testimonios | Biblioteca de citas + temas | Mensual |
| Soporte | Problemas comunes, brechas de proceso | Actualizaciones FAQ + capacitación | Según necesidad |
| Liderazgo | Temas estratégicos, tendencias de satisfacción | Resumen ejecutivo | Trimestral |
```

### Cerrar el Ciclo con los Clientes

Cuando la feedback lleva a acción, dile al cliente:
- "Nos dijiste [feedback]. Nosotros [acción tomada]."
- Comparte vía email, actualizaciones de producto o redes sociales
- Esto fomenta la participación futura en feedback

### Revisión Trimestral VoC

1. ¿Cuáles son los 3 temas principales en todos los canales?
2. ¿Qué temas son nuevos vs. recurrentes?
3. ¿Las acciones del trimestre anterior impactaron la satisfacción?
4. ¿Qué deberíamos priorizar el próximo trimestre basado en datos VoC?
5. ¿Estamos recopilando de los canales correctos?

---

## Anti-Patrones

- **Recopilar sin actuar** — feedback sin seguimiento quema la buena voluntad del cliente. Si preguntas, debes actuar.
- **Solo escuchar voces fuertes** — el cliente más enojado no es representativo. Pondera la feedback por volumen y segmento.
- **Fatiga de encuestas** — demasiadas encuestas matan las tasas de respuesta. Limita a trimestral como máximo.
- **Ignorar feedback positiva** — los temas positivos revelan ventajas competitivas. Amplíficalos.
- **VoC como proyecto único** — este es un programa continuo, no un proyecto de investigación. Intégralo en el ritmo mensual.

---

## Recuperación

- **El usuario tiene cero datos de feedback:** Comienza con 5 entrevistas de clientes este mes. Eso es suficiente para revelar temas iniciales.
- **Los clientes no participan en entrevistas:** Ofrece valor a cambio — comparte insights de la industria durante la llamada, u ofrece un pequeño crédito.
- **Demasiados datos, poco análisis:** Enfócate solo en los 3 temas principales. Profundidad en pocos temas supera a amplitud en muchos.
- **El usuario no tiene tiempo para un programa completo:** Comienza con un canal (entrevistas mensuales O encuestas trimestrales). Agrega canales solo después de que el primero sea un hábito.
- **Los insights no impulsan decisiones:** Vincula cada insight a una decisión de negocio específica. "Los clientes quieren X" es débil. "Los clientes quieren X, que deberíamos abordar en la actualización de producto del Q2" es accionable.
