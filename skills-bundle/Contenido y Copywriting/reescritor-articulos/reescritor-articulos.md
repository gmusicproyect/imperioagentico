# Reescritor de Artículos

## Cuándo Usar Este Skill

Usa esta skill cuando necesites:
- Refrescar una publicación de blog desactualizada con datos actuales y estructura mejorada
- Reescribir un artículo con un nuevo ángulo para una audiencia diferente
- Mejorar el desempeño SEO del contenido existente que ha perdido rankings
- Actualizar un artículo estilo competidor en contenido original de mayor calidad

**NO** uses esta skill para spinning o plagio de contenido. Esta skill produce contenido genuinamente reescrito que agrega nuevo valor.

---

## Principio Fundamental

UNA REESCRITURA DEBE HACER EL CONTENIDO SIGNIFICATIVAMENTE MEJOR -- NO SOLO DIFERENTE. SI LA REESCRITURA NO AGREGA NUEVO VALOR, ES UNA PÉRDIDA DE TIEMPO.

---

## Fase 1: Brief

### Inputs Requeridos

| Input | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Artículo original** | "Pega el artículo o proporciona la URL." | Sin predeterminado -- debe ser proporcionado |
| **Objetivo de reescritura** | "¿Por qué reescriben? ¿Refresco SEO, nueva audiencia, información actualizada, mejor calidad?" | Refresco SEO |
| **Palabra clave objetivo** | "¿Qué palabra clave debería dirigirse la versión reescrita?" | Igual que original |
| **Audiencia** | "¿Misma audiencia o diferente?" | Misma audiencia |
| **Qué mantener** | "¿Hay secciones, ejemplos o datos que deben mantenerse?" | Preservar mensaje central y estructura |
| **Qué cambiar** | "¿Qué específicamente necesita mejora?" | Discreción del usuario -- auditará |
| **Cantidad de palabras** | "¿Duración objetivo para la reescritura?" | Coincide con original +/- 20% |

**PUNTO DE CONTROL:** Confirma brief y revisa artículo original antes de proceder.

---

## Fase 2: Auditoría y Plan

### Auditoría de Contenido

Antes de reescribir, analiza el artículo original en estas dimensiones:

```
## Auditoría de Contenido

**Fortalezas (mantén estas):**
- [Lo que funciona bien -- secciones fuertes, buenos ejemplos, estructura sólida]

**Debilidades (arregla estas):**
- [Datos desactualizados, intro débil, formato pobre, secciones faltantes]

**Problemas SEO:**
- [Colocación de palabras clave, meta descripción, estructura de headers, densidad]

**Problemas Estructurales:**
- [Problemas de flujo, transiciones faltantes, secciones de pared de texto]

**Elementos Faltantes:**
- [Ejemplos, datos, enlaces internos, CTA, visuales]
```

### Plan de Reescritura

```
## Plan de Reescritura

**Nuevo ángulo/hook:** [Cómo la reescritura abrirá diferentemente]
**Secciones a mantener (con actualizaciones):** [Lista]
**Secciones a reescribir completamente:** [Lista]
**Secciones a agregar:** [Lista]
**Secciones a cortar:** [Lista]
**Nuevos datos o ejemplos a incluir:** [Lista]
```

**PUNTO DE CONTROL:** Presenta auditoría y plan para aprobación antes de reescribir.

## Fase 3: Escribe

### Reglas de Reescritura

| Regla | Detalle |
|------|--------|
| **Nunca copiar-pegar párrafos** | Cada párrafo debe ser reescrito, no reorganizado |
| **Se requiere intro nueva** | El párrafo de apertura debe ser completamente original |
| **Agrega nuevo valor** | Incluye al menos 2 nuevos ejemplos, puntos de datos o insights no en original |
| **Mejora estructura** | Arregla jerarquía de headers, agrega listas donde texto es denso |
| **Actualiza datos** | Reemplaza estadísticas desactualizadas con actuales (nota fuentes) |
| **Mejor formato** | Párrafos cortos, frases clave en negrita, bullets para listas de 3+ |
| **Optimización SEO** | Aplica reglas de colocación de palabras clave (H1, primeras 100 palabras, H2s, meta descripción) |

### Lista de Verificación de Reescritura (por sección)

Para cada sección de la reescritura:
- ¿Es esto significativamente diferente del original (no solo sinónimos)?
- ¿Agrega nuevo valor (ejemplos, datos, perspectiva)?
- ¿Está mejor estructurado y es más legible?
- ¿Sirve mejor la palabra clave objetivo?

### Entregables

1. **Artículo completo reescrito** con estructura de heading apropiada
2. **Meta descripción** (150-160 caracteres)
3. **Resumen de cambios** -- qué se mantuvo, cambió, agregó y removió

```
## Resumen de Cambios

| Sección | Acción | Detalle |
|---------|--------|--------|
| Intro | Completamente reescrita | Nuevo hook usando [enfoque] |
| Sección 2 | Actualizada | Nuevos datos de [fuente], ejemplo agregado |
| Sección 4 | Agregada | Nueva sección sobre [tema] no en original |
| Sección 6 | Removida | Redundante con Sección 3 |
```

## Fase 4: Pulir

### 1. Comparación Antes/Después

Destaca 2-3 mejoras clave:

```
## Mejoras Clave

**1. Intro**
Antes: "En el mundo digital actual, el marketing de contenido es importante..."
Después: "Publicamos 47 posts de blog el año pasado. Tres de ellos impulsaron el 80% de nuestro tráfico. Aquí está lo que los hizo diferentes."

**2. [Nombre de sección]**
Antes: [Fragmento breve]
Después: [Fragmento breve]
```

### 2. Lista de Verificación de Mejora SEO

```
## Lista de Verificación SEO

- [ ] Palabra clave objetivo aparece en el H1
- [ ] Palabra clave en primeras 100 palabras
- [ ] Palabra clave en al menos un H2
- [ ] Densidad de palabra clave entre 0.5-1.5%
- [ ] Nueva meta descripción escrita (150-160 caracteres)
- [ ] La jerarquía de headers es correcta (H1 > H2 > H3)
- [ ] Enlaces internos agregados o actualizados
- [ ] Sugerencias de alt text para cualquier imagen
- [ ] Cantidad de palabras cumple objetivo
```

### 3. Evaluación de Legibilidad

Compara métricas de legibilidad antes y después: nivel de lectura, duración promedio de oración, porcentaje de voz pasiva.

## Ejemplo: Reescribir "10 Consejos de Email Marketing" de 2022

```
Hallazgos de auditoría:
- Estadísticas desactualizadas (datos 2021)
- Consejos genéricos sin ejemplos
- Sin optimización de palabras clave
- 800 palabras (demasiado delgado para ranking)

Plan de reescritura:
- Nuevo ángulo: "10 Tácticas de Email Marketing Que Funcionan en 2025"
- Agregar ejemplos específicos para cada consejo
- Incluir datos 2024-2025 de email marketing
- Expandir a 1,800 palabras con cobertura más profunda
- Palabra clave objetivo: "tácticas email marketing 2025"
```

---

## Anti-Patrones

- **Sinónimo swapping** -- reemplazar palabras con sinónimos no es reescritura. Es spinning, y lectores y motores de búsqueda pueden notarlo.
- **Mantener la misma intro** -- la intro es el párrafo más importante. Si no cambia, la reescritura se siente rancia.
- **Sin nuevo valor agregado** -- si la reescritura tiene los mismos ejemplos, datos y estructura, no vale la pena publicar.
- **Ignorar datos desactualizados** -- reescribir alrededor de estadísticas antiguas socava credibilidad. Actualiza o remueve.
- **Hacerla más larga sin hacerla mejor** -- agregar 500 palabras de relleno para cumplir cantidad de palabras daña calidad.

---

## Recuperación

- **Original es bueno pero desactualizado:** Enfoca la reescritura en actualizaciones de datos, nuevos ejemplos y arreglos SEO. Preserva la estructura.
- **Original está pobremente escrito:** Reescribe desde cero usando el original como brief de tema, no como plantilla.
- **Nuevos datos no disponibles:** Sustituye con mejoras cualitativas -- mejores ejemplos, explicaciones más claras, estructura más fuerte.
- **Usuario quiere cambios mínimos:** Crea "refresco ligero" -- intro nueva, datos actualizados, meta descripción mejorada, formato mejor. Nota que refrescos ligeros tienen impacto SEO limitado.
- **Reescritura es demasiado similar a original:** Compara párrafos lado a lado. Cualquier párrafo que sea más del 50% similar necesita otro paso.
