# Constructor de Propuesta de Libro

## Cuándo Usar Esta Skill

Usa esta skill cuando necesites:
- Escribir una propuesta de libro profesional para editores o agentes
- Crear un argumento convincente y sinopsis ejecutiva
- Estructurar el contenido de tu libro para una propuesta
- Desarrollar análisis de mercado para tu libro

**NO USES** esta skill para escribir el libro mismo o el contenido detallado del capítulo.

---

## Principio Fundamental

UNA PROPUESTA DE LIBRO EFECTIVA RESPONDE: ¿QUIÉN LO QUIERE? ¿POR QUÉ LO QUIEREN? ¿POR QUÉ TÚ ERES EL INDICADO PARA ESCRIBIRLO?

---

## Componentes de la Propuesta

### 1. Página de Título
- Título
- Subtítulo
- Autor
- Género/Categoría
- Fecha

### 2. Resumen Ejecutivo (1 página)
- Argumento de una oración
- Beneficio principal
- Audiencia objetivo
- Por qué ahora

### 3. Sinopsis (1-2 páginas)
- Resumen del contenido
- Arco principal
- Puntos clave
- Conclusión

### 4. Autor Bio (1/2 página)
- Quién eres
- Credenciales relevantes
- Por qué estás calificado
- Plataforma/audiencia

### 5. Análisis de Mercado (1-2 páginas)
- Audiencia objetivo (tamaño, demográfica)
- Libros competidores
- Por qué tu libro es diferente
- Oportunidades de venta

### 6. Estructura del Libro (1-2 páginas)
- Parte I: [Tema] - [# de capítulos]
- Parte II: [Tema] - [# de capítulos]
- Resumen de cada capítulo (1-2 oraciones)

### 7. Visión de Marketing (1 página)
- Cómo promoverás el libro
- Plataformas/audiencias existentes
- Contactos en medios
- Ideas de eventos

---

## Plantilla de Sinopsis

```
## Sinopsis

[Párrafo 1: Hook - por qué este libro importa ahora]

[Párrafo 2: Problema que resuelve]

[Párrafo 3: Solución/enfoque único]

[Párrafo 4: Beneficios para el lector]

[Párrafo 5: Conclusión y visión]
```

---

## Formato de Estructura

```
## Estructura del Libro: [Título]

**Parte I: [Tema]** (X capítulos)

**Capítulo 1: [Título]**
[1-2 oraciones sobre contenido]

**Capítulo 2: [Título]**
[1-2 oraciones sobre contenido]

**Parte II: [Tema]** (X capítulos)
...
```

---

## Anti-Patrones

- Propuesta demasiado larga (máximo 20 páginas)
- Sin análisis de mercado claro
- Bio de autor enfocada en historia personal (enfócate en credenciales relevantes)
- Sin diferenciador claro de competidores
- Plataforma/audiencia poco clara o pequeña
