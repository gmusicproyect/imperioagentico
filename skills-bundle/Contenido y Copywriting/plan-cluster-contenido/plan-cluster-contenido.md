# Plan de Cluster de Contenido

## Cuándo Usar Esta Habilidad

Usa esta habilidad cuando necesites:
- Diseñar una estrategia de cluster temático con páginas pilares y contenido de apoyo
- Mapear arquitectura de enlace interno entre piezas de contenido relacionadas
- Construir autoridad temática alrededor de temas clave para SEO
- Planificar un calendario de contenido organizado por clusters temáticos

**NO** uses esta habilidad para escritura individual de posts de blog, investigación de palabras clave, o SEO técnico. Esto es para planificación estratégica de arquitectura de contenido.

---

## Principio Fundamental

LA AUTORIDAD TEMÁTICA SE CONSTRUYE AL CUBRIR UN TEMA INTEGRALMENTE A TRAVÉS DE CONTENIDO INTERCONECTADO — UNA PÁGINA PILAR APOYADA POR MUCHOS POSTS DE CLUSTER SEÑALA A GOOGLE QUE ERES LA AUTORIDAD EN ESE TEMA.

## Fase 1: Análisis Inicial

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Nicho del negocio** | "¿Cuál es tu área de expertise?" | No hay predeterminado — debe proporcionarse |
| **Temas principales** | "¿Qué 3-5 temas amplios deberías ser conocido?" | No hay predeterminado — debe proporcionarse |
| **Contenido existente** | "¿Cuántos posts/páginas publicados tienes?" | Bajo 20 |
| **Capacidad de publicación** | "¿Cuántas piezas puedes publicar por mes?" | 4 por mes |
| **Audiencia objetivo** | "¿Para quién estás escribiendo?" | Tu cliente ideal |
| **Objetivo principal** | "¿Qué debería impulsar este contenido? (tráfico, clientes potenciales, ventas)" | Tráfico orgánico y clientes potenciales |

**PUNTO DE CONTROL: Confirma antes de diseñar la arquitectura de cluster.**

## Fase 2: Arquitectura de Cluster

### Mapa de Cluster Temático

Para cada tema principal, diseña un cluster:

```
## Cluster 1: [Tema Principal]

**Página Pilar:** "[Título de Guía Integral]"
- URL: /guides/[topic]
- Palabra clave objetivo: [keyword head/body]
- Conteo de palabras: 3,000-5,000 palabras
- Formato: Guía integral cubriendo todos los subtemas

**Posts de Cluster:**
1. "[Título de Subtema 1]" → /blog/[slug]
   - Palabra clave objetivo: [long-tail keyword]
   - Conteo de palabras: 1,500-2,000 palabras
   - Enlaces A pilar: [texto de anclaje]
   - Enlaces DESDE pilar: [sección donde aparece enlace]

2. "[Título de Subtema 2]" → /blog/[slug]
   - Palabra clave objetivo: [long-tail keyword]
   - Conteo de palabras: 1,500-2,000 palabras
   - Enlaces A pilar: [texto de anclaje]
   - Enlaces DESDE pilar: [sección]

3. "[Título de Subtema 3]" → /blog/[slug]
   ...

[8-15 posts de cluster por pilar]
```

### Mapa de Enlace Interno

```
## Arquitectura de Enlace

Página Pilar ←→ Cada post de cluster (bidireccional)
Posts de cluster → 2-3 posts otros en mismo tema (enlace cruzado)
Posts de cluster → 1 post de cluster en DIFERENTE tema (entre clusters)

Visual:
        [Post de Cluster 1] ←→ [Post de Cluster 2]
              ↕                    ↕
         [PÁGINA PILAR] ←→ [Post de Cluster 3]
              ↕                    ↕
        [Post de Cluster 4] ←→ [Post de Cluster 5]
```

### Priorización de Cluster

```
## Ranking de Prioridad de Cluster

| Tema de Cluster | Valor Comercial | Volumen de Palabra Clave | Competencia | Prioridad |
|--------------|---------------|---------------|-------------|----------|
| [Tema 1] | Alto | Alto | Medio | 1 — Construir primero |
| [Tema 2] | Alto | Medio | Bajo | 2 — Ganancias rápidas |
| [Tema 3] | Medio | Alto | Alto | 3 — Juego a largo plazo |
```

**PUNTO DE CONTROL: Aprueba la arquitectura de cluster antes de construir el calendario de contenido.**

## Fase 3: Calendario de Contenido

### Cronograma de Publicación

```
## Calendario de Contenido de 6 Meses

**Mes 1-2: Fundación de Cluster 1**
Semana 1: Publica Página Pilar
Semana 2: Post de Cluster 1
Semana 3: Post de Cluster 2
Semana 4: Post de Cluster 3
[Continúa a través del Mes 2]

**Mes 3-4: Fundación de Cluster 2**
Semana 1: Publica Página Pilar
[Continúa...]

**Mes 5-6: Expansión de Cluster 1 + Inicio de Cluster 3**
- Agrega 3-4 nuevos posts de cluster a Cluster 1
- Comienza pilar de Cluster 3 y primeros posts
```

### Plantillas de Brief de Contenido

Para cada pieza en el cluster, proporciona un mini-brief:
- Palabra clave objetivo
- Intención de búsqueda
- Conteo de palabras recomendado
- Secciones clave para cubrir
- Enlaces internos para incluir
- Enlace desde sección de página pilar

## Fase 4: Pulido

### 1. Auditoría de Contenido Existente

Mapea contenido existente en el framework de cluster:
- ¿Qué posts existentes encajan en qué cluster?
- ¿Qué posts necesitan actualización para coincidir con estrategia de cluster?
- ¿Qué posts están huérfanos y necesitan integración?

### 2. Plan de Medición

Sigue por cluster:
- Tráfico orgánico total al cluster (pilar + todos los posts)
- Rankings para palabra clave pilar y palabras clave de cluster
- Click-through de enlace interno entre páginas de cluster
- Atribución de cliente potencial/conversión a clusters específicos

### 3. Directrices de Escala

- Comienza con 1-2 clusters y construyelos completamente antes de agregar más
- Cada cluster necesita 8-15 posts antes de que señales de autoridad temática sean fuertes
- Actualiza páginas pilares trimestralmente a medida que se publica nuevo contenido de cluster
- Poda o fusiona posts de cluster con bajo desempeño anualmente

---

## Anti-Patrones

- **Páginas pilares demasiado delgadas** — una "guía definitiva" de 1,000 palabras no es integral. Las páginas pilares necesitan 3,000+ palabras con profundidad real.
- **Posts de cluster que no enlazan de nuevo** — cada post de cluster debe enlazar al pilar. Sin enlaces, el cluster es solo posts de blog aleatorios.
- **Demasiados clusters a la vez** — construir 5 clusters simultáneamente significa que ninguno está completo. El enfoque gana.
- **Temas superpuestos entre clusters** — si Cluster 1 y Cluster 2 tienen posts dirigidos a la misma palabra clave, se canibaliza entre sí.
- **Publicar y olvidar** — el contenido de cluster necesita actualización. Las páginas pilares desactualizadas pierden autoridad con el tiempo.

---

## Recuperación

- **Sin contenido existente:** Comienza con una página pilar y 3-4 posts de cluster. Construye el primer cluster antes de planificar otros.
- **El contenido existente está desorganizado:** Audita todo, categoriza por tema, y retroactivamente agrega enlaces internos para crear estructura de cluster.
- **La página pilar no está clasificando:** Verifica que los posts de cluster estén enlazándose a ella, el contenido sea genuinamente integral, y la palabra clave sea alcanzable para la autoridad de tu dominio.
- **Capacidad de publicación limitada (1-2 posts/mes):** Construye un cluster a la vez. Un cluster completo de 10 posts toma 5-10 meses a este ritmo, pero será efectivo.
