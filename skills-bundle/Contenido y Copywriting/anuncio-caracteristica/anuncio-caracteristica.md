# Anuncio de Característica

## Cuándo Usar Este Skill

Usa esta skill cuando necesites:
- Anunciar nueva característica de producto
- Escribir comunicado de prensa de producto
- Educar usuarios en cómo usar feature nueva
- Generar entusiasmo alrededor de release

## Principio Fundamental

UN ANUNCIO DE CARACTERÍSTICA EFECTIVO MUESTRA QUÉ ES LA CARACTERÍSTICA, POR QUÉ IMPORTA Y CÓMO ACCEDER.

## Estructura

**Titular** - Qué es (beneficio, no feature)

**Problema** - Qué dolor resuelve

**Solución** - Cómo funciona la feature

**Beneficios** - Por qué los usuarios lo quieren

**Cómo Acceder** - Instrucciones claras

**Testimonial o Ejemplo** - Caso de uso real

## Formato Opciones

**Blog Post** - Profundo con tutorial

**Comunicado de Prensa** - Formal y distribuible

**Email a Usuario** - Personal y actionable

**Post en Redes** - Breve y visual

## Anti-Patrones

- No uses jerga técnica sin explicación
- No olvides el beneficio del usuario - no solo la característica
- No hagas demasiado largo para anuncio inicial
- No olvides enlazar a docs o tutorial
