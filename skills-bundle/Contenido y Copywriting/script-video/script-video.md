# Script de Video

## Cuándo Usar Esta Habilidad

Usa esta habilidad cuando necesites:
- Escribir un script listo para filmar para YouTube, TikTok, Instagram Reels o contenido de curso
- Estructurar un talking head, tutorial o video de corta duración con segmentos apropiados y tiempo
- Agregar señales de producción como [B-ROLL], [TEXTO EN PANTALLA], y [CORTE A] para que creadores en solitario puedan filmar sin productor
- Convertir un tema, esquema o notas brutas en un script completo con hook, cuerpo y CTA
- Generar una lista de tomas para que el creador sepa cada configuración antes de presionar grabar

**NO** uses esta habilidad para scripts de podcast (solo audio, sin señales visuales), publicaciones de blog escritas o esquemas de transmisión en vivo donde el scripting mata la espontaneidad.

---

## Principio Fundamental

CADA SEGUNDO DE VIDEO DEBE GANAR EL SIGUIENTE SEGUNDO — SI EL ESPECTADOR NO TIENE RAZÓN PARA SEGUIR MIRANDO, SE VA.

---

## Referencia Rápida de Formato de Video

| Formato | Longitud Objetivo | Ritmo | Ventana de Hook | Segmentos |
|--------|-------------|--------|-------------|----------|
| YouTube larga duración | 8-15 min | Cambio visual cada 5-8 seg | Primeros 3 seg | 4-6 + intro/outro |
| Forma corta (Reel/TikTok) | 30-60 seg | Cambio visual cada 2-3 seg | Primeros 1-2 seg | Hook + 1-3 puntos + CTA |
| Tutorial | 5-10 min | Ritmo de pasos | Primeros 5 seg | Setup + 3-5 pasos + resumen |
| Talking Head | 3-5 min | Corte cada 10-15 seg | Primeros 3 seg | 2-3 segmentos + CTA |

---

## Fase 1: Brief

Recopila estos detalles antes de escribir cualquier cosa. Pide cualquier cosa que el usuario no proporcione.

1. **Tema** — el ángulo específico, no solo el tema amplio
2. **Formato** — YouTube larga duración, reel de forma corta, tutorial o talking head (predeterminado: YouTube larga duración)
3. **Longitud objetivo** — usa los valores predeterminados de referencia rápida si no se especifica
4. **Puntos clave** — 3-5 cosas que el video debe cubrir, en orden de prioridad
5. **CTA** — ¿qué debería hacer el espectador después de ver? (suscribirse, visitar enlace, comentar, intentar algo)
6. **Tono** — predeterminado: conversacional y directo, como explicar a un amigo inteligente
7. **Audiencia** — predeterminado: emprendedores y creadores en solitario

Presenta el brief de nuevo al usuario:

```
## Brief de Script

**Tema:** 5 herramientas que cada emprendedor necesita para ahorrar 10+ horas por semana
**Formato:** YouTube larga duración (8-10 minutos)
**Puntos clave:**
1. Gestión de proyectos (Notion)
2. Programación (Cal.com)
3. Automatización de email (Kit)
4. Diseño (Canva)
5. Asistente de escritura IA (Claude)
**CTA:** Suscribir + enlace a PDF de comparación de herramientas gratuitas en descripción
**Tono:** Conversacional, entusiasta pero no hype-y
**Audiencia:** Fundadores en solitario y freelancers en sus primeros 2 años
```

**PUNTO DE CONTROL: No procedas a Fase 2 hasta que el usuario confirme o ajuste el brief.**

---

## Fase 2: Estructura

Construye el esqueleto del script antes de escribir diálogo completo. Esto previene divagación y mantiene cada segmento propositivo.

### Fórmula de Hook (Primeros 3 Segundos)

Elige el tipo de hook que mejor se ajuste al tema:

| Tipo de Hook | Estructura | Mejor Para |
|-----------|-----------|----------|
| **Interrupción de patrón** | Di/muestra algo inesperado que rompa el scroll | Forma corta, entretenimiento |
| **Afirmación audaz** | Declara un resultado específico o provocador u opinión | Larga duración, contenido de autoridad |
| **Pregunta directa** | Haz una pregunta que tu audiencia objetivo no pueda ignorar | Tutoriales, contenido de cómo hacer |

**Reglas de hook:**
- **NUNCA** comiences con "Hola chicos, bienvenidos a mi canal" — salto instantáneo
- **NUNCA** comiences con "En este video voy a..." — muestra, no previsualizces
- El hook debe funcionar con SIN contexto — asume que el espectador no te conoce

### Plantilla de Esquema

Construye y presenta esta estructura:

```
## Esquema de Script

**Hook (0-3 seg):** [Hook statement]

**Segmento 1: [Título] (0:03-2:00)**
- Punto principal: [qué cubre]
- Evidencia: [ejemplo, estadístico o historia]
- Transición a Segmento 2: [cómo conectar]

**Segmento 2: [Título] (2:00-4:30)**
[Estructura similar]

**Segmento 3: [Título] (4:30-7:00)**
[Estructura similar]

**Resumen (7:00-8:00)**
[Recapitulación rápida de puntos]

**CTA (8:00-8:30)**
[Lo que hacer después]

**Outro (8:30-8:45)**
[Música, gracias, subscripción]
```

**PUNTO DE CONTROL: Presenta esquema para aprobación antes de escribir script completo.**

## Fase 3: Escritura

### Formato de Script

```
# 5 Herramientas Que Todo Emprendedor Necesita

**Hook (0-3 seg):**
"Si pasas más de 40 horas a la semana en tu negocio, casi el 25% de ese tiempo desaparece en tareas que una herramienta simple podría eliminar. Aquí están las 5 que uso para recuperar 10+ horas por semana."

[B-ROLL: Montaje rápido de dashboards de herramientas]
[TEXTO EN PANTALLA: "5 HERRAMIENTAS PARA AHORRAR 10+ HORAS"]

---

**Segmento 1: Notion para Gestión de Proyectos (0:03-2:00)**

"Primero es Notion. Pasé años saltando entre Asana, Monday y Trello. Notion consolidó todo — proyectos, bases de datos, notas — en un lugar."

[CORTE A: Pantalla de Notion mostrando base de datos de proyecto]
[TEXTO EN PANTALLA: "Consolidar herramientas = 3 horas ahorradas/mes"]

"La primera vez que configuré Notion, tardé 4 horas. Pero esas 4 horas ahorran 3 horas cada mes, para siempre. Aquí está cómo hacerlo."

[B-ROLL: Tiempo rápido de configuración de base de datos]

---

**Transición a Segmento 2:**
"Pero gestión de proyectos no es todo. La siguiente cosa que me mata es la programación de reuniones."
```

### Anti-Patrones

- **Guiones demasiado escritos** — suena robótico, usa palabras conversacionales
- **Sin señales de producción** — los creadores no saben qué filmar
- **Demasiado contenido** — los videos aburridos pierden espectadores
- **Sin CTA claro** — no esperes que los espectadores adivinen qué hacer después
- **Transiciones abruptas** — cada segmento necesita un puente al siguiente

---

## Recuperación

- **El usuario no tiene segmentos claros:** Ayuda a identificar 3-5 puntos principales y estructura alrededor de esos
- **El script es demasiado largo:** Corta ejemplos o divide en Parte 1 y Parte 2
- **El usuario quiere estructura diferente:** Ofrece alternativas (problema-solución, lista numerada, cronología)
- **Sin idea de qué filmar:** Crea una lista de tomas con cada segmento
