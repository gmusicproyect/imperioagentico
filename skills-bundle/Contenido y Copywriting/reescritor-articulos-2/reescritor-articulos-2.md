# Reescritor de Artículos

## Cuándo Usar Esta Habilidad

Usa esta habilidad cuando necesites:
- Refrescar una publicación de blog desactualizada con datos actuales y estructura mejorada
- Reescribir un artículo con un nuevo ángulo para una audiencia diferente
- Mejorar el desempeño SEO del contenido existente que ha perdido rankings
- Actualizar un artículo estilo competencia en contenido original de mayor calidad

**NO** uses esta habilidad para hacer girar o plagiar contenido. Esta habilidad produce contenido genuinamente reescrito que agrega nuevo valor.

---

## Principio Fundamental

UNA REESCRITURA DEBE HACER EL CONTENIDO SIGNIFICATIVAMENTE MEJOR — NO SOLO DIFERENTE. SI LA REESCRITURA NO AGREGA NUEVO VALOR, ES PÉRDIDA DE TIEMPO.

---

## Fase 1: Análisis Inicial

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Artículo original** | "Pega el artículo o proporciona la URL." | No hay predeterminado — debe proporcionarse |
| **Objetivo de reescritura** | "¿Por qué reescribes? Refresco SEO, nueva audiencia, información actualizada, mejor calidad?" | Refresco SEO |
| **Palabra clave objetivo** | "¿Qué palabra clave debería dirigir la versión reescrita?" | Igual que la original |
| **Audiencia** | "¿Misma audiencia u diferente?" | Misma audiencia |
| **Qué mantener** | "¿Alguna sección, ejemplo o datos que deben mantenerse?" | Preservar mensaje y estructura central |
| **Qué cambiar** | "¿Qué específicamente necesita mejorar?" | Discreción del usuario — auditará |
| **Conteo de palabras** | "¿Longitud objetivo para la reescritura?" | Coincide con original +/- 20% |

**PUNTO DE CONTROL: Confirma brief y revisa artículo original antes de proceder.**

## Fase 2: Auditoría y Plan

### Auditoría de Contenido

Antes de reescribir, analiza el artículo original en estas dimensiones:

```
## Auditoría de Contenido

**Fortalezas (mantén estas):**
- [Lo que funciona bien — secciones fuertes, buenos ejemplos, estructura sólida]

**Debilidades (arregla estas):**
- [Datos desactualizados, intro débil, formato pobre, secciones faltantes]

**Problemas SEO:**
- [Colocación de palabra clave, meta descripción, estructura de encabezado, densidad]

**Problemas Estructurales:**
- [Problemas de flujo, transiciones faltantes, secciones de pared de texto]

**Elementos Faltantes:**
- [Ejemplos, datos, enlaces internos, CTA, visuals]
```

### Plan de Reescritura

```
## Plan de Reescritura

**Nuevo ángulo/hook:** [Cómo la reescritura abrirá diferente]
**Secciones a mantener (con actualizaciones):** [Lista]
**Secciones a reescribir completamente:** [Lista]
**Secciones a agregar:** [Lista]
**Secciones a cortar:** [Lista]
**Nuevos datos o ejemplos para incluir:** [Lista]
```

**PUNTO DE CONTROL: Presenta auditoría y plan para aprobación antes de reescribir.**

---

## Fase 3: Escritura

### Reglas de Reescritura

| Regla | Detalle |
|------|--------|
| **Nunca copiar-pegar párrafos** | Cada párrafo debe reescribirse, no reorganizarse |
| **Intro nueva requerida** | El párrafo de apertura debe ser completamente original |
| **Agrega nuevo valor** | Incluye al menos 2 nuevos ejemplos, puntos de datos o perspectivas no en original |
| **Mejora estructura** | Arregla jerarquía de encabezados, agrega listas donde el texto es denso |
| **Actualiza datos** | Reemplaza estadísticas desactualizadas con las actuales (nota fuentes) |
| **Reescribe transiciones** | Las nuevas transiciones deben conectar diferentes puntos de datos |
| **Optimiza para palabra clave** | Asegura colocación en H1, primeras 100 palabras, y distribución natural |

## Fase 4: Pulido

### 1. Lista de Verificación de Reescritura

```
## Lista de Verificación de Reescritura

- [ ] Intro completamente original (no reutilizada de original)
- [ ] Estructura mejorada (encabezados más claros, mejor flujo)
- [ ] Al menos 2 nuevos ejemplos o datos añadidos
- [ ] Todas las estadísticas actualizadas y fuentes notadas
- [ ] Palabra clave objetivo optimizada (H1, primeras 100 palabras)
- [ ] Longitud dentro del 20% del original
- [ ] Sin párrafos copiados del original
- [ ] CTA clara al final
```

### 2. Checklist de Mejora de Valor

- ¿Proporciona la reescritura perspectiva fresca? (no solo reorganización)
- ¿Hay nuevos datos o ejemplos? (al menos 2)
- ¿Es más útil que el original?
- ¿Es mejor organizado que el original?

---

## Anti-Patrones

- **Reorganizar sin reescribir** — cambiar el orden de párrafos sin nuevas palabras no es una reescritura
- **Cambiar solo algunos párrafos** — parece obvio que es un plagio ligero
- **Mantener los mismos ejemplos** — los nuevos ejemplos son vitales
- **Ignorar datos desactualizados** — si el original tiene datos de 2020, actualiza

---

## Recuperación

- **Original es realmente pobre:** Considera si debe reescribirse o simplemente reemplazarse con contenido completamente nuevo
- **Es difícil encontrar nuevos datos:** Entrevista expertos, cita investigación reciente, o incluye tu perspectiva personal
- **El usuario quiere múltiples ángulos:** Crea 2-3 versiones diferentes dirigidas a audiencias diferentes

## Checklist de Reescritura Completa

```
## Validación de Reescritura

- [ ] Intro completamente reescrita (diferentes palabras clave de apertura)
- [ ] Al menos 2 nuevos ejemplos o datos agregados
- [ ] Ningún párrafo copiado directamente del original
- [ ] Estructura mejorada o reorganizada
- [ ] Todas las estadísticas actualizadas con fechas de fuente
- [ ] Nuevas secciones agregadas o secciones débiles expandidas
- [ ] Transiciones reescritas (no solo reutilizadas)
- [ ] Palabra clave objetivo optimizada en H1, primeras 100 palabras
- [ ] CTA clara y diferente de original
- [ ] Longitud dentro de 20% del original (o justificadamente diferente)
```

## Diferenciación vs. Original

La reescritura debe pasar estas pruebas:
- Un lector que conoce el artículo original nota cambios sustanciales
- El nuevo ángulo o perspectiva es evidentes
- Los nuevos datos o ejemplos proporcionan valor fresco
- El artículo reescrito funcionaría bien si el original desapareciera

## Gestión de Cambios SEO

Cuando reescribas un artículo existente:
- Mantén la misma URL (sin 301 redirecciones)
- Actualiza meta descripción para reflejar nuevos datos/ángulo
- Agrega enlaces internos a contenido nuevo relacionado
- Nota cambios significativos en comentario editorial si aplica
- Monitora rankings por 2-3 semanas después de publicar para ver si mejoran

Una buena reescritura típicamente hace:
- Aumento en CTR desde buscadores (nueva meta descripción)
- Aumento en tiempo en página (mejor contenido)
- Mejor ubicación para palabras clave de cola larga relacionadas
