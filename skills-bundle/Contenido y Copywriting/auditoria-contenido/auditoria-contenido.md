# Auditoría de Contenido

## Cuándo Usar Este Skill

Usa esta skill cuando necesites:
- Auditar una librería de blog o contenido existente para desempeño y calidad
- Identificar contenido desactualizado que necesita actualización o removido
- Encontrar brechas de contenido y oportunidades para nuevas piezas
- Consolidar artículos delgados o superpuestos en piezas más fuertes

**NO** uses esta skill para crear nuevo contenido o para investigación de palabras clave SEO. Esto es para evaluar y priorizar contenido existente.

## Principio Fundamental

UNA AUDITORÍA DE CONTENIDO NO ES UN EJERCICIO DE SPREADSHEET -- ES UNA DECISIÓN ESTRATÉGICA SOBRE QUÉ ACTUALIZAR, QUÉ FUSIONAR, QUÉ ELIMINAR Y QUÉ CREAR SIGUIENTE.

## Fase 1: Brief

### Inputs Requeridos

| Input | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Inventario de contenido** | "Comparte una lista de tu contenido publicado (URLs, títulos o un sitemap)." | Sin predeterminado -- debe ser proporcionado |
| **Datos de desempeño** | "¿Tienes datos de tráfico, ranking o engagement para estas piezas?" | Ninguno -- audita basado en calidad de contenido |
| **Metas de negocio** | "¿Cuál es la meta primaria de tu contenido? ¿Tráfico, leads, ventas, autoridad?" | Tráfico orgánico |
| **Alcance de auditoría** | "¿Todo contenido o una sección/categoría específica?" | Todo contenido |
| **Audiencia** | "¿Quién es tu lector objetivo?" | Solopreneurs y dueños de negocio |

**PUNTO DE CONTROL:** Confirma alcance e inputs antes de iniciar auditoría.

## Fase 2: Marco de Auditoría

### Categoriza Cada Pieza

Asigna cada pieza de contenido a una de cinco acciones:

| Categoría | Criterios | Acción |
|----------|----------|--------|
| **Mantener** | Alto desempeño, actual y relevante | Sin cambios necesarios |
| **Actualizar** | Buen tópico pero datos desactualizados, estructura débil o decaimiento SEO | Refresco con info actual y formato mejorado |
| **Fusionar** | Dos o más piezas cubriendo mismo tópico | Consolidar en un artículo más fuerte |
| **Eliminar** | Contenido delgado, irrelevante o redundante sin tráfico | Remover (301 redirect si tiene backlinks) |
| **Crear** | Brecha identificada -- sin contenido existe para tópico importante | Agregar a roadmap de contenido |

## Anti-Patrones

- **Auditar sin meta** -- "auditar todo" lleva a spreadsheet que nadie actúa. Define meta de negocio primero.
- **Solo mirando tráfico** -- una pieza con tráfico bajo podría tener alto valor de conversión. Considera múltiples métricas.
- **Mantener todo** -- apego emocional a contenido viejo previene mejora. Sé dispuesto a eliminar.
- **Sin plan de acción** -- auditoría sin plan de acción priorizado es solo un inventario. Siempre termina con próximos pasos.
- **Auditar demasiado frecuentemente** -- mini-auditorías trimestrales son finas. Auditorías completas más de una vez al año crean auditoría fatiga.
