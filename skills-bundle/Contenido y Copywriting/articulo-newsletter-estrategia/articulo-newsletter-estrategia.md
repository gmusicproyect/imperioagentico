# Estrategia de Newsletter

## Cuándo Usar Esta Skill

Usa esta skill cuando necesites:
- Planificar una nueva newsletter de correo desde cero (cadencia, temas, formato)
- Reestructurar una newsletter de bajo rendimiento con una estrategia clara
- Construir un plan de crecimiento de suscriptores con tácticas específicas
- Diseñar una ruta de monetización para una publicación de correo electrónico

**NO USES** esta skill para escribir ediciones individuales de newsletter o copia de correo electrónico. Esto es solo para planificación estratégica.

---

## Principio Fundamental

UNA NEWSLETTER QUE INTENTA SERLO TODO TERMINA SIENDO NADA — DEFINE UNA PROPUESTA DE VALOR CLARA Y ENTREGA CONSISTENTEMENTE.

---

## Fase 1: Resumen Inicial

### Información Requerida

| Entrada | Qué Preguntar | Predeterminado |
|---------|---------------|--------|
| **Nombre de newsletter** | "¿Cómo se llama la newsletter (o nombre de trabajo)?" | Sin predeterminado — debe proporcionarse |
| **Propuesta de valor** | "En una oración, ¿por qué alguien debería suscribirse?" | Sin predeterminado — debe proporcionarse |
| **Audiencia** | "¿Quién es el suscriptor ideal?" | Emprendedores individuales y dueños de negocios |
| **Cadencia** | "¿Con qué frecuencia puedes enviar realísticamente? ¿Diariamente, semanalmente, quincenalmente?" | Semanal |
| **Tamaño de lista actual** | "¿Cuántos suscriptores tienes hoy?" | 0 — comenzando desde cero |
| **Modelo de negocio** | "¿Cómo gana dinero tu negocio? ¿Qué vendes?" | Productos digitales o servicios |
| **Tiempo por edición** | "¿Cuántas horas puedes dedicar a escribir cada edición?" | 2-3 horas |

**PUNTO DE CONTROL: Confirma el resumen antes de construir la estrategia.**

---

## Fase 2: Esquema

### Secciones de Estrategia

```
1. Identidad de Newsletter — nombre, lema, propuesta de valor, posicionamiento
2. Marco de Contenido — secciones recurrentes, temas, plantilla de formato
3. Cadencia de Publicación — horario, días/horas de envío, reglas de consistencia
4. Plan de Crecimiento — tácticas para alcanzar los primeros 1,000 suscriptores
5. Estrategia de Monetización — cómo la newsletter soporta ingresos
6. Tech Stack — plataforma, automatización, analítica
```

**PUNTO DE CONTROL: Aprueba el esquema antes de la estrategia detallada.**

## Fase 3: Escribir

### 1. Identidad de Newsletter

```
## Identidad de Newsletter

**Nombre:** [Nombre de newsletter]
**Lema:** [Una oración — qué recibe el lector]
**Propuesta de valor:** "Suscríbete a [Nombre] para [valor específico] cada [cadencia]."
**Posicionamiento:** [Cómo esto es diferente de otras newsletters en el nicho]
**Tono:** [Conversacional / profesional / ingenioso / etc.]
```

### 2. Marco de Contenido

Define 3-5 secciones recurrentes que aparezcan en cada edición:

```
## Marco de Contenido

**Sección 1: [Nombre]** — [Descripción, ej., "Un consejo accionable con un ejemplo"]
**Sección 2: [Nombre]** — [Descripción, ej., "Enlace curado de la semana con comentario"]
**Sección 3: [Nombre]** — [Descripción, ej., "Victoria rápida — algo que pueden implementar en 5 minutos"]
**Sección 4: [Nombre]** — [Descripción, ej., "Pregunta del lector respondida"]
**Sección 5: [Nombre]** — [Descripción, ej., "CTA o mención de producto"]

**Largo de la edición:** [Meta de recuento de palabras, ej., 500-800 palabras]
**Meta de tiempo de lectura:** [ej., 3-5 minutos]
```

### 3. Plan de Crecimiento

Proporciona tácticas organizadas por fase:

```
## Plan de Crecimiento

### Fase 1: Primeros 100 Suscriptores (Semanas 1-4)
- Alcance personal a la red existente (correo electrónico, DM, texto)
- Añade opt-in a la firma de correo electrónico
- Crea un lead magnet vinculado al tema de la newsletter
- Anuncia en todos los canales sociales existentes

### Fase 2: 100-500 Suscriptores (Meses 2-3)
- Co-promociones con newsletters complementarias
- Contenido invitado en blogs y podcasts con CTA para suscribirse
- Optimiza sitio web con pop-up/banner para newsletter
- Comparte ediciones individuales en redes sociales como avances

### Fase 3: 500-1,000 Suscriptores (Meses 3-6)
- Programa de referidos (incentivo de recomendación a amigos)
- Anuncios pagados en redes sociales dirigidos al perfil de suscriptor ideal
- Webinars de asociación o contenido co-creado
- Páginas de archivo optimizadas para SEO de ediciones pasadas
```

### 4. Estrategia de Monetización

```
## Ruta de Monetización

**Etapa 1 (0-1,000 suscriptores):** Sin monetización directa — enfócate en consistencia y crecimiento
**Etapa 2 (1,000-5,000 suscriptores):** Promueve tus propios productos/servicios en cada edición
**Etapa 3 (5,000+ suscriptores):** Añade contenido patrocinado y/o nivel de suscripción pagado

**Fuentes de ingresos:**
1. Promoción de producto propio — [producto específico y cómo la newsletter impulsa ventas]
2. Recomendaciones de afiliados — [productos relevantes para recomendar con enlaces de afiliado]
3. Secciones patrocinadas — [sugerencia de tarifa de tasa basada en el tamaño de la lista]
4. Nivel pagado — [contenido premium que justifique una tarifa de suscripción]
```

## Fase 4: Pulir

### 1. Lista de Verificación de Estrategia

```
## Lista de Verificación de Estrategia de Newsletter

- [ ] La propuesta de valor es clara en una oración
- [ ] El marco de contenido tiene 3-5 secciones recurrentes
- [ ] Cada edición puede ser producida dentro del presupuesto de tiempo establecido
- [ ] El plan de crecimiento tiene tácticas específicas para cada fase
- [ ] La estrategia de monetización se alinea con el modelo de negocio
- [ ] Se recomienda tech stack con razón
- [ ] La cadencia de envío es realista y sostenible
- [ ] Los primeros 4 temas de edición están pre-planificados
- [ ] La secuencia de correo de bienvenida está esbozada
- [ ] Se definen las métricas de éxito (tasa de apertura, tasa de clic, tasa de crecimiento)
```

### 2. Primeros 4 Temas de Edición

Pre-planifica el primer mes de ediciones para que el usuario pueda lanzarse inmediatamente.

### 3. Esquema de Correo de Bienvenida

```
## Correo de Bienvenida

**Asunto:** Bienvenido a [Nombre de Newsletter] — aquí está lo que esperar
**Cuerpo:**
- Qué recibirán y cuándo
- Qué hace esta newsletter diferente
- Un consejo o recurso inmediatamente útil (entrega valor en correo 1)
- Pídeles que respondan con una pregunta o que muevan el correo a bandeja de entrada principal
```

## Ejemplo: Newsletter para un Diseñador Web Freelance

```
Nombre: Design Clients Weekly
Lema: Un consejo de diseño freelance + una táctica para conseguir clientes, cada martes.
Propuesta de valor: "Obtén los consejos de marketing y negocios que la escuela de diseño nunca te enseñó."

Secciones:
1. El Consejo — un insight accionable del negocio de diseño
2. Conseguidor de Clientes — una táctica para aterrizar un nuevo cliente esta semana
3. Herramienta de la Semana — una herramienta que ahorra tiempo o dinero
4. El CTA — enlaces al curso o servicio del autor
```

## Anti-Patrones

- **Sin formato consistente** — los lectores se suscriben por predictibilidad. Los formatos aleatorios confunden y generan desuscripciones.
- **Demasiado largo** — las newsletters de más de 1,000 palabras pierden lectores casuales. Respeta su tiempo.
- **Sin plan de crecimiento** — "Solo lo publicaré en redes sociales" no es una estrategia. Sé específico sobre tácticas.
- **Monetizar demasiado pronto** — una promoción pesada con una lista de 200 personas daña la confianza antes de que se construya.
- **Cadencia inconsistente** — saltar semanas mata el momentum y la capacidad de entrega. Elige una cadencia que puedas sostener.
- **Sin correo de bienvenida** — el primer correo establece expectativas. Saltarlo desperdicia el momento de mayor engagement.

---

## Recuperación

- **Sin tiempo para escribir semanalmente:** Cambia a quincenalmente o cursa en lugar de crear contenido original. Una newsletter quincenalsostenida supera a una semanal inconsistente.
- **La lista no está creciendo:** Audita el opt-in — ¿es clara la propuesta de valor? ¿Es atractivo el lead magnet? ¿Lo están promoviendo regularmente?
- **Tasas de apertura bajas:** Prueba líneas de asunto, limpia la lista de suscriptores inactivos y asegúrate de que la hora de envío coincida con la audiencia.
- **Sin ideas de monetización:** Comienza con promover un servicio o producto que ya venden. La newsletter es la parte superior del funnel de ventas, no el producto en sí.
- **No puedo elegir un nicho:** Lista 10 temas sobre los que podrías escribir para siempre. Haz referencia cruzada con demanda de audiencia. La superposición es el nicho.
