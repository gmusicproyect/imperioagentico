# Artículo de Comparación

## Cuándo Usar Este Skill

Usa esta skill cuando necesites:
- Escribir un artículo de comparación "X vs Y" para dos productos, herramientas o enfoques
- Crear una comparación de múltiples opciones (formato "Mejor X para Y")
- Producir contenido con intención de comprador que tenga ranking para consultas de comparación
- Construir tablas de características, listas de pros/contras y secciones de recomendación

**NO** uses esta skill para reseñas de un único producto o listicles de herramientas no relacionadas. Esto es para comparaciones head-to-head o de múltiples opciones.

## Principio Fundamental

UN ARTÍCULO DE COMPARACIÓN DEBE AYUDAR AL LECTOR A TOMAR UNA DECISIÓN -- NO SOLO LISTAR CARACTERÍSTICAS. TODA SECCIÓN DEBERÍA MOVERLOS MÁS CERCA DE ELEGIR.

## Estructura de Artículo de Comparación

```
**H1:** [Item A] vs [Item B]: [Ángulo diferenciador o audiencia]

**Veredicto Rápido** (~100 palabras) -- recomendación TL;DR en la parte superior

**H2: Resumen** (~200 palabras)
- Breve intro a ambas opciones y por qué la gente las compara

**H2: [Criterio de Comparación 1]** (~300 palabras)
- Análisis [Item A]
- Análisis [Item B]
- Ganador para este criterio

**H2: Tabla de Comparación de Características**
- Matriz lado a lado

**H2: Comparación de Pricing** (~200 palabras)

**H2: Quién Debería Elegir [Item A]** (~150 palabras)
**H2: Quién Debería Elegir [Item B]** (~150 palabras)

**H2: Veredicto Final** (~150 palabras)
```

## Reglas de Escritura

| Regla | Detalle |
|------|--------|
| **Sé específico** | "ConvertKit comienza en $29/mes para 1,000 suscriptores" no "ConvertKit es asequible" |
| **Nombra ganadores** | Cada sección de criterio debe declarar un ganador (los empates se permiten con explicación) |
| **Usa screenshots/callouts** | Marca dónde deben aparecer comparaciones de screenshot |
| **Divulga sesgo** | Si el autor usa un producto, dilo al frente |
| **Enlaza a ambos** | Incluye enlaces a ambas opciones (afiliado o directo) |

## Anti-Patrones

- **Sin ganadores claros** -- "¡Ambos son excelentes!" ayuda a nadie a decidir. Nombra ganador para cada criterio o explica el empate.
- **Listado de característica sin contexto** -- "ConvertKit tiene automatización" es inútil. "El constructor de automatización visual de ConvertKit te permite crear una secuencia de email de bienvenida de 5 emails en 10 minutos" es útil.
- **Pricing desactualizado** -- nada mata credibilidad más rápido. Verifica pricing antes de publicar.
- **Sesgo oculto** -- si eres afiliado o usas un producto, divúlgalo. Los lectores detectan sesgo oculto.
- **Sin recomendaciones de caso de uso** -- características no ayudan lectores a decidir. Casos de uso sí.
- **Comparaciones de pared de texto** -- tablas y bullets hacen comparaciones escaneables. Úsalos.
