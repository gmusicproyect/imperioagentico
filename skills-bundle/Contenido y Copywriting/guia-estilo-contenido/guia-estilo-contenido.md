# Guía de Estilo de Contenido

## Cuándo Usar Esta Habilidad

Usa esta habilidad cuando necesites:
- Crear una guía de estilo de marca para contenido escrito (gramática, tono, formato)
- Estandarizar cómo tu negocio se comunica en todos los canales escritos
- Incorporar nuevos escritores o miembros del equipo con reglas editoriales claras
- Documentar preferencias de palabras, frases prohibidas y convenciones de formato

**NO** uses esta habilidad para directrices visuales de marca (logos, colores, tipografía). Esto es solo para reglas de contenido editorial y escrito.

---

## Principio Fundamental

UNA GUÍA DE ESTILO DEBE SER LO SUFICIENTEMENTE BREVE PARA CONSULTARLA EN 5 MINUTOS Y ESPECÍFICA SUFICIENTE PARA RESOLVER CUALQUIER PREGUNTA DE ESCRITURA SIN UNA REUNIÓN.

---

## Fase 1: Análisis Inicial

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|---------|-----------------|---------|
| **Nombre del negocio** | "¿Cuál es tu nombre de negocio o marca?" | No hay predeterminado — debe proporcionarse |
| **Canales de contenido** | "¿Dónde aparece tu contenido? ¿Blog, email, redes sociales, documentos?" | Blog + email + redes sociales |
| **Referencias de estilo existentes** | "Comparte 2-3 piezas de contenido que representen cómo quieres sonar." | Ninguno — se construirá desde cero |
| **Audiencia** | "¿Quién lee tu contenido?" | Emprendedores y propietarios de pequeños negocios |
| **Palabras clave de tono** | "Elige 3-5 palabras que describan cómo debería sonar tu marca." | Directo, amigable, confiado |
| **Puntos débiles** | "¿Qué inconsistencias de escritura te molestan más?" | Ninguno identificado |

**PUNTO DE CONTROL: Confirma el análisis inicial antes de construir la guía.**

---

## Fase 2: Esquema

### Secciones de la Guía de Estilo

```
1. Voz y Tono de Marca
2. Preferencias Gramaticales y de Puntuación
3. Reglas de Formato
4. Lista de Palabras (términos preferidos y frases prohibidas)
5. Directrices Específicas por Canal
6. Errores Comunes a Evitar
```

**PUNTO DE CONTROL: Aprueba la estructura de secciones antes de escribir.**

## Fase 3: Escritura

### 1. Voz y Tono de Marca

```
## Voz de Marca

**Sonamos como:** [Descripción concreta — p. ej., "Un amigo inteligente que dirige un negocio"]
**NO sonamos como:** [Contraejemplo concreto — p. ej., "Un comunicado de prensa corporativo"]

### Características de Voz

| Característica | Descripción | Ejemplo | Anti-Ejemplo |
|-------|-------------|---------|-------------|
| [p. ej., Directo] | [Ve al grano rápido] | "Así es cómo solucionarlo." | "En esta sección, exploraremos soluciones potenciales." |
| [p. ej., Confiado] | [Declara opiniones, no dudes] | "Este es el mejor enfoque." | "Esto podría ser potencialmente digno de consideración." |
| [p. ej., Conversacional] | [Escribe como hablas] | "Analicemos esto." | "El siguiente análisis demostrará..." |

### Ajustes de Tono por Contexto

| Contexto | Cambio de Tono |
|---------|-----------|
| Publicaciones de blog | Más casual — la personalidad brilla |
| Emails | Cálido y directo — como escribir a un colega |
| Redes sociales | Conciso y punzante — engancha rápido |
| Atención al cliente | Empático y claro — resuelve el problema |
| Legal / políticas | Profesional y preciso — sin ambigüedad |
```

### 2. Gramática y Puntuación

```
## Preferencias Gramaticales

| Regla | Preferencia |
|------|-----------|
| Coma de Oxford | [Sí / No] |
| Contracciones | [Usa libremente / Evita / Depende del contexto] |
| Fragmentos de oraciones | [Permitidos en contenido casual / Nunca] |
| Guiones largos | [Usa para énfasis / Evita] |
| Signos de exclamación | [Máx. 1 por pieza / Nunca / Ocasionalmente] |
| Números | [Deletrea 1-9, dígitos para 10+ / Siempre dígitos] |
| Porcentaje | [Símbolo % / "por ciento" deletreado] |
| Ampersands | [Nunca en texto de cuerpo / OK en encabezados] |
| Puntos suspensivos | [Evita / OK en contenido casual] |
```

### 3. Reglas de Formato

```
## Formato

| Elemento | Regla |
|---------|------|
| Encabezados | Caso de oración ("Cómo escribir un pitch") no mayúsculas de título |
| Negrita | Usa para frases clave que los lectores no deben perder |
| Cursiva | Usa para énfasis o introducir términos nuevos |
| Listas | Viñetas para sin orden, números para secuencial |
| Párrafos | 2-4 oraciones máximo |
| Enlaces | Texto de anclaje descriptivo, nunca "haz clic aquí" |
| CTAs | Negrita, orientado a la acción, uno por sección |
```

### 4. Lista de Palabras

```
## Lista de Palabras

### Términos Preferidos
| Usa Esto | No Esto |
|----------|---------|
| [p. ej., "emprendedor"] | [p. ej., "propietario único"] |
| [p. ej., "ingresos"] | [p. ej., "renta" o "ganancias"] |
| [p. ej., "clientes"] | [p. ej., "usuarios" o "consumidores"] |

### Frases Prohibidas
- "En el mundo actual..."
- "Se sobreentiende..."
- "Al final del día..."
- "Aprovechar" (como verbo)
- "Sinergia" / "Sinergizar"
- "Comunicarse"
- "Volver a revisar"
- [Adiciones específicas del usuario]

### Reglas de Jerga Técnica
- Define términos técnicos en el primer uso
- Nunca supongas que el lector conoce acrónimos — deletrea en la primera referencia
- [Permitencias específicas de jerga para esta marca]
```

### 5. Directrices Específicas por Canal

```
## Directrices de Canal

### Blog
- Objetivo: [rango de palabras]
- Siempre incluye: meta descripción, enlaces internos, breve de imagen destacada
- Jerarquía de encabezados: H1 > H2 > H3 (nunca saltes niveles)

### Email
- Líneas de asunto: menos de 50 caracteres
- Cuerpo: menos de 300 palabras para promocional, menos de 800 para newsletter
- Siempre incluye: texto de vista previa, un CTA, línea P.S.

### Redes Sociales
- Orientación de caracteres específica por plataforma
- Reglas de hashtags por plataforma
- Reglas de colocación de enlaces
```

### 6. Errores Comunes

```
## Errores Comunes a Evitar

1. **Voz pasiva** — "El informe fue escrito por el equipo" → "El equipo escribió el informe"
2. **Lenguaje de cobertura** — "Creemos que esto podría ayudar" → "Esto ayudará"
3. **Frases redundantes** — "Regalo gratis" (los regalos son gratis), "Resultado final" (los resultados están al final)
4. **Nominalizaciones** — "Tomar una decisión" → "Decidir"
5. **Empezar con "Creo que"** — Solo declara la opinión
```

## Fase 4: Pulido

### 1. Lista de Verificación de Guía de Estilo

```
## Lista de Verificación de Guía de Estilo

- [ ] La descripción de voz incluye ejemplos concretos y anti-ejemplos
- [ ] Las preferencias gramaticales cubren las 10 preguntas más comunes
- [ ] Las reglas de formato son específicas y viables
- [ ] La lista de palabras incluye términos preferidos y frases prohibidas
- [ ] Se incluyen directrices específicas del canal para cada plataforma activa
- [ ] La sección de errores comunes aborda problemas reales (no consejos genéricos)
- [ ] La guía tiene menos de 5 páginas (amigable para consultar, no un libro de texto)
- [ ] Hay al menos 3 comparaciones "Ejemplo vs Anti-Ejemplo" en toda la guía
```

## Ejemplo: Guía de Estilo para una Startup SaaS

```
Voz: Mentor confiado — hemos hecho esto y queremos ayudarte a hacerlo también
No: Equipo de PR corporativo leyendo un guión

Preferido: "Inicia tu prueba gratuita" No: "Comience su período de prueba complementario"
Preferido: "panel" No: "interfaz de usuario" o "panel de control"

Coma de Oxford: Sí
Contracciones: Siempre en blog/redes, evita en documentos legales
Números: Dígitos siempre (incluso 1-9) para facilidad de escaneo
```

---

## Anti-Patrones

- **Demasiado larga** — una guía de estilo de 30 páginas nunca será leída. Mantenla bajo 5 páginas.
- **Demasiado vaga** — "Sé profesional pero amigable" es inútil sin ejemplos. Muestra, no solo digas.
- **Sin ejemplos** — cada regla necesita un par "haz esto / no hagas esto" o será interpretada diferentemente por cada escritor.
- **Referencias desactualizadas** — las guías de estilo necesitan revisiones anuales. Marca la fecha de revisión.
- **Ignorar diferencias de canal** — el mismo tono no funciona en TikTok y en contratos legales. Aborda cambios de canal.

---

## Recuperación

- **Sin contenido existente para consultar:** Escribe 3 párrafos de muestra en diferentes tonos. Haz que el usuario elija la coincidencia más cercana y construye la guía a partir de eso.
- **Demasiadas stakeholders con opiniones:** Enfócate en las 10 reglas que causan el 90% de las inconsistencias. Pospón casos límite al criterio del editor.
- **La guía se está poniendo demasiado larga:** Elimina cualquier cosa que duplique los estilos AP o Chicago. Solo documenta desviaciones de la práctica estándar y reglas específicas de la marca.
- **El escritor sigue ignorando la guía:** Agrega las 5 reglas principales a una lista de verificación pre-publicación. Hazlo un punto de control, no una sugerencia.
