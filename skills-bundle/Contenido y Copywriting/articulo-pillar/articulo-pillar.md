# Página Pilar

## Cuándo Usar Esta Skill

Usa esta skill cuando necesites:
- Escribir una página pilar comprehensiva (3,000-5,000 palabras) que cubra un tema amplio
- Construir un centro de contenido que enlace a publicaciones de blog de cluster relacionado
- Crear una pieza angular diseñada para clasificarse para una palabra clave competitiva de alto volumen
- Establecer autoridad temática a través de un único recurso definitivo

**NO USES** esta skill para publicaciones de blog regulares (usa blog-post skill), landing pages o contenido de forma corta. Esto es para páginas pilares de forma larga estilo hub.

---

## Principio Fundamental

UNA PÁGINA PILAR RESPONDE CADA PREGUNTA IMPORTANTE SOBRE UN TEMA EN UN SOLO LUGAR — ES LA PÁGINA QUE GUARDARÍAS SI SOLO PUDIERAS GUARDAR UN RECURSO.

---

## Fase 1: Resumen Inicial

### Información Requerida

| Entrada | Qué Preguntar | Predeterminado |
|---------|---------------|--------|
| **Tema pilar** | "¿Qué tema amplio debería esta página cubrir comprehensivamente?" | Sin predeterminado — debe proporcionarse |
| **Palabra clave objetivo** | "¿Qué palabra clave primaria debería esta página clasificar?" | Sin predeterminado — debe proporcionarse |
| **Contenido de cluster** | "Lista publicaciones de blog existentes o planificadas que deberían enlazar desde esta página pilar." | Ninguno — sugerirá temas de cluster |
| **Audiencia** | "¿Para quién es este recurso?" | Emprendedores individuales y dueños de negocios |
| **Número de palabras** | "¿Largo objetivo?" | 3,500-5,000 palabras |
| **Páginas pilares competidoras** | "¿Hay páginas competidoras que quieras superar?" | Ninguno — investigaremos |

**PUNTO DE CONTROL: Confirma el resumen antes de esbozar.**

---

## Fase 2: Esquema

### Arquitectura de Página Pilar

```
**H1:** [Título comprehensivo con palabra clave objetivo]

**Tabla de Contenidos** (enlazada a cada H2)

**Intro** (~200 palabras) — Qué cubre esta guía y para quién es

**H2: [Concepto Fundacional]** (~500 palabras)
- [Puntos clave]
- [ENLACE DE CLUSTER: publicación de blog relacionada]

**H2: [Subtema Principal 1]** (~600 palabras)
- [Puntos clave]
- [ENLACE DE CLUSTER: publicación de blog relacionada]

**H2: [Subtema Principal 2]** (~600 palabras)
...

**H2: [Tema Avanzado]** (~500 palabras)

**H2: [Errores Comunes / FAQ]** (~400 palabras)

**H2: [Siguientes Pasos / CTA]** (~200 palabras)

**Total estimado:** [número de palabras]
**Enlaces de cluster planificados:** [número]
```

### Mapa de Contenido de Cluster

```
## Mapa de Cluster de Tema

**Página pilar:** [Tema] — se enfoca en "[palabra clave primaria]"

**Publicaciones de cluster (existentes):**
1. [Título de publicación] — se enfoca en "[palabra clave long-tail]" — enlaza desde Sección H2 [N]
2. [Título de publicación] — se enfoca en "[palabra clave long-tail]" — enlaza desde Sección H2 [N]

**Publicaciones de cluster (para crear):**
1. [Título sugerido] — se enfoca en "[palabra clave long-tail]"
2. [Título sugerido] — se enfoca en "[palabra clave long-tail]"
3. [Título sugerido] — se enfoca en "[palabra clave long-tail]"
```

**PUNTO DE CONTROL: Aprueba el esquema y mapa de cluster antes de escribir.**

---

## Fase 3: Escribir

### Reglas de Escritura

| Regla | Detalle |
|------|--------|
| **Amplitud sobre profundidad** | Cubre cada subtema a fondo pero enlaza a publicaciones de cluster para exploración profunda |
| **Tabla de contenidos** | Incluye una TOC clickable en la parte superior — esencial para páginas de forma larga |
| **Enlaces de cluster** | Enlaza naturalmente a publicaciones de cluster usando texto de anclaje descriptivo |
| **Secciones autónomas** | Cada sección H2 debería tener sentido si se lee independientemente |
| **Formato escaneable** | Enfatiza frases clave, usa listas de puntos, añade cajas de resumen al final de secciones importantes |
| **Colocación de palabra clave** | Palabra clave objetivo en H1, primeras 100 palabras, 2-3 H2s y meta descripción |
| **Marcadores visuales** | Anota dónde deberían aparecer infografías, diagramas o tablas de resumen |

### Plantilla de Sección

Cada sección H2 importante sigue este patrón:

1. **Declaración de apertura** — qué cubre esta sección y por qué importa
2. **Contenido principal** — explicación con ejemplos, datos o pasos
3. **Idea clave** — resumen de una oración en negrita
4. **Enlace de cluster** — transición natural a una publicación de blog relacionada para cobertura más profunda

### Estrategia de Enlazado Interno

```
## Plan de Enlazado Interno

**Desde pilar a publicaciones de cluster:**
- Sección 2 → [Título de publicación de cluster] (anclaje: "[texto descriptivo]")
- Sección 3 → [Título de publicación de cluster] (anclaje: "[texto descriptivo]")
...

**Desde publicaciones de cluster de vuelta a pilar:**
- Cada publicación de cluster debe enlazar de vuelta a esta página pilar con texto de anclaje: "guía de [palabra clave objetivo]"
```

---

## Fase 4: Pulir

### 1. Lista de Verificación de Página Pilar

```
## Lista de Verificación Pre-Publicación

- [ ] El recuento de palabras es de 3,000+ palabras
- [ ] Se incluye tabla de contenidos con enlaces de anclaje
- [ ] La palabra clave objetivo aparece en H1, primeras 100 palabras y 2+ H2s
- [ ] Cada sección H2 es autónoma y escaneable
- [ ] Los enlaces de publicaciones de cluster se colocan naturalmente con texto de anclaje descriptivo
- [ ] Se incluyen al menos 5 enlaces de cluster (existentes o planificados)
- [ ] Se anotan sugerencias de elementos visuales (infografía, tabla, diagrama)
- [ ] Se escribe meta descripción (150-160 caracteres)
- [ ] Se incluyen cajas de resumen o ideas clave para secciones importantes
- [ ] CTA aparece al final con un siguiente paso claro
- [ ] La página es comprehensiva lo suficiente como para ser el recurso definitivo en este tema
```

### 2. Roadmap de Contenido de Cluster

Lista 5-10 publicaciones de cluster para crear, priorizadas por volumen de búsqueda y relevancia.

### 3. Horario de Actualización

Recomienda revisiones trimestrales para mantener la página pilar actual con nuevos datos, enlaces y contenido de cluster.

## Ejemplo: Página Pilar sobre "Email Marketing para Pequeños Negocios"

```
H1: La Guía Completa de Email Marketing para Pequeños Negocios
Palabra clave objetivo: email marketing para pequeños negocios
Número de palabras: 4,500

Secciones:
- Qué Es Email Marketing (Y Por Qué Importa para Pequeños Negocios)
- Elegir una Plataforma de Email Marketing
- Construir Tu Lista de Correo desde Cero
- Escribir Correos Que Se Abran y Se Haga Clic
- Automatización de Correo para Principiantes
- Medir el Éxito del Email Marketing
- Errores Comunes de Email Marketing
- Tu Plan de Acción de Email Marketing

Enlaces de cluster:
- "Mejores Plataformas de Email Marketing para Emprendedores Individuales" → desde Sección 2
- "Cómo Escribir Líneas de Asunto de Correo Que Obtengan 40%+ Tasas de Apertura" → desde Sección 4
- "5 Automatizaciones de Correo Que Todo Pequeño Negocio Necesita" → desde Sección 5
```

## Anti-Patrones

- **Demasiado estrecho** — una página pilar sobre "fórmulas de línea de asunto de correo" es demasiado específica. Eso es una publicación de cluster. Los pilares cubren temas amplios.
- **Sin enlaces de cluster** — una página pilar sin enlaces a contenido más profundo es solo una publicación de blog larga. La estructura de enlazado es lo que lo hace pilar.
- **Pared de texto** — 5,000 palabras sin formato es ilegible. Usa la TOC, encabezados, listas y cajas de resumen.
- **Relleno de palabra clave** — el contenido largo tienta al exceso de palabras clave. Mantén densidad bajo 1.5%.
- **Nunca actualizar** — las páginas pilares requieren revisiones trimestrales para mantener clasificaciones. Programa actualizaciones.

---

## Recuperación

- **Sin contenido de cluster existente:** Escribe la página pilar primero, luego usa la roadmap de cluster para planificar publicaciones de apoyo durante los próximos 90 días.
- **El tema es demasiado amplio:** Estrecha a un ángulo específico de audiencia. "Marketing" es demasiado amplio; "Email Marketing para Pequeños Negocios" tiene tamaño de pilar.
- **El recuento de palabras es insuficiente:** Añade una sección de FAQ, una sección de errores comunes o un subtema adicional para alcanzar 3,000+ palabras.
- **El usuario quiere que sea más corto:** Explica que las páginas pilares deben ser comprehensivas para clasificar. Ofrece una versión "guía rápida" como una publicación separada más corta.
- **Las publicaciones de cluster se superponen:** Fusiona ideas de cluster superpuestas o diferencia por segmento de audiencia o caso de uso.
