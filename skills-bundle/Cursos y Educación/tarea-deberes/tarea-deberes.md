# Tarea / Deberes

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Crear tareas o ejercicios prácticos para un curso o programa de capacitación
- Diseñar ejercicios que refuercen lecciones específicas con aplicación práctica
- Construir tareas con rúbricas claras de calificación y directrices de envío
- Producir trabajo práctico que conecte teoría con resultados comerciales reales

**NO USES** este skill para quizzes, exámenes, o evaluaciones para medir competencia. Esto es para ejercicios prácticos que profundicen el aprendizaje a través de aplicación.

---

## Principio Fundamental

UNA TAREA QUE NO PRODUCE ALGO QUE EL ESTUDIANTE PUEDA USAR EN SU NEGOCIO ES TRABAJO OCUPADO — CADA ASIGNACIÓN DEBE TERMINAR CON UN ENTREGABLE TANGIBLE QUE MANTENGAN.

---

## Fases (Resumen)

**Fase 1: Brief** — Confirma tema de lección, objetivo de aprendizaje, tiempo de finalización, formato de envío.

**Fase 2: Diseño** — Arquitectura: Contexto (por qué importa), Instrucciones (qué hacer), Entregable (qué enviar), Rúbrica (cómo se evalúa), Desafío Extra (opcional).

**Fase 3: Escribe** — Documento completo de tarea con instrucciones específicas, ejemplos, y espacio para rellenar.

**Fase 4: Pulir** — Clave de respuesta o guía de auto-verificación, notas del instructor, lista de verificación de calidad.

---

## Anti-Patrones

- **Instrucciones vagas** — "Escribe algo sobre tu marca" produce basura. Especifica tema, longitud, formato, y audiencia.
- **Sin conexión del mundo real** — los ejercicios que se sienten académicos se saltan. Vincula cada asignación a la negocio real del estudiante.
- **Demasiado tiempo para la asignación** — debería reforzar, no duplicar el compromiso de tiempo.
- **Sin ejemplo de "hecho"** — los estudiantes necesitan ver qué se ve bien antes de comenzar.
- **Calificación sin rúbrica** — el feedback subjetivo parece arbitrario. Proporciona criterios claros.

---

## Recuperación

- **Usuario no puede articular el objetivo:** Pregunta "Después de esta lección, ¿qué debería el estudiante poder HACER que no podían antes?" La respuesta ES la tarea.
- **Alcance demasiado grande:** Divide en dos asignaciones más pequeñas o quita el desafío extra y simplifica la tarea principal.
- **Usuario quiere tareas sin calificar:** Proporciona una rúbrica de auto-verificación y un ejemplo completo. La responsabilidad viene de ver la brecha.
- **Los estudiantes constantemente fallan la tarea:** La lección probablemente tiene una brecha, no la tarea. Revisa prerrequisitos.
