# Revisión de Curriculum

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Auditar un curso existente o programa de capacitación para calidad y relevancia
- Identificar brechas de contenido, material desactualizado, y puntos débiles de engagement
- Modernizar un curriculum con mejores prácticas actuales y ejemplos actualizados
- Optimizar la estructura del curso para mejores tasas de finalización y resultados de aprendizaje

**NO USES** este skill para crear un curso desde cero o revisar contenido no educativo. Esto es para mejorar currículos existentes.

---

## Principio Fundamental

UNA REVISIÓN DE CURRICULUM NO SE TRATA DE AGREGAR MÁS — SE TRATA DE IDENTIFICAR QUÉ FALTA, QUÉ ESTÁ DESACTUALIZADO, Y QUÉ MATA EL ENGAGEMENT, LUEGO HACER MEJORAS QUIRÚRGICAS QUE ELEVAN LAS TASAS DE FINALIZACIÓN Y RESULTADOS.

## Fase 1: Brief

### Entradas Requeridas

| Entrada | Qué Preguntar | Por Defecto |
|---------|--------------|------------|
| **Curso a revisar** | "Comparte tu esquema de curso actual, currículo, o documento." | Sin defecto — debe proporcionarse |
| **Objetivos originales** | "¿Qué resultados fue diseñado este curso para entregar?" | Sin defecto — debe proporcionarse |
| **Problemas conocidos** | "¿Qué feedback has recibido? ¿Dónde abandonan los estudiantes?" | Ninguno — será evaluado desde la estructura |
| **Cambios de audiencia** | "¿Ha cambiado tu audiencia objetivo desde que se creó el curso?" | Misma audiencia |
| **Datos de finalización** | "¿Cuál es tu tasa de finalización actual? ¿Qué módulos tienen el engagement más bajo?" | Desconocido — será estimado desde la estructura |

**PUNTO DE CONTROL: Confirma el brief y recibe el curriculum existente antes de proceder.**

---

## Fase 2: Auditoría

Analiza el curriculum existente en cinco dimensiones.

### Marco de Auditoría

```
## 1. Auditoría de Relevancia de Contenido
- ¿Qué temas siguen siendo actuales y precisos?
- ¿Qué ejemplos o casos de estudio están desactualizados?
- ¿Qué cambios de la industria requieren contenido actualizado?
- Puntuación: [1-10]

## 2. Análisis de Brechas
- ¿Qué temas esenciales faltan?
- ¿Dónde necesitan los estudiantes más profundidad?
- ¿Qué prerrequisitos se asumen pero no se enseñan?
- Puntuación: [1-10]

## 3. Evaluación de Engagement
- ¿Dónde hay los tramos más largos sin interacción?
- ¿Qué módulos carecen de ejercicios o aplicación?
- ¿Dónde el contenido es denso sin variedad?
- Puntuación: [1-10]

## 4. Estructura y Flujo
- ¿La secuencia construye lógicamente?
- ¿Hay picos de dificultad que podrían causar abandonos?
- ¿El ritmo es consistente en todos los módulos?
- Puntuación: [1-10]

## 5. Alineación de Resultados
- ¿Cada módulo se conecta al resultado del curso declarado?
- ¿Hay módulos que no sirven el objetivo final?
- ¿Es el resultado final alcanzable con lo que se enseña?
- Puntuación: [1-10]
```

**PUNTO DE CONTROL: Presenta los hallazgos de la auditoría y espera a que el usuario priorice mejoras.**

---

## Fase 3: Recomendar

Crea un plan de mejora priorizado.

### Categorías de Mejora

**Crítico (hazlo ahora):**
- Contenido factualmente incorrecto u desactualizado
- Temas fundamentales faltantes que causan confusión después
- Módulos sin interacción o aplicación

**Importante (hazlo pronto):**
- Ejemplos desactualizados que debilitan credibilidad
- Zonas muertas de engagement más de 15 minutos sin interacción
- Problemas de ritmo causando picos de dificultad

**Agradable tener (hazlo después):**
- Ejemplos o casos de estudio adicionales
- Recursos suplementarios
- Mejoras visuales o de formato

### Formato de Recomendación

Para cada recomendación:

```
## Recomendación: [Título]
**Prioridad:** Crítico / Importante / Agradable tener
**Estado actual:** [Lo que existe ahora]
**Problema:** [Por qué necesita cambiar]
**Cambio recomendado:** [Acción específica]
**Esfuerzo estimado:** [Bajo / Medio / Alto]
**Impacto en finalización:** [Bajo / Medio / Alto]
```

## Fase 4: Pulir

### 1. Mapa de Curriculum Actualizado

Proporciona un esquema revisado mostrando todos los cambios:
- Adiciones marcadas (contenido nuevo)
- Eliminaciones marcadas (contenido cortado)
- Revisiones marcadas (contenido actualizado)
- Nuevo orden de módulo si se reestructura

### 2. Mapa de Ruta de Implementación

```
## Fase 1 (Esta semana): Correcciones críticas
- [ ] [Acción específica]

## Fase 2 (Este mes): Mejoras importantes
- [ ] [Acción específica]

## Fase 3 (Este trimestre): Mejoras
- [ ] [Acción específica]
```

### 3. Calendario de Revisión Continua

Recomienda una verificación trimestral de actualización de contenido:
- Revisa ejemplos y datos para precisión
- Verifica tendencias de tasa de finalización por módulo
- Encuesta a graduados recientes para feedback
- Actualiza un módulo como mínimo cada trimestre

---

## Ejemplo 1: Revisión de Curso de Marketing Desactualizado

```
Hallazgo de auditoría: 40% de ejemplos hacen referencia a plataformas o características que ya no existen.
Recomendación: Reemplaza 12 casos de estudio con ejemplos actuales. Prioridad: Crítico.
Esfuerzo estimado: Medio (8-10 horas de actualizaciones de contenido).
```

## Ejemplo 2: Bootcamp de Codificación con Baja Finalización

```
Hallazgo de auditoría: Módulo 4 tiene churn rate del 60%. El contenido salta de básico a avanzado sin puente.
Recomendación: Agrega un módulo de ejercicio intermedio entre 3 y 4. Prioridad: Crítico.
Esfuerzo estimado: Alto (creación de nuevo módulo, 15-20 horas).
```

## Anti-Patrones

- **Revisar sin datos** — los sentimientos no son una revisión de curriculum. Usa tasas de finalización, feedback, y datos de abandono donde sea posible.
- **Agregar sin cortar** — si añades 3 módulos, considera remover o fusionar 2. La inflación del curso mata la finalización.
- **Actualizaciones superficiales** — cambiar capturas de pantalla mientras ignoras problemas estructurales desperdicia tiempo.
- **Ignorar el cambio de audiencia** — un curso construido para principiantes en 2020 puede ahora atraer intermedios. Ajusta la profundidad.
- **Recomendar una reconstrucción completa** — el objetivo es mejora, no reemplazo. Enfócate en cambios de mayor impacto primero.

---

## Recuperación

- **Sin documento de curriculum proporcionado:** Pide al usuario que liste títulos de módulo y una descripción de una oración para cada uno. Trabaja desde ese esquema.
- **Sin datos de finalización:** Estima riesgo de engagement basado en duración del módulo, interactividad, y tipo de contenido. Marca módulos de más de 20 minutos sin ejercicios.
- **El usuario quiere agregar todo:** Fuerza un ranking de recomendaciones por impacto. Limita Fase 1 a los 3 arreglos críticos principales.
- **El curso está más allá de reparación:** Si más del 70% del contenido necesita reemplazo, recomienda construir un nuevo curso usando el 30% que funciona como base, en lugar de parchar el viejo.
