# Estrategia Entrega Alimentos

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Lanzar u optimizar operaciones entrega alimentos restaurante
- Seleccionar y gestionar plataformas entrega terceros
- Diseñar menús específicos entrega, empaque y estrategias precios
- Construir procedimientos control calidad entrega órdenes

**NO USES** este skill para prep comidas o negocios kit comida, entrega víveres o logística catering.

---

## Principio Fundamental

ENTREGA ES PRODUCTO DIFERENTE QUE COMER AQUÍ — COMIDA DEBE LLEGAR VIENDO Y SABIENDO COMO INTENCIÓN. PLATO NO VIAJA BIEN NO PERTENECE MENÚ ENTREGA.

## Fase 1: Resumen

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Tipo restaurante** | "¿Qué tipo restaurante y cocina?" | Sin predeterminado |
| **Estado entrega actual** | "¿Ofreces entrega actualmente? ¿A través qué plataformas?" | No aún |
| **Idoneidad menú** | "¿Cuáles artículos menú viajan bien? ¿Cuáles no?" | Desconocido — necesita evaluación |
| **Radio entrega** | "¿Cuán lejos estás dispuesto entregar?" | Radio 5 millas |
| **Capacidad cocina** | "¿Tu cocina maneja volumen entrega además comer aquí?" | Limitada — necesita gestión cuidadosa |
| **Presupuesto** | "¿Estás dispuesto absorber comisiones plataforma o pasar costos clientes?" | Pasar a través markup tarifa entrega |

**PUNTO DE CONTROL:** Confirma resumen antes construir estrategia.

## Fase 2: Estrategia Plataforma

### Comparación Plataforma

| Plataforma | Comisión | Alcance | Mejor Para |
|---|---|---|---|
| **DoorDash** | 15-30% | Alcance EE.UU. más grande | Exposición máxima |
| **Uber Eats** | 15-30% | Fuerte presencia urbana | Mercados urbanos |
| **Grubhub** | 15-30% | Fuerte Noreste | Enfoque regional |
| **Directo (sitio web propio)** | 0% + tarifas procesamiento | Tus clientes | Clientes repetidos, márgenes altos |
| **Toast/Square entrega** | Comisión más baja | Integrado POS | Usuarios Toast/Square existentes |

### Opciones Estrategia Plataforma

| Estrategia | Descripción | Impacto Margen |
|---|---|---|
| **Multi-plataforma** | Lista 2-3 plataformas alcance máximo | Margen más bajo, volumen más alto |
| **Plataforma + directo** | Usa 1 plataforma descubrimiento, push órdenes repetidas a directo | Balanceado |
| **Solo directo** | Sitio web ordenamiento propio o app | Margen más alto, requiere marketing |

### Estrategia Precios Entrega

- **Opción 1:** Sube precios menú entrega 15-20% offset comisiones
- **Opción 2:** Mantén mismos precios, absorbe comisión (construye volumen)
- **Opción 3:** Crea combos exclusivos entrega con margen incorporado

## Fase 3: Operaciones

### Diseño Menú Entrega

Evalúa cada artículo menú idoneidad entrega:

| Criterios | Pasa | Falla |
|---|---|---|
| Sostiene temperatura 30 minutos | Sí | Descalificado |
| No se pone blando o marchita | Sí | Modifica o retira |
| Se ve presentable después transporte | Sí | Modifica o retira |
| Se puede recalentar sin pérdida calidad | Bonificación | No requerido |
| Empaca eficientemente | Sí | Modifica contenedor |

**Reglas menú:**
- Retira artículos no viajan bien (crujientes se ponen blandos, artículos requieren plato preciso)
- Agrega artículos amigables entrega (bowls, wraps, contenedores sellados)
- Crea combos exclusivos entrega aumentan valor orden promedio
- Ofrece opciones tamaño familia o multi-persona tickets más altos

---

## Anti-Patrones

- **Poner menú entero en entrega** — no todo plato viaja bien. Comida que llega fría, derramada o marchita pierde cliente permanentemente.
- **Ignorar costos empaque** — comida que llega fría, derramada o desastrada obtiene 1-estrella. Invierte contenedores apropiados.
- **Sin control calidad antes entrega** — artículos incorrectos y faltantes son quejas entrega principales. Verifica cada bolsa.
- **Mismos precios plataformas que comer aquí** — pagas 20-30% comisión. Sube precios o acepta margen hit conscientemente.
- **NO promocionar ordenamiento directo** — cada orden plataforma cuesta 20-30% comisión. Empuja clientes canal ordenamiento propio.

---

## Recuperación

- **Clasificaciones entrega bajas:** Audita últimas 10 reseñas negativas. Quejas principales: artículos incorrectos, comida fría o faltantes. Arregla proceso QC.
- **Comisiones plataforma demasiado altas:** Negocia tasas (posible volumen más alto), sube precios entrega o empuja clientes a ordenamiento directo.
- **Cocina no maneja volumen entrega:** Fija límites orden durante picos comer aquí. Escala disponibilidad.
- **Calidad comida sufre en tránsito:** Rediseña empaque. Prueba ordenando propia entrega comiéndola 30 minutos después. Arregla qué no funciona.
