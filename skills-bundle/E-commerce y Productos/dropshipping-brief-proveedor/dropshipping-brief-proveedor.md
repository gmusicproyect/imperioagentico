# Brief Proveedor Dropshipping

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Evaluar y verificar proveedores dropshipping potenciales
- Crear plantillas comunicación para alcance y gestión proveedor
- Definir estándares calidad y SLAs para cadena suministro
- Construir sistema gestión proveedores para negocio dropshipping

**NO USES** este skill para estrategia abastecimiento producto, configuración tienda e-commerce o marketing. Esto es para lado relación proveedores y gestión dropshipping.

---

## Principio Fundamental

TU PROVEEDOR ES TU SOCIO SILENCIOSO — SU CALIDAD, VELOCIDAD Y CONFIABILIDAD DETERMINAN DIRECTAMENTE TU EXPERIENCIA CLIENTE Y REPUTACIÓN MARCA.

---

## Fase 1: Resumen

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Nicho producto** | "¿Qué productos dropshippearás?" | Debe proporcionarse |
| **Mercado objetivo** | "¿Dónde están clientes? (EE.UU., UE, global)" | Estados Unidos |
| **Volumen órdenes** | "¿Volumen órdenes mensual esperado?" | 50-200 órdenes/mes |
| **Rango precio** | "¿Costo producto y precio venta objetivo?" | Debe proporcionarse |
| **Expectativas envío** | "¿Tiempo envío máximo aceptable a cliente?" | 7-14 días |
| **Proveedores actuales** | "¿Trabajaste con proveedores ya?" | Comenzando fresco |
| **Plataforma** | "¿Dónde sourcing? (AliExpress, Alibaba, EE.UU., private label)" | Mixta |

**PUNTO DE CONTROL:** Confirma resumen antes construir marco gestión proveedor.

---

## Fase 2: Diseño

### Criterios Evaluación Proveedor

Puntúa cada proveedor potencial (1-10):

| Criterios | Qué Evaluar | Puntuación Mínima |
|----------|------------|---|
| **Calidad producto** | Revisión muestra, calidad material, consistencia | 7 |
| **Velocidad envío** | Tiempo entrega promedio a tu target market | 7 |
| **Comunicación** | Tiempo respuesta, claridad idioma, profesionalismo | 6 |
| **Confiabilidad** | Precisión orden, disponibilidad stock, consistencia | 8 |
| **Precios** | Costo unitario, tarifas envío, descuentos volumen | 6 |
| **Manejo devoluciones** | Política devolución, proceso reemplazo defectos | 6 |
| **Escalabilidad** | Capacidad aumentos volumen, inventario backup | 5 |

### Proceso Verificación Proveedor

1. Contacto inicial consulta
2. Orden muestra (siempre ordena antes vender)
3. Evalúa calidad muestra y tiempo envío
4. Coloca 3-5 órdenes prueba sobre 2 semanas
5. Evalúa consistencia y comunicación
6. Negocia términos, firma acuerdo

---

## Fase 3: Construir

### Entregables

**1. Plantilla Alcance Proveedor**
- Email introducción profesional
- Consulta producto con requisitos especificación
- Plantilla negociación precios y MOQ
- Formato solicitud muestra

**2. Scorecard Evaluación Proveedor**
- Matriz puntuación por criterio
- Umbrales pass/fail
- Tabla comparación múltiples proveedores
- Recomendación decisión

**3. Plantilla Acuerdo Proveedor**
- Estándares calidad y expectativas
- Cronogramas envío y requisitos rastreo
- Proceso manejo devoluciones y defectos
- Expectativas comunicación (SLAs tiempo respuesta)
- Términos pago y horario
- Condiciones terminación

**4. Flujo Gestión Órdenes**
- Proceso transmisión orden (manual o automatizado)
- Flujo comunicación número rastreo
- Procedimientos verificación calidad primeras 10 órdenes
- Proceso escalada problemas (envíos tarde, artículos incorrectos, problemas calidad)

**5. Rastreador Rendimiento Proveedor**
- Métricas mensuales: precisión orden, velocidad envío, tasa defectos, puntuación comunicación
- Indicadores estado rojo/amarillo/verde
- Puntos disparo revisión trimestral

---

## Anti-Patrones

- **Vender antes muestrear** — listar productos nunca vistos es receta refunds negativas. Siempre ordena muestras.
- **Elegir solo por precio** — proveedor más barato a menudo envío lentísimo, calidad pobre, dolores cabeza máximos.
- **Sin acuerdo escrito** — promesas verbales no significan nada falla envío. Consigue compromisos por escrito.
- **Dependencia proveedor único** — si proveedor agota stock, negocio se detiene. Siempre ten backup.
- **Ignorar calidad comunicación** — proveedor tarda 3 días responder consultas tardará 3 días resolver problemas cliente.

---

## Recuperación

- **Calidad proveedor cae:** Documenta problemas fotos/números rastreo. Contacta proveedor con evidencia, solicita acción correctiva. Si no resuelto 2 semanas, activa proveedor backup.
- **Tiempos envío aumentan súbitamente:** Investiga (demoras holidays, problemas cadena suministro, o proveedor deprioritizando órdenes). Comunica proactivamente clientes afectados.
- **Sin proveedores disponibles que hablen inglés:** Usa agente sourcing como intermediario. Agente gestiona comunicación proveedor y control calidad.
- **Quejas cliente se acumulan:** Pausa órdenes nuevas, audita envíos recientes, aborda causa raíz antes escalar más. Pérdida ingresos corto plazo previene daño marca largo plazo.
