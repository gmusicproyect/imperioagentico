# Listado Marketplace

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Crear u optimizar listados producto para Etsy, Amazon o eBay
- Escribir títulos específicos plataforma, descripciones, bullets para visibilidad búsqueda
- Desarrollar estrategias precios que contabilicen tarifas y competencia
- Construir directrices imágenes que maximicen click-through y tasas conversión

**NO USES** este skill para páginas producto tu sitio web, posts redes sociales o entradas catálogo mayorista. Esto es solo para listados marketplace terceros.

---

## Principio Fundamental

CADA MARKETPLACE TIENE SU PROPIO ALGORITMO BÚSQUEDA, COMPORTAMIENTO COMPRADOR Y FORMATO LISTADO — UN LISTADO AMAZON EXCELENTE FALLARÁ EN ETSY SI COPIAS Y PEGAS.

## Fase 1: Resumen Listado

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Plataforma** | "¿Cuál marketplace — Etsy, Amazon, eBay?" | Sin predeterminado |
| **Producto** | "Describe producto, materiales, dimensiones, características clave." | Sin predeterminado |
| **Palabras clave objetivo** | "¿Qué términos buscan compradores este producto?" | Investigación Fase 2 |
| **Rango precio** | "¿Qué precio estás apuntando?" | Análisis competitivo Fase 2 |
| **Competidores** | "¿Comparte 2-3 URLs listados competidor si tienes?" | Ninguno — benchmarking manual |

**PUNTO DE CONTROL:** Confirma plataforma y detalles producto antes escribir copia listado.

## Fase 2: Optimización Específica Plataforma

### Listados Etsy

**Título (máx. 140 caracteres):**
- Front-load palabra clave primaria
- Incluye material, caso uso y ocasión regalo
- Usa frases naturales separadas por comas o pipes
- Ejemplo: "Diario Personalizado Piel | Cuaderno Grabado | Regalo Aniversario para Él"

**Tags (máx. 13):**
- Usa todos 13 slots — mezcla palabras clave amplias y long-tail
- Incluye material, ocasión, estilo, destinatario y caso uso

**Descripción:**
- Primeros 160 caracteres aparecen búsqueda — lidera beneficios y palabras clave
- Cuent historia producto — materiales, proceso, inspiración
- Incluye dimensiones, instrucciones cuidado, detalles envío
- Agrega resumen políticas tienda final

### Listados Amazon

**Título (máx. 200 caracteres):**
- Formato: Marca + Producto + Característica Clave + Material + Tamaño/Cantidad
- Ejemplo: "CraftCo Diario Piel Personalizado — Cuaderno Grabado Mano, 240 Hojas, Tamaño A5, Marrón"

**Bullets (5 bullets):**
- Lidera cada bullet con frase BENEFICIO CAPITALIZADA
- Sigue con detalles apoyo y especificidades
- Incluye palabras clave naturalmente — evita relleno

**Descripción / Contenido A+:**
- Expande bullets con casos uso y social proof
- Quiebra párrafos cortos con encabezados bold
- Incluye gráficos comparación si vendes múltiples variantes

### Listados eBay

**Título (máx. 80 caracteres):**
- Incluye marca, tipo producto, specs clave, condición
- Usa abreviaturas búsqueda comunes esperadas compradores
- Ejemplo: "Diario Piel Personalizado Grabado Cuaderno A5 240pg Marrón NUEVO"

**Especificaciones Artículo:**
- Completa cada campo disponible — algoritmo eBay pondera especificaciones artículo pesadamente
- Usa valores exactos específicos categoría donde proporcionado

**Descripción:**
- Plantilla HTML profesional con fotos producto incrustadas
- Tabla specs superior, historia/beneficios debajo
- Política retorno y información envío clara

## Fase 3: Precios e Imágenes

### Estrategia Precios

Calcula precios con tarifas plataforma incluidas:

```
## Hoja Cálculo Precios

**Costo producto:** $8.00
**Costo envío (si absorbido):** $4.50
**Tarifas plataforma:** [Etsy: 6.5% + $0.20 | Amazon: 15% referral | eBay: 13.25%]
**Margen objetivo:** 50%+

**Precio Etsy:** $28.99 (tarifa: ~$2.08) → margen: $14.41 (49.7%)
**Precio Amazon:** $29.99 (tarifa: ~$4.50) → margen: $13.49 (45.0%)
**Precio eBay:** $27.99 (tarifa: ~$3.71) → margen: $11.78 (42.1%)
```

### Directrices Imágenes

| Slot Imagen | Propósito | Specs |
|-----------|---------|-------|
| Principal | Producto fondo blanco (Amazon requiere) | Mín. 1500x1500px, sin overlay texto |
| 2 | Lifestyle / en uso | Muestra escala, contexto, ambiente |
| 3 | Close-up detalles, textura, calidad | Destaca artesanía o características únicas |
| 4 | Referencia tamaño o gráfico dimensiones | Incluye medidas overlay |
| 5 | Packaging o shot unboxing | Muestra experiencia que recibe comprador |
| 6-7 | Variaciones, vista atrás o comparación | Cubre preguntas visuales restantes |

## Anti-Patrones

- **Copiar-pegar entre plataformas** — cada marketplace tiene algoritmos diferentes, límites caracteres y expectativas comprador.
- **Relleno palabras clave títulos** — títulos ilegibles reducen click-through incluso si rankean.
- **Ignorar tarifas en precios** — producto que se ve rentable $25 puede perder dinero después 15% tarifas referral Amazon.
- **Foto de producto única** — listados con 5+ imágenes convierten 2-3x superior a listados imagen única.
- **Descripciones genéricas** — "Producto calidad alta, regalo excelente" no dice compradores nada. Usa especificidades.
- **Saltarse especificaciones artículo eBay** — campos vacíos significa visibilidad búsqueda menor.

---

## Recuperación

- **Sin ideas palabras clave:** Usa barras búsqueda marketplace para sugerencias autocomplete. Busca categoría producto y nota títulos listados top-selling y tags.
- **Fotos baja calidad:** Usa smartphone con iluminación natural y cartulina blanca. Enfócate imágenes agudas bien iluminadas sobre setups profesionales.
- **Listado no obtiene vistas:** Revisa palabras clave título, verifica colocación categoría, asegúrate todos tags/especificaciones completos.
- **Vistas pero sin ventas:** Revisa precios contra competidores, mejora imagen principal, agrega social proof o reseñas.
- **Riesgo suspensión plataforma:** Revisa políticas marketplace antes publica — evita reclamaciones prohibidas, problemas marca registrada o categorías restringidas.
