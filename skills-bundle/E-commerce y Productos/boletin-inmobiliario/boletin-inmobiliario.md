# Boletín Inmobiliario

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Escribir boletín mensual o quincenal de mercado inmobiliario para tu base de contactos
- Presentar datos de mercado local en formato atractivo y no técnico
- Incluir consejos de compra o venta que demuestren tu experiencia
- Destacar listados activos y ventas recientes

**NO USES** este skill para descripciones de listado de propiedad, reportes análisis de mercado o contenido redes sociales. Esto es para boletines email a tu base de datos inmobiliaria.

---

## Principio Fundamental

TU BOLETÍN TE MANTIENE EN TOP-OF-MIND PARA QUE CUANDO ALGUIEN EN TU BASE DE DATOS ESTÉ LISTO PARA COMPRAR O VENDER, PIENSEN EN TI PRIMERO — ENTREGA VALOR CADA EMISIÓN, NO SOLO LISTADOS.

---

## Fase 1: Resumen de Boletín

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Área de mercado** | "¿Qué ciudad, vecindario o región cubre?" | Sin predeterminado — debe proporcionarse |
| **Audiencia** | "¿Quién está en tu lista — compradores, vendedores, inversores, clientes pasados, todos?" | Mixta — todos contactos |
| **Frecuencia** | "¿Mensual, quincenal o semanal?" | Mensual |
| **Datos de mercado** | "Comparte stats recientes — precio mediano, días mercado, inventario." | Usará lenguaje general si no hay datos |
| **Listados destacados** | "¿Algún listado activo o venta reciente destacar?" | Ninguno — se estructurará sin |

**PUNTO DE CONTROL:** Confirma área mercado y audiencia antes de redactar.

---

## Fase 2: Estructura de Boletín

### Diseño de Emisión Estándar

```
## [Tu Nombre/Marca] — Actualización Inmobiliaria de [Mes]

### 1. Nota Personal (2-3 oraciones)
[Apertura cálida y breve. Reference algo estacional, local o personal.
No sobre inmobiliaria — humanízate.]

### 2. Panorama de Mercado (3-5 oraciones + datos)
[Stats clave con interpretación lenguaje simple. ¿Qué significan números
para compradores? ¿Para vendedores? Haz datos accesibles.]

### 3. Artículo Destacado (150-250 palabras)
[Una punta educativa, guía o insight. Rota temas: consejos compra,
prep venta, tendencias mercado, mejora hogar, eventos locales.]

### 4. Listados/Ventas Destacadas (2-3 propiedades)
[Descripciones breves con fotos y detalles clave. Incluye listados
activos y ventas recientes como social proof.]

### 5. Foco Local (2-3 oraciones)
[Destaca negocio local, evento, restaurante o noticias comunidad.
Muestra que conoces y amas el área.]

### 6. CTA
[Un CTA claro — no tres. "¿Considerando vender? Responde para valuación gratis."]
```

## Fase 3: Creación de Contenido

### Plantilla de Panorama de Mercado

```
## Panorama [Área] — [Mes Año]

**Precio mediano del hogar:** $[monto] ([+/-X%] vs. año pasado)
**Días promedio mercado:** [X] días ([+/-X] vs. mes pasado)
**Inventario activo:** [X] hogares ([arriba/abajo] de [X] mes pasado)
**Hogares vendidos este mes:** [X]

**Qué significa:**
[2-3 oraciones interpretando datos para tu audiencia. Ejemplo:
"Inventario se aprieta, significa vendedores en posición fuerte.
Si has pensado listar, esta primavera podría ser tu momento."]
```

## Anti-Patrones

- **Solo listados, sin valor** — boletín que es solo dump de listados se ignora. Lidera con contenido útil.
- **Envío inconsistente** — saltar meses mata momentum. Commit horario y mantén.
- **Datos sin interpretación** — "Precio mediano $450K" sin contexto no significa nada. Dile QUÉ SIGNIFICA para ELLOS.
- **Demasiado largo** — boletines sobre 800 palabras se abandonan. Sé conciso.
- **Sin voz personal** — si suena como escrito por equipo marketing corporativo, no construirá relación.
- **CTAs múltiples** — "Llámame comprar, vender, invertir o referir amigo" diluye cada mensaje. Un CTA por emisión.

---

## Recuperación

- **Datos de mercado no disponibles:** Usa tendencias regionales generales y observaciones anecdóticas de tus propias transacciones.
- **Base de datos pequeña:** Empieza enviando igual. Calidad supera cantidad. Lista 200 personas con 30% apertura gana lista 5,000 con 5%.
- **Bajas tasas apertura:** Prueba líneas asunto diferentes, intenta nuevo horario envío, asegúrate proporcionando valor no solo auto-promoción.
- **Nada noticioso:** Destaca negocio local, comparte consejo mantenimiento hogar, o escribe sobre tendencia que ves en showings.
- **Se siente repetitivo:** Rota categorías contenido mensualmente. Encuesta tu lista sobre qué quieren leer.
