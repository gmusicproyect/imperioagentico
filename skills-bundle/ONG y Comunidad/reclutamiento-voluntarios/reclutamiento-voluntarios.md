# Reclutamiento de Voluntarios

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Crear materiales de reclutamiento de voluntarios con descripciones de roles atractivas
- Construir procesos de solicitud y evaluación para programas de voluntarios
- Diseñar paquetes de incorporación de voluntarios y materiales de entrenamiento
- Lanzar una campaña de reclutamiento para llenar posiciones de voluntarios específicas

**NO** uses este skill para ofertas de trabajos pagados, programas de pasantías o contratación de contratistas. Esto es para reclutamiento de voluntarios sin pagar.

---

## Principio Fundamental

LOS VOLUNTARIOS ELIGEN REGALAR SU TIEMPO — TU RECLUTAMIENTO DEBE VENDER LA EXPERIENCIA, NO SOLO LA NECESIDAD, PORQUE LAS PERSONAS SE OFRECEN COMO VOLUNTARIOS POR SIGNIFICADO, DESARROLLO DE HABILIDADES Y CONEXIÓN, NO POR OBLIGACIÓN.

## Fase 1: Resumen

### Información Requerida

| Entrada | Qué Preguntar | Predeterminado |
|---------|--------------|--------|
| **Organización** | "¿Cuál es la organización y su misión?" | Sin predeterminado — debe proporcionarse |
| **Roles necesarios** | "¿Qué roles de voluntarios estás llenando?" | Sin predeterminado — debe proporcionarse |
| **Compromiso de tiempo** | "¿Cuántas horas por semana/mes por voluntario?" | 4-6 horas/mes |
| **Habilidades necesarias** | "¿Alguna habilidad específica requerida o preferida?" | Sin habilidades específicas requeridas |
| **Canales de reclutamiento** | "¿Dónde publicarás esto? (website, redes sociales, email, dashboards comunitarios)" | Website + redes sociales |
| **Número de voluntarios** | "¿Cuántos voluntarios necesitas?" | 10-15 |

**PUNTO DE CONTROL: Confirma el resumen antes de continuar.**

## Fase 2: Diseño

### Plantilla de Descripción de Rol

Para cada rol de voluntario:

```
## Rol de Voluntario: [Título]

**Impacto:** [Qué logra este rol para la misión — comienza con esto]
**Responsabilidades:**
- [Tarea específica 1]
- [Tarea específica 2]
- [Tarea específica 3]
**Compromiso de tiempo:** [Horas por semana/mes, duración, flexibilidad de horario]
**Habilidades:** [Requeridas vs. bienvenidas]
**Qué recibes:**
- [Desarrollo de habilidades]
- [Conexión comunitaria]
- [Construcción de cartera/currículum]
- [Carta de referencia después de X meses]
**Ubicación:** [Presencial / remoto / híbrido]
**Reporta a:** [Nombre del coordinador de voluntarios]
```

### Proceso de Solicitud

```
## Flujo de Solicitud
1. Lee descripción de rol y FAQ
2. Envía formulario de solicitud breve (máximo 5 minutos)
3. Evaluación breve por teléfono o video (15 minutos)
4. Revisión de antecedentes (si aplica)
5. Email de bienvenida + materiales de incorporación
6. Orientación del primer día
```

**PUNTO DE CONTROL: Presenta descripciones de rol y flujo de solicitud para aprobación.**

## Fase 3: Construir

### Materiales de Campaña de Reclutamiento

**1. Publicación de Reclutamiento (Redes Sociales)**
```
[Hook: Afirmación en negrita sobre el impacto]
[Rol: Qué hace el voluntario]
[Compromiso: Tiempo requerido]
[Beneficio: Qué gana el voluntario]
[CTA: Enlace de solicitud]
```

**2. Email para Partidarios Existentes**
```
Asunto: Necesitamos tu ayuda — [X] espacios de voluntarios abiertos

[Apelación personal de líder de organización]
[Roles específicos disponibles]
[Qué experimentan los voluntarios]
[Enlace de solicitud]
[Plazo si aplica]
```

**3. Página de Voluntarios en Website**
- Descripción general de la misión (2-3 frases)
- Roles disponibles con descripciones
- Testimonios de voluntarios
- Sección de FAQ
- Formulario de solicitud o enlace

### Paquete de Bienvenida para Voluntarios

```
## Paquete de Bienvenida para Voluntarios

1. Carta de bienvenida del director ejecutivo
2. Descripción general de la organización y misión
3. Tu descripción de rol y expectativas
4. Contactos clave y canales de comunicación
5. Detalles de horario y ubicación
6. Políticas (confidencialidad, código de conducta, seguridad)
7. Cronograma de entrenamiento
8. FAQ
9. Información de contacto de emergencia
```

### Acuerdo de Voluntario

```
## Acuerdo de Voluntario
- Rol y responsabilidades
- Compromiso de tiempo
- Expectativas de confidencialidad
- Código de conducta
- Autorización de foto/medios (opcional)
- Información de contacto de emergencia
- Firma y fecha
```

## Fase 4: Pulir

### 1. Estrategia de Retención

Reclutamiento sin retención es una puerta giratoria:
- Apreciación mensual (menciones, notas de agradecimiento)
- Revisiones trimestrales con coordinador de voluntarios
- Evento anual de apreciación
- Oportunidades de desarrollo de habilidades
- Ruta clara hacia mayor responsabilidad

### 2. Lista de Verificación de Reclutamiento

```
- [ ] Las descripciones de rol están enfocadas en beneficios, no solo listas de tareas
- [ ] La solicitud toma menos de 5 minutos para completar
- [ ] El tiempo de respuesta a solicitudes es menos de 48 horas
- [ ] El paquete de incorporación está listo antes de que comience el reclutamiento
- [ ] El cronograma de entrenamiento está establecido
- [ ] El coordinador de voluntarios está identificado y disponible
- [ ] El proceso de agradecimiento está automatizado o programado
```

### 3. Métricas

```
## Rastrear Mensualmente
- Solicitudes recibidas
- Tasa de conversión (solicitud → voluntario activo)
- Horas de voluntarios contribuidas
- Tasa de retención (% aún activo después de 3 meses)
- Puntuación de satisfacción de voluntarios
```

## Ejemplo 1: Reclutamiento de Voluntario de Evento

```
Rol: Voluntario del Día del Evento
Impacto: Ayuda a 200 asistentes a tener una experiencia de conferencia sin problemas
Compromiso: Un día completo (8 horas) + 1 hora de entrenamiento previo al evento
Qué recibes: Acceso gratuito al evento, networking con oradores, camiseta de voluntario
Solicitud: Formulario simple, primero en llegar primero en servirse, 20 espacios
```

## Ejemplo 2: Voluntario de Programa Continuo

```
Rol: Mentor para Jóvenes Emprendedores
Impacto: Guía a un joven a través de su primera idea de negocio
Compromiso: 2 horas/semana durante 12 semanas
Habilidades necesarias: Experiencia en negocios, paciencia, horario confiable
Qué recibes: Entrenamiento de mentor, comunidad de mentores compañeros, informe de impacto
Solicitud: Solicitud + entrevista + revisión de antecedentes
```

## Anti-Patrones

- **Comenzar con las necesidades de la organización** — "Necesitamos ayuda" es menos convincente que "Puedes cambiar la trayectoria de un estudiante."
- **Sin beneficio para el voluntario** — la gente da tiempo por significado, habilidades y conexión. Especifica qué reciben.
- **Descripciones de rol vagas** — "Ayuda con eventos" no atrae voluntarios de calidad. Sé específico sobre tareas y tiempo.
- **Procesos de solicitud largos** — cuanto más tiempo toma la solicitud, menos completiones. Mantenerlo bajo 5 minutos.
- **Sin incorporación** — lanzar voluntarios al trabajo sin orientación lleva a confusión y abandono temprano.
- **Dar voluntarios por sentado** — el reconocimiento no es opcional. Los voluntarios no apreciados se van.

---

## Recuperación

- **No hay suficientes solicitudes:** Aumenta la sección "qué recibes". Añade desarrollo de habilidades, networking y beneficios de carta de referencia.
- **Alto abandono después de incorporación:** El rol probablemente no coincide con lo que se anunció. Audita la brecha entre descripción y realidad.
- **Los voluntarios carecen de habilidades necesarias:** Baja los requisitos de habilidad y proporciona entrenamiento, o recluta de canales más enfocados (asociaciones profesionales, redes de antiguos alumnos).
- **El usuario nunca ha gestionado voluntarios:** Comienza con 3-5 voluntarios, no 20. Construye el sistema de gestión a pequeña escala primero.
