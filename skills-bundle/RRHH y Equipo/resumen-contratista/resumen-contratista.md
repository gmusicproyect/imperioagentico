# Resumen de Contratista

## Cuándo Usar Este Skill

Utiliza este skill cuando necesites:
- Escribir un resumen detallado para enviar a un contratista antes de comenzar el trabajo
- Definir alcance, entregables, cronograma, y términos de pago claramente
- Establecer expectativas de comunicación y procesos de feedback
- Crear una plantilla de resumen reutilizable para contratar contratistas consistentemente

**NO** uses este skill para acuerdos completos de contratista o contratos legales, descripciones de trabajo para empleados, o planes de gestión de proyectos. Esto es para el resumen operacional que dice al contratista exactamente qué necesitas.

---

## Principio Fundamental

UN RESUMEN DE CONTRATISTA ES EL DOCUMENTO MÁS IMPORTANTE EN UN COMPROMISO FREELANCE — EL 80% DE LAS DISPUTAS DE CONTRATISTA SE REMONTAN A ALCANCE POCO CLARO, ENTREGABLES VAGOS, O EXPECTATIVAS NO HABLADAS.

---

## Fase 1: Define Requisitos

Recopila todo lo que el contratista necesita saber.

### Información Requerida

| Información | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Nombre del proyecto** | "¿Cómo se llama este proyecto o compromiso?" | Sin predeterminado |
| **Rol del contratista** | "¿Qué hará el contratista? (diseño, redacción, desarrollo, marketing, etc.)" | Sin predeterminado |
| **Entregables** | "¿Qué salidas específicas esperas?" | Sin predeterminado |
| **Cronograma** | "¿Cuándo lo necesitas?" | Sin predeterminado |
| **Presupuesto** | "¿Cuál es tu presupuesto? (proyecto fijo, por hora, retención)" | Sin predeterminado |
| **Contexto** | "¿Qué información de antecedentes necesita el contratista sobre tu negocio?" | Sin predeterminado |
| **Referencias** | "¿Hay ejemplos de cómo se ve algo 'bueno'?" | Ninguno |

### Prueba de Claridad del Alcance

Antes de redactar, responde estas tres preguntas:
1. ¿Si el contratista entregara exactamente lo que dice el resumen, estarías satisfecho?
2. ¿Podrían dos contratistas diferentes leer este resumen y producir salidas similares?
3. ¿Hay algo que estés asumiendo pero no escribiendo?

**PUNTO DE CONTROL: Confirma que los requisitos estén completos antes de redactar el resumen.**

- [ ] [Criterio 3 — "Todos los entregables presentados en o antes de la fecha límite"]

## Fase 3: Revisa y Refina

Asegura que el resumen sea claro y completo.

### Lista de Verificación de Calidad del Resumen

```
## Lista de Verificación de Revisión del Resumen

- [ ] El alcance es lo suficientemente específico para que los entregables sean inequívocos
- [ ] Los elementos fuera del alcance se enumeran explícitamente
- [ ] El cronograma tiene fechas específicas, no "ASAP" o "lo antes posible"
- [ ] Los términos de pago y montos están claramente establecidos
- [ ] Los límites de revisión se definen
- [ ] Las normas de comunicación se establecen (herramienta, frecuencia, tiempo de respuesta)
- [ ] Se incluyen o vinculan referencias de marca/estilo
- [ ] Los criterios de éxito son mensurables
- [ ] Se abordan la propiedad y la confidencialidad
- [ ] Se programa una reunión de inicio
```

### Agenda de Reunión de Inicio

```
## Llamada de Inicio (20-30 minutos)

1. Camina a través del resumen juntos (10 min)
2. Preguntas del contratista (10 min)
3. Confirma el cronograma, la fecha del próximo entregable, y el plan de comunicación (5 min)
4. Acepta ajustes al resumen (5 min)
```

## Fase 4: Gestiona el Compromiso

Usa el resumen como punto de referencia durante todo el proyecto.

### Durante el Proyecto

- Referencia el resumen al revisar entregables — ¿coincide con las especificaciones?
- Si el alcance cambia, actualiza el resumen por escrito y acuerda cronograma/costo ajustado
- Mantén la feedback específica y vinculada a los criterios de éxito del resumen

### Plantilla de Feedback

```
## Feedback: [Nombre del Entregable] — Ronda [#]

**Evaluación general:** [En vía / Necesita revisión / Requiere rework importante]

### Lo que funciona bien:
- [Feedback positiva específica]

### Lo que necesita cambiar:
- [Feedback específica y procesable — no "hazlo mejor" sino "cambia el titular para enfocarse en [beneficio]"]

### Prioridad:
1. [Debe corregirse]
2. [Debería corregirse]
3. [Agradable tener]

**Próximo paso:** Versión revisada vence [fecha]
```

### Cierre del Proyecto

```
## Revisión del Compromiso: [Nombre del Proyecto]

**Entregables recibidos:** [Todos / Parcial]
**A tiempo:** [Sí / No — X días tarde]
**Calidad:** [Superó / Cumplió / Por debajo de expectativas]
**Comunicación:** [Excelente / Buena / Necesita mejoría]
**¿Contratarías de nuevo:** [Sí / Con reservas / No]
**Notas para compromisos futuros:** [Qué cambiar en el resumen o proceso]
```

## Anti-Patrones

- **Alcance vago** — "Diseña nuestro sitio web" no es un resumen. "Diseña un sitio web de 5 páginas (Inicio, Acerca de, Servicios, Blog, Contacto) con diseño responsivo mobile" es.
- **Sin ejemplos** — decirle a un contratista "hazlo moderno" significa algo diferente para todos. Muestra ejemplos.
- **Cambio de alcance sin documentación** — agregar trabajo sin actualizar el resumen y acordar compensación causa resentimiento.
- **Sin límite de revisión** — revisiones ilimitadas incentivan feedback vaga. Define 2 rondas; revisiones adicionales se pagan.
- **Pago solo en finalización** — retener todo el pago hasta el final crea riesgo para el contratista y menos apalancamiento para ti. Divide pagos por hito.

---

## Recuperación

- **Contratista entrega algo completamente incorrecto:** Revisa el resumen juntos. Si el resumen era claro, el contratista se perdió. Si el resumen era vago, la culpa es compartida — aclara e intenta de nuevo.
- **El alcance se expande durante el proyecto:** Detente, documenta el nuevo alcance, acuerda cronograma y costo revisado, luego procede. Nunca dejes que el cambio de alcance ocurra sin un rastro de papel.
- **El contratista pierde una fecha límite:** Pregunta qué pasó y cuál es el nuevo cronograma. Si es un patrón, abórdalo directamente y referencia el cronograma del resumen.
- **El usuario no sabe qué quiere:** Comienza con una fase de descubrimiento. Paga al contratista por una sesión de estrategia o mood board antes de comprometerse con entregables completos.
- **La comunicación se rompe:** Revisita la sección de comunicación del resumen. Establece una verificación recurrente y escala si la falta de responsabilidad continúa.
