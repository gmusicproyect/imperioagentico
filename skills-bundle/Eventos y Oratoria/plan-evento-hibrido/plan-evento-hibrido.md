# Plan de Evento Híbrido

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Planificar un evento que ocurra both in-person y virtualmente al mismo tiempo
- Diseñar experiencias para ambas audiencias (no servir a una sobre la otra)
- Gestionar logística de streaming, AV, interacción y flujo de audiencia
- Establecer criterios de éxito para ambas audiencias

**NO** uses para eventos solo in-person o solo virtual. Esto es específicamente para AMBOS simultáneamente.

---

## Principio Fundamental

UN EVENTO HÍBRIDO NO ES "IN-PERSON CON UN LIVESTREAM COMO BONUS" — ES DOS EVENTOS SIMULTÁNEOS CON DIFERENTES NECESIDADES. SIRVE A AMBOS O FALLAS EN AMBOS.

---

## Fase 1: Brief

### Inputs Requeridos

| Input | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Objetivo asistencia in-person** | "¿Cuántos en la sala?" | 200-300 |
| **Objetivo asistencia virtual** | "¿Cuántos en línea?" | 500-1,000 |
| **Plataforma de streaming** | "Zoom, YouTube Live, Hopin?" | Zoom o YouTube Live |
| **Duración del evento** | "¿Horas o días?" | 4-8 horas, 1 día |
| **Interacción esperada** | "¿Deseas preguntas de virtual? ¿Ambas audiencias en chat?" | Ambas audiencias interactúan |
| **Presupuesto AV/Tech** | "¿Presupuesto para streaming setup?" | $2,000-5,000 |

**PUNTO DE CONTROL:** Confirma brief antes de planificar.

---

## Fase 2: Diseñar Experiencias Duales

### Audiencia In-Person

```
NECESIDADES ÚNICAS:
- Conexión física de networking
- Experiencia de "estar allí" (energía de vivo)
- Ritmo en vivo sin pausas para técnica

SOLUCIONES:
- Booth de sponsors (solo in-person)
- Descansos para socializar
- Q&A en vivo desde la sala
- Materiales impresos, name tags
```

### Audiencia Virtual

```
NECESIDADES ÚNICAS:
- Claridad de contenido (pantalla compartida debe ser grande)
- Interacción sin estar en la sala (chat, Q&A, polls)
- Grabación confiable

SOLUCIONES:
- Chat dedicado (monitor de moderación)
- Polls/encuestas en vivo
- Opción para hacer preguntas por escrito
- Replay disponible
```

### Cómo Servir a Ambas

```
KEYNOTE:
In-person: Hablante en escenario. Slides en pantalla. Q&A en vivo desde audiencia.
Virtual: Hablante en pantalla completa. Diapositivas grandes. Chat moderado para preguntas. Moderador lee top 3 preguntas en vivo.

BREAKOUT SESSIONS:
In-person: Sala física. Máximo 50-100 personas.
Virtual: Zoom simultáneamente. Facilitador en video. 200-500 en línea.

NETWORKING:
In-person: Actividades estructuradas, icebreakers, room setup.
Virtual: Breakout rooms en Zoom para pares/grupos pequeños. O salas de chat basadas en intereses.

CONTENIDO VISUAL:
- Slides: Mínimo 20pt font (legible en Zoom). No más de 3 líneas de texto por slide.
- Demostración en vivo: Zoom compartiendo pantalla DESDE ancho de pantalla. Demo en grande.
- Webcam del speaker: Video grande del speaker EN LA PANTALLA (no minimizado).
```

## Fase 3: Logística Técnica

### Setup de Streaming

```
## Equipo Necesario

- Camera (1-2): Cámaras PTZ (pan-tilt-zoom) si presupuesto alto. O DSLR multi-ángulo.
- Audio: Micrófono lavalier para speaker principal + micrófonos de auriculares inalámbricos para Q&A.
- Video Switcher: Cambiar entre webcam del speaker, slides, demo en vivo.
- Backups: 2 computadoras (una para streaming en vivo, una para slides backup).
- Internet: Conexión wired (no WiFi) + hotspot móvil de backup.
- Monitor de control: Pantalla que muestra lo que la audiencia virtual ve (no confié en lo que VES).

## Plataforma de Streaming

**Zoom:**
- Fácil si registrados asisten en Zoom
- Built-in interacción (chat, polls, hands up)
- Grabación automática
- Limitación: 1,000 participantes en video en plan típico; 10,000 con webinar

**YouTube Live:**
- Mejor para audiencia masiva (sin límite)
- Excelente para replay (YouTube retiene por siempre)
- Chat sí, pero menos modesto
- Limitación: slight latency (10-30 seg retraso)

**Hopin:**
- Integrado para in-person + virtual
- Expo booths virtuales
- Networking features
- Costo: $500-2,000+
```

### Run-of-Show Modificado

```
[Cada segmento necesita:]
- Propietario in-person + propietario virtual
- Notas técnicas específicas (switches de cámara, slides timing, Q&A flow)
- Transiciones (cómo movemos de un segmento a otro sin dejar virtual en blanco)
- Contingency (si audio falla, qué hacemos para cada audiencia)
```

## Fase 4: Día del Evento

### Checklist Pre-Evento

```
- [ ] Camera Y audio están probados (ambas audiencias escuchan claro)
- [ ] Slides están cargadas en ambas computadoras (slide show en una, Zoom en otra)
- [ ] Internet está testeado (carga de video sin buffer)
- [ ] Moderador de chat está entrenado (aprobar preguntas, filtrar spam)
- [ ] Speaker sabe dónde mirar (a la cámara, no a la pantalla)
- [ ] Virtual registrados tienen Zoom link con 24 horas de anticipación
- [ ] In-person asistentes saben que el evento también será virtual (dejar privacidad)
```

---

## Anti-Patrones

- **Favorecer una audiencia sobre la otra** — si virtual es "second class," todo se siente así.
- **Sin moderación de chat virtual** — el chat sin mod se convierte rápidamente en spam.
- **Slides demasiado pequeñas** — "lindo design" que no se puede leer en Zoom es hermoso pero inútil.
- **Sin plan de backup de internet** — si internet falla, pierdes 50% de tu audiencia. Tener hotspot.
- **Asumir el streaming "simplemente funcionará"** — tech check 30 min antes de ir en vivo. No confíes en la teoría.

---

## Checklist

```
- [ ] Ambas audiencias tienen beneficios claros de asistir
- [ ] Equipo técnico está listado y presupuestado
- [ ] Run-of-show tiene propietarios in-person Y virtual
- [ ] Todos los speakers/facilitadores practican el flujo híbrido
- [ ] Plataforma de streaming es confiable (pruebas con 100+ personas)
- [ ] Plan de backup de internet está en lugar
- [ ] Moderador de chat está entrenado
```
