# Plan de Producto Digital

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Planificar un producto digital (plantilla, kit de herramientas, guía, curso o recurso)
- Validar demanda antes de invertir tiempo en construir el producto
- Diseñar estrategia de precios, empaque y distribución
- Crear un launch plan para un nuevo producto digital

**NO** uses este skill para planificación de productos SaaS, desarrollo de productos físicos o estrategia de marketing de contenidos. Esto es para productos digitales descargables o de autoservicio.

---

## Principio Fundamental

UN PRODUCTO DIGITAL RESUELVE UN PROBLEMA ESPECÍFICO Y DOLOROSO PARA UNA AUDIENCIA DEFINIDA — SI NO PUEDES DESCRIBIR QUIÉN LO COMPRA Y POR QUÉ EN UNA ORACIÓN, EL PRODUCTO NO ESTÁ SUFICIENTEMENTE ENFOCADO.

## Fase 1: Brief

### Inputs Requeridos

| Input | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Idea de producto** | "¿Qué producto digital deseas crear?" | Sin predeterminado — debe proporcionarse |
| **Comprador objetivo** | "¿Para quién es esto? Sé específico — rol, situación, pain point." | Sin predeterminado — debe proporcionarse |
| **Problema resuelto** | "¿Qué problema específico resuelve este producto?" | Sin predeterminado — debe proporcionarse |
| **Formato de producto** | "¿Qué formato? ¿Plantilla, kit de herramientas, guía, curso, hoja de cálculo, otro?" | Plantilla o kit de herramientas |
| **Experiencia existente** | "¿Qué te califica para crear este producto?" | Sin predeterminado — debe proporcionarse |
| **Objetivo de ingresos** | "¿Cuál es tu objetivo de ingresos para este producto?" | $1,000 en los primeros 90 días |

**PUNTO DE CONTROL:** Confirma el brief antes de comenzar validación.

## Fase 2: Validar

### Lista de Verificación de Validación de Demanda

Antes de construir, confirma que existe demanda:

```
## Evidencia de Validación

- [ ] **Volumen de búsqueda:** Las personas buscan este tema (Google Trends, investigación de palabras clave)
- [ ] **Demanda de comunidad:** Las preguntas sobre este tema aparecen en foros, grupos o redes sociales
- [ ] **Productos competidores:** Otros venden algo similar (competencia = demanda)
- [ ] **Comentarios directos:** Al menos 5 personas de la audiencia objetivo dicen que comprarían esto
- [ ] **Tracción de contenido:** Tu contenido sobre este tema obtiene engagement superior al promedio
```

## Anti-Patrones

- **Crear sin validar:** Construyes el producto perfecto que nadie quiere comprar.
- **Hacer el producto demasiado amplio:** Enfocarse en demasiados problemas diluye el valor.
- **Precificar demasiado bajo:** Señala falta de confianza. Los compradores desconfían de productos muy baratos.
- **Sin marketing claro:** El mejor producto no se vende a sí mismo.

---

## Recuperación

- **Validación débil:** Consulta 20 personas más en tu audiencia objetivo directamente.
- **No sabes a quién dirigirte:** Retrocede. Elige un segmento más pequeño de ta audiencia ideal.
- **Competencia muy fuerte:** Busca un ángulo diferente o un público diferente.
