# Página de Registro de Evento

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Escribir una landing page de registro para un evento
- Diseñar headlines, subheadlines y copias de beneficios
- Incluir social proof, testimonios y estadísticas
- Crear un call-to-action claro y un formulario de registro
- Optimizar para conversión (objetivo: 5-10% de visitantes a registros)

**NO** uses este skill para páginas de evento generales o agendas. Esto es específicamente para conversión.

---

## Principio Fundamental

UNA PÁGINA DE REGISTRO DE EVENTO TIENE UNA ÚNICA MISIÓN: LLEVAR AL VISITANTE DE "CURIOSO" A "REGISTRADO" EN 30 SEGUNDOS — TODO DEBE SERVIR A ESE OBJETIVO.

## Secciones de Página

### 1. Hero/Headline (Lo Primero que Ven)

```
ESTRUCTURA:
- Headline principal (una línea, 8-12 palabras)
- Subheadline (1-2 líneas que profundizan)
- Imagen o video hero que muestra el evento
- CTA principal (botón)
- Social proof inmediata (número de registrados, testimonial, logo de compañía)

EJEMPLO:
HEADLINE: "Aprende a Construir un Negocio de 6 Cifras Sin un Equipo"
SUBHEADLINE: "3 Días de Frameworks Comprobados + Networking con 200+ Solopreneurs"
IMAGE: Foto de evento anterior (energía, gente en acción)
BUTTON: "Reserva Mi Lugar (quedan 30)"
PROOF: "500+ solopreneurs hicieron esto. El 82% reportó ingresos en 90 días."
```

### 2. Beneficios (Por Qué Asistir)

```
**No lista características. Lista transformaciones.**

MAL: "Aprenderás sobre sistemas de automatización"
BIEN: "Automatiza tareas administrativas en 2 horas. Recupera 10+ horas a la semana."

3-5 beneficios claros, cada uno con:
- Beneficio principal (MAIÚSCULA)
- Descripción de cómo cambia su vida (1 línea)
- Momento específico (durante el evento cuando aprenden esto)
```

### 3. Speakers/Anfitriones

```
Para cada speaker:
- Foto grande
- Nombre + Título
- 1-2 logros clave (números > adjetivos)
- La charla que dan (nombre + duración)
- El resultado que obtendrás
```

### 4. Logística (No Entierres Esto)

```
**CUÁNDO:** Fecha exacta + hora de inicio/finalización + zona horaria
**DÓNDE:** Venue con dirección, estacionamiento, instrucciones de transporte
        O Plataforma virtual con enlace
**FORMATO:** In-person, virtual o hybrid
**COSTO:** Precio claro. "Gratuito" es mejor que ocultarlo.
**LO QUE OBTIENEN:** Acceso a grabaciones (si virtual), kit de materiales, acceso a comunidad, etc.
```

### 5. Social Proof (Confianza)

```
- Número de registrados (si es fuerte)
- Testimonios de eventos anteriores (foto + nombre + 1-2 oraciones)
- Menciones de prensa o compañías que lo apoyan
- Estadísticas post-evento ("92% reportaron nuevo contacto valioso")
- NPS o reseñas de Trustpilot/G2
```

### 6. Objection Handling

```
"¿Será demasiado básico para mí?"
"No. Ofrecemos tracks para principiantes e intermedios. Elige tu nivel en registro."

"¿Qué pasa si no puedo asistir?"
"Acceso a todas las grabaciones por 30 días después del evento."

"¿Es spam?"
"Prometemos: 1 follow-up email. Nada más. Puedes desuscribirse en cualquier momento."
```

### 7. FAQ

```
- ¿Cuál es la agenda exacta?
- ¿Puedo llevar a un amigo?
- ¿Cuál es tu política de reembolso?
- ¿Qué necesito traer / configurar?
- ¿Ofrecen recordatorios?
```

### 8. CTA Final / Form

```
BUTTON TEXT: "Reserva Mi Lugar" (no "Registrarse" — menos accionable)
FORM FIELDS:
- Nombre
- Email
- Rol/Industria (opcional pero preferido para segmentación)
- ¿Cómo escuchaste sobre nosotros? (para rastrear qué marketing funciona)

POST-REGISTRATION:
- Email de confirmación inmediato
- Agregar a calendario (.ics file)
- Recordatorio 1 semana antes
- Recordatorio 1 día antes
```

## Anti-Patrones

- **Burying the logística** — date, time, location, format deben ser OBVIOS.
- **Sin social proof** — incluir al menos una revisión o estadística.
- **Demasiado texto** — mantén párrafos a 2-3 líneas máximo.
- **Imagen de baja calidad** — la foto hero de tu evento anterior debe verse profesional.
- **Sin CTA claro** — button debe estar above the fold y no debe decir "Registrarse."

---

## Checklist de Conversión

```
- [ ] Headline principal es emocional + orientada a beneficios
- [ ] Logística (cuándo, dónde, formato, precio) es clara arriba
- [ ] Al menos 3-5 beneficios específicos listados
- [ ] Social proof (testimonios, números, estadísticas) presente
- [ ] Fotos de eventos anteriores o de los speakers
- [ ] CTA principal aparece en top y bottom
- [ ] Form pide solo esencial (nombre, email, opcionalmente rol)
- [ ] FAQ responde objeciones principales
- [ ] Page es mobile-responsive
```
