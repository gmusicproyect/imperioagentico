# Plataforma de Evento Virtual

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Planificar una configuración de evento virtual con selección de plataforma y requisitos técnicos
- Diseñar características de engagement que mantengan a los asistentes virtuales activos y conectados
- Crear un plan de producción técnica para webinars, summits o conferencias virtuales
- Evaluar y comparar plataformas de eventos virtuales para tus necesidades específicas

**NO** uses este skill para logística de eventos presenciales, configuración de podcast o producción de cursos pre-grabados. Esto es para eventos virtuales en vivo o semi-vivo con interacción de audiencia.

---

## Principio Fundamental

UN EVENTO VIRTUAL COMPITE CON CADA TAB EN EL NAVEGADOR DEL ASISTENTE — SI TU PLATAFORMA, ENGAGEMENT Y PRODUCCIÓN NO MANTIENEN ATENCIÓN, LAS PERSONAS SE IRÁN SIN AVISAR.

|-------|------------|---------|

## Fase 3: Construir

### Plan de Producción Técnica

```
## Configuración de Producción

**Streaming:**
- Plataforma: [Plataforma seleccionada]
- Calidad de stream: Mínimo 1080p
- Stream de respaldo: [Plataforma secundaria en caso de fallo]

**Audio/Video:**
- Cámaras de speaker: Webcam HD o DSLR con tarjeta de captura
- Micrófonos: Micrófono USB condensador o headset (mandatorio para todos los speakers)
- Iluminación: Ring light o iluminación de ventana (proporciona guía de prep para speaker)
- Fondo: Fondo virtual o fondo real limpio

**Roles:**
- Productor/tech host: Gestiona backstage, transiciones, solución de problemas
- Moderador: Gestiona chat, Q&A e interacción de audiencia
- Speaker host: Introduce speakers, gestiona timing
- Tech de respaldo: Standby para emergencias
```

### Diseño de Engagement

```
## Puntos de Engagement Táctil (por sesión)

**Cada 5-10 minutos:** Un punto de interacción
- Pregunta de poll
- Indicación de chat ("Escribe tu respuesta en chat")
- Pausa de Q&A
- Momento de reacción emoji

**Por sesión:** Al menos 3 de estos:
- [ ] Poll de apertura o rompehielos
- [ ] Interacción a mitad de sesión (poll, pregunta de chat, sala de descanso)
- [ ] Segmento de Q&A (en vivo o curado)
- [ ] Resource drop en chat (enlace, descarga, plantilla)
- [ ] Indicación de acción de cierre

**Entre sesiones:**
- Salas de networking o matching 1-on-1
- Stands virtuales de patrocinador
- Canales de chat por tópico
- Gamificación (puntos por participación)
```

### Experiencia de Asistente

```
## Jornada del Asistente
1. Email de confirmación de registro con calendar invite
2. Email pre-evento (3 días antes): acceso a plataforma, enlace de prueba técnica, horario
3. Recordatorio del día (1 hora antes): enlace de join directo
4. Pantalla de bienvenida con agenda y navegación
5. Sesiones en vivo con interacción en tiempo real
6. Oportunidades de networking entre sesiones
7. Post-evento: email de acceso a replay dentro de 24 horas
8. Seguimiento: encuesta + recursos + próximos pasos (día 2-3)
```

## Fase 4: Pulido

### 1. Guía Técnica de Speaker

Envía a cada speaker 2 semanas antes:

```
## Requisitos Técnicos de Speaker
- Internet: Conexión por cable preferida, mínimo 10 Mbps upload
- Cámara: A la altura de los ojos, cara bien iluminada, fondo limpio
- Audio: Micrófono externo requerido (sin micrófono de laptop)
- Software: [Nombre de plataforma] — descarga y prueba antes del evento
- Respaldo: Número telefónico del productor en caso de desconexión
- Slides: Envía 48 horas antes para pre-carga
- Ensayo: Verificación técnica obligatoria [fecha/hora]
```

### 2. Lista de Verificación del Día

```
- [ ] Todos los speakers probados y confirmados
- [ ] Plataforma en vivo y probada con miembro del equipo
- [ ] Stream de respaldo o plataforma listo
- [ ] Moderador de chat informado sobre directrices
- [ ] Grabación está habilitada
- [ ] Elementos de engagement (polls, Q&A) pre-cargados
- [ ] Lista de contacto de emergencia distribuida a todo el equipo
- [ ] Canal de soporte de asistente staffed (email o chat)
```

### 3. Métricas Posteriores al Evento

```
## Rastrear e Informar
- Asistencia concurrente pico
- Duración promedio de sesión por asistente
- Mensajes de chat enviados
- Polls completadas
- Preguntas de Q&A enviadas
- Vistas de replay (7-días y 30-días)
- Puntuación de satisfacción de asistente
- Net Promoter Score
```

## Ejemplo 1: Half-Day Virtual Summit (4 Horas)

```
Plataforma: Zoom Events ($150/mes)
Sesiones: 4 presentaciones de speaker (30 min cada) + 2 panels (30 min cada)
Engagement: Poll por sesión, Q&A en vivo, chat challenges
Equipo: 1 productor, 1 moderador, 1 host
Asistentes: 300 esperados
```

## Ejemplo 2: Multi-Day Virtual Conference (3 Días)

```
Plataforma: Hopin ($1,500)
Sesiones: 6 por día a través de 2 tracks + sesiones de networking
Engagement: Salas de descanso, matching de networking 1-on-1, stands de patrocinador, gamificación
Equipo: 2 productores, 3 moderadores, 1 host, 1 liaison de patrocinador
Asistentes: 1,000 esperados
```

## Anti-Patrones

- **Sin ensayo técnico** — speakers que no pueden descubrir la plataforma durante el evento en vivo arruinan la experiencia. Haz ensayos obligatorios.
- **Cero características de engagement** — un evento virtual donde la gente solo mira es un video de YouTube con pasos extras. Construye interacción en cada sesión.
- **Sin plan de respaldo** — las plataformas se cuelgan, internet falla, los speakers se desconectan. Ten un plan B para cada momento crítico.
- **Ignorar zonas horarias** — si tu audiencia cubre múltiples zonas, programa para la superposición y proporciona replays.
- **Sobre-programar** — los spans de atención virtuales son más cortos. Máximo 4-5 horas de contenido por día con descansos frecuentes.
- **Audio malo** — los asistentes tolerarán video malo pero se irán con audio malo. Haz obligatorios los micrófonos externos.

---

## Recuperación

- **La plataforma se cuelga a mitad del evento:** Cambia a respaldo (pre-comunicado). Email todos los asistentes el nuevo enlace inmediatamente. Ten un phone tree para speakers.
- **Baja asistencia el día del evento:** Envía un email "comenzando ahora." Promociona replays fuertemente. La tasa de engagement importa más que la cantidad de personas.
- **Los speakers no son tech-savvy:** Asigna un productor dedicado para gestionar su stream. Ten que se unan 30 minutos antes.
- **El presupuesto está cerca de cero:** Usa Zoom free tier (límite de 40-min) o StreamYard + YouTube Live (gratis). Enfócate en una sesión excelente en lugar de un día completo.
