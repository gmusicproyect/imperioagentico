# Guía de Identidad de Marca

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Documentar directrices de marca para identidad visual y verbal consistente
- Crear un libro de marca para freelancers, agencias o nuevos miembros del equipo
- Establecer estándares para uso de logo, color, tipografía e imagenología
- Formalizar reglas de marca que actualmente viven en la cabeza del fundador

**NO** uses este skill para diseño de logo, diseño de sitio web o estrategia de marketing. Esto es para documentar y codificar decisiones de identidad de marca existentes.

---

## Principio Fundamental

UNA GUÍA DE MARCA SOLO ES ÚTIL SI ES ESPECÍFICA SUFICIENTE PARA QUE ALGUIEN QUE NUNCA TE HA CONOCIDO PUEDA PRODUCIR TRABAJO EN MARCA — DIRECTRICES VAGAS PRODUCEN MARCAS INCONSISTENTES.

## Fase 1: Brief

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|---------|------------|---------|
| **Nombre de marca** | "¿Cuál es el nombre de tu marca?" | Debe ser proporcionado |
| **Archivos de logo** | "¿Tienes un logo? Comparte archivos o descríbelo." | Debe tener o describir dirección deseada |
| **Colores** | "¿Tienes colores de marca establecidos? (códigos hex si es posible)" | Recomendaré |
| **Tipografía** | "¿Algunas fuentes que uses consistentemente?" | Recomendaré |
| **Personalidad de marca** | "Describe tu marca en 3-5 adjetivos." | Debe ser proporcionado |
| **Audiencia** | "¿Quién usará esta guía? (equipo interno, freelancers, socios de agencia)" | Freelancers y equipo |
| **Materiales existentes** | "Comparte cualquier material de marca existente (sitio web, social, empaque)." | URL del sitio web |

**PUNTO DE CONTROL: Confirma brief antes de proceder.**

---

## Fase 2: Esquema

### Secciones de la Guía de Marca

1. **Descripción general de marca** — misión, visión, valores, declaración de posicionamiento
2. **Logo** — marca principal, variaciones, espacio libre, tamaño mínimo, ejemplos de mal uso
3. **Paleta de color** — colores primarios, secundarios, acentos con valores hex/RGB/CMYK
4. **Tipografía** — fuente de encabezado, fuente de cuerpo, jerarquía, especificaciones web e impresión
5. **Estilo de imagenología** — dirección de fotografía, estilo de ilustración, directrices de icono
6. **Voz de marca** — tono, vocabulario, dos y no's, ejemplos de escritura
7. **Aplicaciones** — tarjetas de presentación, redes sociales, firmas de email, presentaciones
8. **Do's y Don'ts** — ejemplos visuales de uso correcto e incorrecto para cada elemento

**PUNTO DE CONTROL: Confirma qué secciones incluir y nivel de profundidad.**

---

## Fase 3: Escribir

### Reglas de Escritura

- Incluye valores específicos (códigos hex, tamaños de fuente, proporciones de espaciado) — no "usa azul de marca"
- Muestra ejemplos visuales: uso correcto E incorrecto para cada elemento
- Proporciona orientación de formato de archivo: qué archivo de logo para qué caso de uso
- Escribe reglas de uso como comandos claros: "Siempre mantén 20px de espacio libre alrededor del logo"

### Formato de Documentación de Color

Para cada color:
- Nombre, código hex, RGB, CMYK (para impresión), Pantone (si aplica)
- Clasificación de accesibilidad (relación de contraste contra fondos blancos y oscuros)
- Contexto de uso (primario para CTAs, secundario para fondos, acento para destacados)

### Formato de Documentación de Tipografía

Para cada fuente:
- Nombre de fuente, peso y estilo
- Dónde obtenerla (enlace de Google Fonts, Adobe Fonts o info de licencia)
- Jerarquía de tamaño: H1, H2, H3, cuerpo, caption con tamaños exactos
- Recomendaciones de altura de línea y espaciado de letras

---

## Fase 4: Pulir

### Entregables Finales

1. **Guía completa de identidad de marca** — todas las secciones formateadas limpiamente
2. **Tarjeta de referencia rápida** — resumen de una página con logo, colores y fuentes
3. **Lista de verificación de activos** — lista de todos los activos de marca necesarios (archivos de logo, archivos de fuentes, plantillas)
4. **Notas de entrega** — qué enviar a freelancers o agencias junto con la guía

---

## Anti-Patrones

- **Nombres de color vagos** — "azul de marca" sin código hex significa que cada diseñador elige un azul diferente. Especifica valores exactos.
- **Sin ejemplos de mal uso** — mostrar solo uso correcto deja espacio para interpretación creativa. Muestra qué NO hacer.
- **Guía demasiado larga para leer** — un libro de marca de 60 páginas que nadie abre es peor que una guía de 5 páginas que todos usan. Prioriza brevedad.
- **Especificaciones digitales faltantes** — especificaciones de impresión sin especificaciones web (o viceversa) deja la mitad de los casos de uso sin cubrir.
- **Estático, nunca actualizado** — las marcas evolucionan. Revisa y actualiza la guía anualmente.

---

## Recuperación

- **Sin logo aún:** Documenta color, tipografía y directrices de voz primero. Agrega la sección de logo después de que el diseño esté completo.
- **Usuario no puede articular personalidad de marca:** Pídeles que nombren 3 marcas que admiren y 3 que no. Extrae traits de personalidad del contraste.
- **Materiales existentes inconsistentes:** Documenta el estándar aspiracional, no la inconsistencia actual. Señala materiales que necesitan actualización.
- **Sin presupuesto para fuentes profesionales:** Recomienda alternativas gratuitas de alta calidad de Google Fonts que coincidan con la personalidad deseada.
