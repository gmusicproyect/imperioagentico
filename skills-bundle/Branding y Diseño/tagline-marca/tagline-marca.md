# Tagline de Marca

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Crear un tagline de marca o slogan desde cero
- Refrescar un tagline existente que ya no encaja
- Generar múltiples opciones de tagline con justificación para cada una
- Desarrollar variantes de tagline para diferentes canales o campañas

**NO** uses este skill para headlines, ad copy o descripciones de producto. Esto es para el tagline de marca central que define la identidad de tu negocio.

---

## Principio Fundamental

UN GRAN TAGLINE ES MEMORABLE, SIGNIFICATIVO E IMPOSIBLE DE CONFUNDIR CON UN COMPETIDOR — DEBE DECIR ALGO QUE SOLO TU MARCA PUEDE DECIR.

---

## Fase 1: Brief

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|---------|------------|---------|
| **Nombre del negocio** | "¿Cómo se llama tu negocio?" | Sin predeterminado — debe ser proporcionado |
| **Qué haces** | "Describe qué hace tu negocio en una oración." | Sin predeterminado — debe ser proporcionado |
| **Audiencia objetivo** | "¿Quién es tu cliente ideal?" | Sin predeterminado — debe ser proporcionado |
| **Diferenciador clave** | "¿Qué te hace diferente de los competidores?" | Sin predeterminado — debe ser proporcionado |
| **Personalidad de marca** | "Si tu marca fuera una persona, ¿cómo la describirías?" | Confiado, accesible, experto |
| **Tagline actual** | "¿Tienes un tagline existente?" | Ninguno |
| **Taglines que admiras** | "Comparte 2-3 taglines de otras marcas que te gusten (cualquier industria)." | Ninguno |

**PUNTO DE CONTROL: Confirma brief antes de generar.**

---

## Fase 2: Esquema

### Categorías de Tagline

Genera opciones en estos tipos de fórmula:

```
1. Impulsado por beneficio — establece lo que el cliente obtiene
2. Imperativo — dice al cliente qué hacer
3. Descriptivo — dice qué hace la marca
4. Provocador — desafía una creencia o norma
5. Aspiracional — pinta el estado futuro
6. Ingenio — usa juego de palabras o doble significado
```

**PUNTO DE CONTROL: Confirma qué categorías priorizar (o hacer todas).**

---

## Fase 3: Escribir

### Genera 15-20 Opciones de Tagline

Para cada tagline, proporciona:

```
**"[Tagline]"**
- Categoría: [Beneficio / Imperativo / Descriptivo / etc.]
- Justificación: [Por qué esto funciona — 1 oración]
- Mejor usado en: [Sitio web, bios sociales, empaque, anuncios]
```

### Criterios de Calidad de Tagline

Cada tagline debe pasar estas pruebas:

| Prueba | Pregunta |
|--------|----------|
| **Memorable** | ¿Podría alguien recordarlo después de escucharlo una vez? |
| **Significativo** | ¿Comunica un beneficio real o posicionamiento? |
| **Único** | ¿Podría un competidor usar esta línea exacta? Si sí, falla. |
| **Corto** | ¿Bajo 8 palabras? (Ideal: 3-6 palabras) |
| **Intemporal** | ¿Seguirá funcionando en 5 años? |
| **Pronunciable** | ¿Suena natural cuando se dice en voz alta? |

### Top 5 Recomendaciones

Presenta las 5 opciones más fuertes con justificación detallada:

```
## Top 5 Taglines

### 1. "[Tagline]"
**Por qué funciona:** [2-3 oraciones sobre posicionamiento, memorabilidad y encaje de audiencia]
**Dónde usarlo:** [Colocaciones específicas — header, bios sociales, firma de email, anuncios]
**Riesgo potencial:** [Algún inconveniente o malinterpretación a considerar]

### 2. "[Tagline]"
...
```

### Pares de Prueba A/B

```
## Sugerencias de Prueba A/B

**Prueba 1:** Beneficio vs Imperativo
- A: "[Tagline de beneficio]"
- B: "[Tagline imperativo]"
- Dónde probar: [Header de sitio web, anuncios sociales]

**Prueba 2:** Corto vs Descriptivo
- A: "[Tagline de 3 palabras]"
- B: "[Tagline descriptivo de 6 palabras]"
```

---

## Fase 4: Pulir

### 1. Lista de Verificación de Tagline

```
## Lista de Verificación de Calidad

- [ ] Bajo 8 palabras (idealmente 3-6)
- [ ] Comunica un beneficio o posicionamiento de marca
- [ ] No puede ser usado por un competidor sin modificación
- [ ] Suena natural cuando se dice en voz alta
- [ ] Funciona en plataformas (sitio web, social, impresión, anuncios)
- [ ] No confía en jerga o conocimiento interno
- [ ] Intemporal — no atado a una tendencia o año
- [ ] Sin significados negativos no intencionados o asociaciones
```

### 2. Guía de Uso

Proporciona orientación sobre dónde y cómo desplegar el tagline seleccionado:

```
## Guía de Uso de Tagline

- **Header del sitio web:** Empareja con el nombre de marca: "[Nombre de Marca] — [Tagline]"
- **Bios sociales:** Usa como la primera línea de la bio
- **Firma de email:** Debajo del nombre y título
- **Tarjetas de presentación:** Debajo del logo
- **Publicidad:** Como la línea de cierre en anuncios
```

## Ejemplo: Taglines para una Marca de Entrenamiento de Negocio Freelance

```
Negocio: FreeAgent Academy
Hace: Enseña a freelancers cómo aterrizar clientes y crecer ingresos
Audiencia: Freelancers ganando bajo $100K que quieren escalar

Opciones principales:
1. "Aterriza clientes. Construye libertad." — Beneficio, aspiracional
2. "La escuela de negocio que los freelancers merecen." — Descriptivo, posicionamiento
3. "Deja de ser freelancer. Empieza a construir." — Provocador, imperativo
4. "De solo a escalable." — Aspiracional, conciso
5. "Más clientes. Menos hustle." — Beneficio, memorable
```

## Anti-Patrones

- **Demasiado genérico** — "Calidad en la que puedes confiar" aplica a cada negocio en la tierra. El tagline debe ser únicamente tuyo.
- **Demasiado largo** — nada sobre 8 palabras es una oración, no un tagline. Edita sin piedad.
- **Pesado en jerga** — "Apalancando soluciones sinérgicas" no significa nada para humanos reales.
- **Demasiado ingenioso** — si el juego de palabras requiere explicación, falla. La claridad vence al ingenio.
- **Describe el producto, no el beneficio** — "Hacemos software de facturación" es una descripción. "Consigue pago más rápido" es un tagline.
- **Siguiendo tendencias** — "Tu [tema] bestie" envejecerá mal. Apunta a intemporal.

---

## Recuperación

- **El usuario odia todas las opciones:** Pregunta cuáles 2-3 están más cerca y qué específicamente se siente mal (¿demasiado lúdico? ¿demasiado corporativo? ¿demasiado genérico?). Genera 10 más en la dirección refinada.
- **No puedo articular diferenciador:** Pregunta "¿Por qué tus últimos 3 clientes te eligieron sobre alternativas?" La respuesta es el diferenciador.
- **El tagline necesita funcionar en múltiples idiomas:** Señala problemas potenciales de traducción. Evita modismos y juegos de palabras que no se traducen.
- **Múltiples stakeholders no están de acuerdo:** Ejecuta una prueba simple — muestra las top 3 opciones a 10 personas en la audiencia objetivo y elige la que resuena más.
- **El tagline existente tiene equidad de marca:** Considera evolucionar en lugar de reemplazar. Las actualizaciones pequeñas pueden modernizar sin perder reconocimiento.
