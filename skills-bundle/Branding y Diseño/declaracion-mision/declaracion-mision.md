# Declaración de Misión

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Redactar declaraciones de misión, visión y valores para una organización o negocio
- Facilitar un proceso de entrada de stakeholders para definir el propósito organizacional
- Refinar o modernizar declaraciones de misión existentes que se sienten desactualizadas o vagas
- Crear ejercicios de alineación que conecten la misión con operaciones diarias

**NO** uses este skill para taglines de marca, pitches de ascensor o slogans de marketing. Esto es para declaraciones organizacionales fundamentales que guíen estrategia y toma de decisiones.

---

## Principio Fundamental

UNA DECLARACIÓN DE MISIÓN QUE VIVE EN UNA PARED PERO NO EN DECISIONES DIARIAS ES DECORACIÓN — LA PRUEBA REAL ES SI CADA MIEMBRO DEL EQUIPO PUEDE USARLA PARA DECIDIR A QUÉ DECIR SÍ Y NO.

## Fase 1: Brief

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|-------|------------|---------|
| **Organización** | "¿Cuál es la organización o negocio?" | Sin predeterminado — debe ser proporcionado |
| **Misión actual** | "¿Tienes una declaración de misión existente? Si es así, ¿cuál es?" | Ninguno — comenzando desde cero |
| **A quién sirves** | "¿Cuál es tu audiencia primaria o beneficiario?" | Sin predeterminado — debe ser proporcionado |
| **Qué haces** | "¿Cuál es la actividad central o servicio que proporcionas?" | Sin predeterminado — debe ser proporcionado |
| **Por qué importa** | "¿Qué cambio creas en el mundo?" | Sin predeterminado — debe ser proporcionado |
| **Stakeholders** | "¿Quién debe tener entrada? (fundador solo, equipo, junta directiva, clientes)" | Solo fundador |

**PUNTO DE CONTROL: Confirma el brief antes de proceder.**

## Fase 2: Descubrimiento

### Proceso de Entrada de Stakeholders

Si hay múltiples stakeholders involucradas:

```
## Preguntas para Stakeholders (envía a cada persona)
1. En una oración, ¿qué existe esta organización para hacer?
2. ¿A quién servimos, y qué necesitan de nosotros?
3. ¿Qué nos hace diferentes de otros que hacen trabajo similar?
4. ¿Qué perdería el mundo si desapareciéramos mañana?
5. ¿Qué tres palabras describen cómo hacemos nuestro trabajo?
```

### Elementos de Fundación

Extrae de las entradas:

```
## Fundación de Misión
**A quién servimos:** [Audiencia específica]
**Qué hacemos:** [Actividad central]
**Por qué importa:** [El cambio que creamos]
**Cómo somos diferentes:** [Nuestro enfoque único]
**Qué nos guía:** [Temas de valores centrales]
```

### Misión vs. Visión vs. Valores

Define cada una claramente antes de escribir:

```
**Misión:** Qué hacemos hoy y para quién (tiempo presente)
**Visión:** El estado futuro hacia el que estamos trabajando (tiempo futuro)
**Valores:** Cómo nos comportamos y tomamos decisiones (principios)
```

**PUNTO DE CONTROL: Presenta los elementos de fundación y obtén alineación antes de escribir.**

## Fase 3: Escribir

### Fórmula de Declaración de Misión

Usa una de estas estructuras:

**Fórmula 1: Nosotros [acción] para [audiencia] para que [impacto].**
Ejemplo: "Proporcionamos asistencia legal gratuita a familias inmigrantes para que puedan navegar el sistema con dignidad."

**Fórmula 2: [Organización] existe para [acción] mediante [método] para [audiencia].**
Ejemplo: "Imperio Digital existe para acelerar el éxito de solopreneurs haciendo herramientas de IA accesibles y accionables."

**Fórmula 3: Para [declaración de impacto] mediante [método].**
Ejemplo: "Para eliminar la ceguera prevenible mediante atención oftalmológica asequible en comunidades desatendidas."

### Reglas de Declaración de Misión

- Una oración, menos de 25 palabras si es posible
- Tiempo presente — qué haces ahora, no a qué aspiras
- Lo suficientemente específico para guiar decisiones
- Sin jerga, palabras de moda o lenguaje corporativo
- Un niño de 12 años debe poder entenderlo

### Declaración de Visión

- Una a dos oraciones
- Tiempo futuro — el mundo que estás creando
- Ambicioso pero creíble
- Inspira sin ser vago

```
Ejemplo: "Un mundo donde cada solopreneur tiene las herramientas de IA para competir con empresas 100 veces su tamaño."
```

### Valores (3-5 máximo)

Para cada valor:

```
## [Nombre de Valor]
**Qué significa:** [Definición de una oración]
**Cómo se ve:** [Comportamiento observable]
**Lo que NO significa:** [Malinterpretación común]
```

Ejemplo:
```
## Velocidad Sobre Perfección
**Qué significa:** Enviamos rápido e iteramos basado en feedback real.
**Cómo se ve:** Lanzar un MVP en 2 semanas en lugar de un producto pulido en 6 meses.
**Lo que NO significa:** Ser descuidado o saltarse verificaciones de calidad.
```

## Fase 4: Pulir

### 1. Prueba de Estrés

Prueba la declaración de misión contra estos escenarios:

```
## Prueba de Filtro de Decisión
¿Puede esta declaración de misión ayudarte a responder:
- [ ] "¿Deberíamos lanzar este nuevo producto?" (¿Sirve a nuestra audiencia de nuestra manera?)
- [ ] "¿Deberíamos aceptar esta asociación?" (¿Se alinea con nuestra misión?)
- [ ] "¿Deberíamos contratar a esta persona?" (¿Creen en esta misión?)
- [ ] "¿Deberíamos pivotear?" (¿Seguimos sirviendo la misma necesidad?)

Si la misión no puede ayudarte a responder estas, es demasiado vaga.
```

### 2. Alineación de Stakeholders

Presenta 2-3 opciones de declaración de misión para que el grupo de stakeholders vote. Incluye:
- Por qué cada opción fue escrita
- Qué enfatiza cada opción
- Recomendación con fundamento

### 3. Guía de Implementación

```
## Poniendo la Misión a Trabajar
- Agrega a página de información del sitio web, firmas de email y propuestas
- Abre reuniones de equipo con un momento de misión (comparte una historia que la ejemplifique)
- Usa en contratación: pregunta a candidatos qué significa la misión para ellos
- Referencia en discusiones de estrategia: "¿Se alinea esto con nuestra misión?"
- Revisa anualmente — si la organización evoluciona, la misión puede necesitar evolucionar también
```

Misión: "Enseñamos a jóvenes desatendidos a programar para que puedan construir sus propios futuros."
Visión: "Una industria tecnológica que refleja la diversidad de las comunidades a las que sirve."
Valores: Acceso, Excelencia, Comunidad

```
Misión: "Damos a solopreneurs los sistemas para ejecutar un negocio de seis cifras sin equipo."
Visión: "Un mundo donde una persona con las herramientas correctas puede superar el desempeño de una empresa de diez."
Valores: Apalancamiento, Simplicidad, Resultados Sobre Teoría
```

## Anti-Patrones

- **Declaraciones escritas por comité** — demasiados cocineros producen papilla genérica. Una persona redacta, el grupo refina.
- **Sopa de palabras de moda** — "Sinergizamos soluciones innovadoras para empoderar a las stakeholders" no significa nada. Usa lenguaje plano.
- **Demasiado largo** — si toma más de 10 segundos decirlo, nadie la recordará. Mantenla ajustada.
- **Demasiado vago** — "Hacemos el mundo un lugar mejor" podría aplicarse a cualquier organización. Sé específico sobre a quién y cómo.
- **Misión aspiracional** — la misión es lo que haces AHORA. La visión es el futuro. No los confundas.
- **Valores sin comportamientos** — "Integridad" en una pared no significa nada sin "cómo se ve la integridad aquí."

## Recuperación

- **Las stakeholders no pueden estar de acuerdo:** Encuentra el solapamiento. Pregunta "¿En qué están TODOS de acuerdo que existe para hacer?" Comienza desde tierra común.
- **La misión existente es sagrada pero desacualizada:** Posiciona la actualización como "evolución" no "reemplazo." Mantén la intención central, moderniza el lenguaje.
- **El usuario quiere más de 5 valores:** Fuerza-clasifica. Si todo es un valor, nada lo es. Elige los 3-5 que realmente guían decisiones.
- **El usuario sigue agregando palabras:** Desafía cada palabra. Pregunta "Si eliminamos [esta palabra], ¿cambiaría el significado?" Si no, córtala.
