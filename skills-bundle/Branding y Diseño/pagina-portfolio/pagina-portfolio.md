# Página de Portfolio

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Escribir copia de página de portfolio que convierta visitantes en clientes
- Redactar descripciones de estudio de caso de proyecto con resultados medibles
- Integrar testimoniales y social proof estratégicamente
- Crear un flujo claro de CTA de portfolio a investigación

**NO** uses este skill para escritura de resume, perfiles de LinkedIn o copia de sitio web completa. Esto es para páginas de portfolio/muestras de trabajo en un sitio web de freelancer o consultor.

---

## Principio Fundamental

TU PORTFOLIO NO VENDE TUS HABILIDADES — VENDE LOS RESULTADOS QUE TUS HABILIDADES PRODUCEN. CADA DESCRIPCIÓN DE PROYECTO DEBE RESPONDER: "¿QUÉ OBTUVO EL CLIENTE?"

---

## Fase 1: Brief de Portfolio

### Entradas Requeridas

| Entrada | Qué Preguntar | Predeterminado |
|---------|------------|---------|
| **Tipo de servicio** | "¿Qué haces — diseño, copywriting, desarrollo, consultoría?" | Sin predeterminado — debe ser proporcionado |
| **Número de proyectos** | "¿Cuántos proyectos de portfolio quieres presentar?" | 4-6 proyectos |
| **Cliente objetivo** | "¿Quién es tu cliente ideal visitando esta página?" | Dueños de pequeños negocios |
| **Proyectos a presentar** | "Lista cada proyecto: nombre de cliente, qué hiciste y el resultado." | Sin predeterminado — debe ser proporcionado |
| **Testimoniales** | "¿Tienes citas de cliente o reseñas para incluir?" | Ninguno — escribiremos sin |

**PUNTO DE CONTROL: Confirma lista de proyectos y audiencia objetivo antes de escribir copia.**

## Fase 2: Estructura de Página

### Layout de Página de Portfolio

```
## [Tu Nombre] — Portfolio

### Sección de Intro (2-3 oraciones)
[A quién ayudas, qué haces y la transformación que entregas.
No tu bio — tu propuesta de valor.]

### Proyectos Destacados (4-6 proyectos)
[Tarjetas/secciones de proyecto individuales — ver Fase 3 para formato]

### Tira de Testimoniales
[2-3 citas de clientes colocadas entre secciones de proyecto]

### Sección CTA
[Próximo paso claro — reserva una llamada, solicita presupuesto, envíame email]
```

### Reglas de Selección de Proyecto

1. **Lidera con tu mejor resultado** — el resultado más impresionante va primero
2. **Muestra rango** — presenta diferentes industrias, tipos de proyecto o alcances
3. **La recencia importa** — prioriza proyectos de los últimos 12-18 meses
4. **Elimina proyectos débiles** — 4 proyectos fuertes vencen 8 mediocres
5. **Haz coincidir tu cliente objetivo** — presenta trabajo similar a lo que tu cliente ideal necesita

## Fase 3: Descripciones de Proyecto

### Formato de Tarjeta de Proyecto

```
### [Nombre de Proyecto o Nombre de Cliente]

**Industria:** [Industria del cliente]
**Servicio:** [Qué proporcionaste]
**Desafío:** [1-2 oraciones — qué problema tenía el cliente]
**Solución:** [1-2 oraciones — qué hiciste]
**Resultado:** [Resultado específico y medible]

> "[Testimonial del cliente sobre trabajar contigo]" — [Nombre del cliente, título]
```

### Reglas de Escritura

- Lidera con el problema del cliente, no tu proceso
- Cuantifica resultados siempre que sea posible — porcentajes, dólares, tiempo ahorrado
- Si no puedes compartir nombres de cliente, usa descriptores de industria ("una startup SaaS B2B")
- Mantén cada proyecto bajo 100 palabras — el portfolio es un highlight reel, no un estudio de caso
- Usa voz activa — "Rediseñé el flujo de checkout" no "El flujo de checkout fue rediseñado"

### Ejemplos de Resultado por Tipo de Servicio

| Servicio | Resultado Débil | Resultado Fuerte |
|---------|------------|---------------|
| Diseño web | "Entregué un sitio web moderno" | "Aumenté la tasa de conversión de 1.2% a 3.8% en 60 días" |
| Copywriting | "Escribí campañas de email" | "La secuencia de email generó $42K en ingresos en 3 meses" |
| Marketing | "Administré cuentas de redes sociales" | "Crecí Instagram de 800 a 12K, impulsando 200+ visitas mensuales a la tienda" |
| Consultoría | "Proporcioné recomendaciones estratégicas" | "Los cambios operacionales ahorraron $180K anuales en costos generales" |

## Fase 4: CTAs & Pulir

### Sección CTA

```
## ¿Listo para obtener resultados como estos?

[1-2 oraciones reforzando el valor — no "contratame" pero "hablemos sobre lo que es posible para tu negocio."]

[Botón Principal de CTA: "Reserva una Consulta Gratuita" / "Obtén un Presupuesto" / "Inicia un Proyecto"]

[Opción secundaria: "O envíame un email a [email] para contarme sobre tu proyecto."]
```

### Lista de Verificación de Página de Portfolio

- [ ] La sección intro establece a quién ayudas y qué resultados entregas
- [ ] 4-6 proyectos presentados con estructura problema-solución-resultado
- [ ] Al menos 2 testimoniales de cliente incluidos
- [ ] Cada proyecto tiene un resultado cuantificado u resultado específico
- [ ] El CTA es claro, prominente y aparece en el fondo (y opcionalmente a mitad de página)
- [ ] La página carga rápido — imágenes están optimizadas
- [ ] Layout responsive en móvil
- [ ] La info de contacto es fácil de encontrar

## Anti-Patrones

- **Descripciones pesadas en proceso** — los clientes no se preocupan por tu metodología. Se preocupan por lo que OBTENDRÁN.
- **Sin resultados medibles** — "creé un diseño hermoso" no es un resultado. Ingresos, conversiones, tiempo ahorrado — eso es un resultado.
- **Demasiados proyectos** — mostrar 20 proyectos crea fatiga de decisión. Cura sin piedad.
- **Sin testimoniales** — descripciones de proyecto sin validación de terceros son solo afirmaciones. Agrega citas de cliente.
- **CTA débil o sin CTA** — una página de portfolio sin un próximo paso claro es un callejón sin salida.
- **Trabajo desactualizado** — proyectos de 5 años atrás señalan que no estás obteniendo clientes actuales.

---

## Recuperación

- **Sin resultados cuantificados:** Estima basado en lo que sabes. "Ayudé a aumentar las tasas de apertura de email" es mejor que nada, pero presiona para obtener especificidades.
- **Confidencialidad del cliente:** Usa descripciones anónimas — "una marca de skincare DTC" — y enfócate en el tipo de resultado en lugar de nombrar al cliente.
- **Sin testimoniales aún:** Comunícate con clientes anteriores y pide una cita de 1-2 oraciones. La mayoría dirá que sí si lo haces fácil.
- **Demasiados pocos proyectos:** Presenta 3-4 proyectos fuertes con descripciones más profundas en lugar de rellenar con trabajo débil. Calidad sobre cantidad.
- **Los proyectos abarcan servicios muy diferentes:** Agrupa proyectos por tipo de servicio con encabezados de sección claros para que la página no se sienta dispersa.
