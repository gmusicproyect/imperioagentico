# Onboarding de Proveedores

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Incorporar un nuevo proveedor rápidamente
- Establecer expectativas y procesos
- Crear comunicación clara
- Evitar malentendidos desde el inicio

---

## Principio Fundamental

UNA BUENA INCORPORACIÓN CREA UNA RELACIÓN PRODUCTIVA POR AÑOS — UNA POBRE INCORPORACIÓN CREA PROBLEMAS QUE DURAN AÑOS.

---

## Proceso de Onboarding

### Fase 1: Contrato (Antes de comenzar)

- [ ] Contrato firmado por ambas partes
- [ ] Término, plazos, precio acordados
- [ ] Condiciones de pago claras
- [ ] Expectativas de calidad documentadas

### Fase 2: Kickoff (Primeros días)

- [ ] Reunión inaugural - objetivos, cronograma
- [ ] Pasar documentación, accesos necesarios
- [ ] Presentación de punto de contacto principal
- [ ] Revisión de procesos y comunicación

### Fase 3: Rampa (Primera semana)

- [ ] Proveedor completa primer entregable
- [ ] Revisión y feedback
- [ ] Ajustes de proceso si es necesario
- [ ] Confirmación de cadencia de comunicación

### Fase 4: Estabilización (Mes 1)

- [ ] Revisión de calidad - ¿Cumple estándares?
- [ ] Ajustes de proceso si es necesario
- [ ] Establecer cadencia de seguimiento regular

## Plantilla de Expectativas

```
## Acuerdo de Trabajo con [Proveedor]

**Contacto Principal:** [Nombre]
**Horas de Disponibilidad:** [Cuándo disponible]
**Tiempo de Respuesta:** [Aceptación 24 horas, entrega X horas]

**Calidad:** [Estándar esperado]
**Pagos:** [Cuándo, cómo]
**Revisión:** [Cuándo revisamos el trabajo]

**Terminación:** [Cómo terminar relación, aviso]
```

---

## Anti-Patrones

- **Sin contrato claro** — suposiciones diferentes
- **Sin expectativas de calidad** — sorpresas después
- **Sin punto de contacto** — comunicación desorganizada
- **Sin cadencia de revisión** — problemas no identificados

---

## Recuperación

- **Proveedor no cumple:** Feedback temprano, mejora proceso
- **Cambios frecuentes en necesidades:** Comunica, negocia cambios
- **Desalineación persistente:** Considera cambiar proveedor
