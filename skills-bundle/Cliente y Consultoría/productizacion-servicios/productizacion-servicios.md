# Productización de Servicios

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Convertir un servicio personalizado en una oferta de alcance fijo y precio fijo
- Definir entregables repetibles, procesos y precios para un servicio
- Crear una página de servicio que venda sin una propuesta personalizada para cada cliente
- Construir procedimientos operativos estándar para entrega de servicio consistente

**NO USES** este skill para desarrollo de productos SaaS, creación de productos físicos o engagement de consultoría completamente personalizado. Esto es para convertir servicios en paquetes comprables.

---

## Principio Fundamental

UN SERVICIO PRODUCTIZADO TIENE UN ALCANCE CLARO, UN PRECIO FIJO Y UN PROCESO REPETIBLE — EL CLIENTE SABE EXACTAMENTE QUÉ OBTIENE, Y TÚ SABES EXACTAMENTE QUÉ ENTREGAS.

---

## Fase 1: Análisis de Servicios

### Información Requerida

| Información | Qué Preguntar | Valor por Defecto |
|-------|------------|---------|
| **Servicio actual** | "¿Qué servicio ofreces que quieras productizar?" | Sin valor por defecto — debe proporcionarse |
| **Solicitud más común** | "¿Qué piden el 80% de tus clientes?" | Sin valor por defecto — debe proporcionarse |
| **Cronograma típico** | "¿Cuánto tiempo toma típicamente entregar este servicio?" | 1-2 semanas |
| **Precios actuales** | "¿Cuánto típicamente cobras?" | Varía por proyecto |
| **Pain point** | "¿Qué te frustra más de entregar este servicio hoy?" | Alcance personalizado y quoting para cada cliente |

**PUNTO DE CONTROL: Confirma el servicio y el patrón de solicitud común antes de productizar.**

---

## Fase 2: Diseño de Paquete

### Identificar la Oferta Central

Desglosa el servicio a su entregable repetible y de alto valor:

1. **Lista todo lo que haces** para un cliente típico en este área de servicio
2. **Identifica el 80/20** — ¿qué 20% de actividades entrega el 80% del valor?
3. **Elimina personalización** — ¿qué puede estandarizarse sin dañar resultados?
4. **Define el límite** — ¿qué está incluido y qué requiere un engagement separado?

### Estructura de Paquete

Crea 1-3 niveles:

```
## Paquetes de [Nombre de Servicio]

### Iniciador — $[precio]
**Mejor para:** [Para quién es esto]
**Incluye:**
- [Entregable 1]
- [Entregable 2]
- [X] rondas de revisiones
**Cronograma:** [X] días hábiles
**No incluido:** [Exclusión clave]

### Profesional — $[precio] ← Más Popular
**Mejor para:** [Para quién es esto]
**Incluye:**
- Todo en Iniciador, más:
- [Entregable adicional]
- [Entregable adicional]
- [X] rondas de revisiones
**Cronograma:** [X] días hábiles

### Premium — $[precio]
**Mejor para:** [Para quién es esto]
**Incluye:**
- Todo en Profesional, más:
- [Complemento de alto valor]
- [Soporte prioritario o cronograma más rápido]
- [Sesión de estrategia o soporte continuo]
**Cronograma:** [X] días hábiles
```

### Estrategia de Precios

- Precio basado en valor entregado, no horas gastadas
- El nivel medio debe ser el objetivo — establécele precio para ser la opción obvia
- El nivel inferior cubre costos y sirve como punto de entrada
- El nivel superior existe para compradores premium y hace que el nivel medio se vea razonable

## Fase 3: Proceso de Entrega

### Procedimiento Operativo Estándar

```
## SOP de Entrega — [Nombre de Servicio]

### Paso 1: Onboarding de Cliente
- Cliente compra paquete o completa formulario de intake
- Email de bienvenida automatizado con cronograma y próximos pasos
- Recopia todos los materiales requeridos (cuestionario, assets, acceso)

### Paso 2: Producción
- Día 1-2: [Trabajo inicial]
- Día 3-5: [Creación de entregable central]
- Día 5-7: [Verificación de calidad y revisión interna]

### Paso 3: Entrega
- Envía primer borrador al cliente con instrucciones de revisión
- Cliente proporciona feedback dentro de [X] días hábiles
- Implementa revisiones (ronda 1 de [X] incluida)

### Paso 4: Finalización
- Entrega archivos finales en formatos especificados
- Envía follow-up email con consejos de uso o próximos pasos
- Solicita testimonial o reseña (7 días post-entrega)
```

### Cuestionario de Intake

Crea un formulario de intake estandarizado que reemplace llamadas de descubrimiento personalizadas:

- ¿Cuál es tu negocio y quién es tu audiencia objetivo?
- ¿Cuál es el objetivo principal para este [entregable]?
- Comparte ejemplos o referencias que te gusten
- ¿Qué pautas de marca o assets deberíamos usar?
- ¿Hay plazos o restricciones?

```
3. [Paso 3 — recibe entregable]

[3-5 preguntas frecuentes]

```

### Posicionamiento vs. Servicios Personalizados

| Servicio Personalizado | Servicio Productizado |
|---------------|-------------------|
| "Saltemos a una llamada para discutir" | "Aquí está lo que obtienes — compra ahora" |
| Propuesta requerida | Precio fijo, compra instantánea |
| Cronograma variable | Fecha de entrega garantizada |
| Negociación de alcance | Límites claros |
| Revisiones ilimitadas | Rondas de revisión definidas |

## Anti-Patrones

- **Productizar demasiado a la vez** — comienza con un servicio, perfecciona el proceso, luego expande. No lances 5 paquetes simultáneamente.
- **Incluirlo todo** — la productización requiere decir no. Estrategia personalizada, revisiones ilimitadas y soporte continuo no pueden estar todos en el paquete base.
- **Precios demasiado bajos** — el precio fijo debe ser MÁS rentable que el trabajo por hora porque tu eficiencia mejora con el tiempo.
- **Sin proceso de intake** — sin un cuestionario estandarizado, terminas en llamadas de descubrimiento personalizado, derrotando el propósito.
- **Paquetes rígidos sin ruta de upsell** — siempre ofrece una forma para que los clientes agreguen o actualicen.

---

## Recuperación

- **El servicio es demasiado complejo para productizar:** Productiza una pieza — el entregable más común y repetible. Mantén el resto como trabajo personalizado.
- **Los clientes quieren personalización:** Ofrece el paquete productizado como base con complementos claramente preciados para elementos personalizados.
- **No hay suficiente volumen para justificar estandarización:** Comienza con el proceso y plantillas de todos modos. Cuando venga el volumen, estarás listo.
- **La calidad de entrega varía:** Ajusta el SOP, crea plantillas y listas de verificación, construye un paso de revisión de calidad antes de entrega.
- **Los clientes solo eligen el nivel más barato:** Ajusta la estructura de niveles — haz que el nivel medio sea significativamente más valioso que el inferior.
