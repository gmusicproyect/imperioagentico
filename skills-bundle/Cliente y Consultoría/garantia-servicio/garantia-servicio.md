# Garantía de Servicio

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Crear una garantía de servicio que construya confianza del comprador
- Definir términos de garantía específicos, condiciones y exclusiones
- Diseñar un proceso de reclamación que sea justo para ambas partes
- Usar garantías como diferenciador competitivo y herramienta de conversión

**NO USES** este skill para garantías de producto, políticas de reembolso de dinero o documentos de cumplimiento legal. Esto es para garantías de satisfacción del proveedor de servicios. Haz que un abogado revise antes de publicar.

---

## Principio Fundamental

UNA GARANTÍA DE SERVICIO DEMASIADO VAGA ES SIN SENTIDO Y UNA DEMASIADO AMPLIA TE ARRUINARÁ — LAS MEJORES GARANTÍAS SON ESPECÍFICAS, MEDIBLES Y VINCULADAS A TUS ESTÁNDARES DE ENTREGA REALES.

## Fase 1: Diseño de Garantía

### Información Requerida

| Información | Qué Preguntar | Valor por Defecto |
|-------|------------|---------|
| **Servicio ofrecido** | "¿Qué servicio cubre esta garantía?" | Sin valor por defecto — debe proporcionarse |
| **Tipo de garantía** | "¿Garantía de satisfacción, garantía de resultados o garantía de desempeño?" | Garantía de satisfacción |
| **Remedio** | "¿Qué ofreces si se dispara la garantía — reembolso, rehacer, crédito?" | Rehaz el trabajo sin costo |
| **Condiciones** | "¿Qué debe hacer el cliente para que la garantía aplique?" | Proporciona feedback dentro de 14 días de entrega |
| **Tolerancia de riesgo** | "¿Cuánto riesgo financiero puedes absorber de reclamaciones de garantía?" | Bajo — menos del 5% de ingresos |

**PUNTO DE CONTROL: Confirma tipo de garantía y remedio antes de escribir los términos.**

## Fase 2: Tipos de Garantía

### Opción 1: Garantía de Satisfacción

```
## Nuestra Garantía de Satisfacción

Si no estás satisfecho con [entregable], lo revisaremos hasta que lo estés —
sin costo adicional — dentro de [30] días de entrega.

**Cómo funciona:**
1. Revisa tus entregables dentro de [14] días de entrega
2. Proporciona feedback escrito específico sobre lo que necesita cambiar
3. Completaremos revisiones dentro de [X] días hábiles
4. Si aún no estás satisfecho después de [2] rondas de revisiones, ofreceremos
   [reembolso X% / crédito hacia trabajo futuro]

**Condiciones:**
- El feedback debe ser específico y accionable (no solo "no me gusta")
- El resumen de proyecto original y alcance aprobado son la referencia para satisfacción
- Cambios al direcciones original o modificaciones no están cubiertos
```

### Opción 2: Garantía de Resultados

```
## Nuestra Garantía de Resultados

Si [resultado medible específico] no se logra dentro de [timeframe],
haremos [remedy].

**Ejemplo:** "Si tu tasa de conversión del sitio web no mejora al menos 15%
dentro de 90 días del lanzamiento, lo optimizaremos durante 90 días adicionales
sin costo."

**Condiciones:**
- El cliente debe implementar todas las recomendaciones como se especifica
- El método de medición se acordó antes de que comience el proyecto
- Los factores externos fuera de nuestro control (cambios de algoritmo, cambios de mercado)
  están excluidos
- El cliente debe proporcionar acceso necesario y datos para medición
```

### Opción 3: Garantía de Desempeño

```
## Nuestra Garantía de Desempeño

Garantizamos los siguientes estándares de desempeño en cada engagement:

- Todos los entregables completados por la fecha acordada o [remedy]
- Respuesta de comunicación dentro de [24] horas en días hábiles
- [X] rondas de revisiones incluidas sin costo adicional
- Todo el trabajo cumple con [estándar de calidad especificado]

**Si no cumplimos con algún estándar:**
- Primera ocurrencia: [Crédito hacia trabajo futuro / revisiones extendidas]
- Ocurrencia repetida: [Reembolso parcial / derecho a terminar]
```

## Fase 3: Términos y Exclusiones

### Términos Esenciales

Cada garantía debe incluir:

1. **Qué está garantizado** — compromiso específico y medible
2. **Cronograma** — cuándo aplica la garantía y expira
3. **Condiciones** — qué debe hacer el cliente para que la garantía sea válida
4. **Remedio** — exactamente qué sucede si se dispara la garantía
5. **Proceso de reclamación** — instrucciones paso-a-paso para hacer reclamación
6. **Exclusiones** — qué NO está cubierto

### Exclusiones Comunes

- Cambios en dirección o alcance del proyecto después de que comienza el trabajo
- Retrasos causados por el cliente (feedback tardío, assets faltantes)
- Fallos de terceros (hosting, plataformas, APIs)
- Resultados afectados por factores fuera del control del proveedor
- Servicios rendidos hace más de [X] días
- Clientes que no han pagado en su totalidad

### Plantilla de Proceso de Reclamación

```
## Cómo Hacer una Reclamación de Garantía

1. Email a [email] con la línea de asunto "Reclamación de Garantía — [Nombre de Proyecto]"
2. Describe el problema específico y cómo se relaciona con la garantía
3. Incluye cualquier documentación o evidencia relevante
4. Reconoceremos tu reclamación dentro de [2] días hábiles
5. La resolución se proporcionará dentro de [X] días hábiles del reconocimiento
```

## Fase 4: Implementación

### Dónde Mostrar la Garantía

- Página de servicio/precios en tu sitio web (cerca del CTA)
- Propuestas y contratos (sección dedicada)
- Conversaciones de ventas (referencia verbal con seguimiento escrito)
- Firmas de email durante engagement activo
- Testimoniales que mencionan la experiencia de garantía

### Garantía como Herramienta de Ventas

```
## Ejemplo de Copia de Ventas

"Cada [servicio] viene con nuestra [Nombre de Garantía]. Si [compromiso específico],
haremos [remedy específico] — sin preguntas.

Podemos ofrecer esto porque [razón — historial, metodología, confianza
en tu proceso]. En [X] años, hemos honrado esta garantía [X] veces
de [X] proyectos — y cada cliente se fue satisfecho."
```

### Seguimiento y Revisión

| Métrica | Rastrear | Revisar |
|--------|--------|--------|
| Tasa de reclamación de garantía | Por trimestre | Bajo 5% es saludable |
| Tiempo de resolución de reclamación | Por reclamación | Bajo 5 días hábiles |
| Retención de cliente después de reclamación | Por reclamación | ¿Volvieron? |
| Impacto de ingresos de reclamaciones | Trimestral | Costo total de remedios |

## Anti-Patrones

- **Garantías vagas** — "100% satisfacción garantizada" sin términos es arriesgado legalmente y comercialmente sin sentido.
- **Sin exclusiones** — cada garantía necesita límites. Sin exclusiones, clientes de mala fe explotan la garantía.
- **Garantizar cosas que no puedes controlar** — no garantices aumentos de ingresos si el cliente controla la implementación.
- **Escondiendo la garantía** — si tienes una garantía, promocionala. Una garantía escondida no construye confianza del comprador.
- **Haciendo reclamaciones difíciles** — requerir llamada, 3 formularios y carta notariada desalienta reclamaciones legítimas.
- **Sin límite financiero** — responsabilidad ilimitada de una garantía puede ser devastadora. Limita tu exposición.

---

## Recuperación

- **Tasa de reclamación alta:** La garantía no es el problema — tu entrega lo es. Arregla calidad y proceso antes de ajustar términos de garantía.
- **Cliente abusando la garantía:** Documenta el patrón, referencia las condiciones y exclusiones, ten conversación directa.
- **La garantía te asusta financieramente:** Comienza con garantía de revisión (rehaz el trabajo) en lugar de garantía de reembolso. Riesgo financiero más bajo.
- **Competidor tiene garantía más fuerte:** Diferencia en especificidad y historial. "Garantizamos X métrica" supera "100% dinero de vuelta."
- **Cliente amenaza invocar garantía como palanca:** Mantente profesional. Aplica términos de garantía como escrito. No negoces bajo presión.
